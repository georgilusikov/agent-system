# Аудит 100 AI-скиллов

Слепой A/B-эвал всей библиотеки скиллов: каждый скилл проверялся на добавленной ценности против голого baseline-агента на задачах с подставными дефектами. Измерялась дельта, а не красота инструкции.

## Методология

- Слепые прогоны: исполнитель не знает вариант (baseline/skill), транскрипты без имён вариантов и путей скиллов (verify-blind).
- Судейство — программный оракул по planted-дефектам; LLM-грейдер (agy/Gemini) использовался как вторичный — измерено: он мягче оракула в ~35% случаев.
- Сначала baseline-пилот задачи на дискриминативность; недискриминативные усиливались один раз.
- Модели: волна 1 — `gemini-3.6-flash-medium`; волны 2–3 — `muse-spark-subagent` (результаты помечены моделью, линейки не смешиваются).
- ~814 прогонов, судейство ~$5.

## Файлы

- `final-100-skills-report.md` — полный отчёт: вердикт и основание по каждому скиллу, методология, стоимость, ограничения стенда, лицензионные флаги, спорные вердикты.
- `waves/` — сводки по волнам: pilot, wave1, round2 (merge-пары), wave2-batch1 (+досборка переформулированных ячеек), wave2-batch2, wave3 (+таблица дискриминативности).
- `registry/` — `skills-registry.yaml` (реестр со 100 вердиктами), `caller-map.md` (кто кого вызывает), `clusters.md` / `dupe-clusters.md` (кластеризация), `upstream-check.md` (проверка third-party источников), `external-analogs.md` (~150 внешних аналогов).

## Честные ограничения

- n=1 на ячейку: дельты ±1 неразрешимы, слабые сигналы помечены insufficient-data.
- 11 ячеек батча 1 измерены на переформулированных промптах (safety-блок исходных) — помечены риском сравнимости.
- Сырые данные прогонов (транскрипты, tool calls) в публикацию не вошли.

## Статус действий

Вердикты — это записи, не действия: слияния/архивации/замены в библиотеке выполняются отдельно.
