# Брифы облачному агенту (Codex cloud / ChatGPT)

Запуск: chatgpt.com/codex → GitHub-коннектор → environment репозитория → промт в задачу → результат = PR. Несколько задач можно ставить в очередь параллельно.

Правила брифа:

1. **`.env` в облаке НЕТ** (gitignored). Тесты в брифе — ТОЛЬКО на фейках; live-ключи и реальные вызовы — при локальной приёмке. Нужны секреты в облаке → прописывать в environment settings Codex.
2. **Duplicate-check ДО брифа**: `git ls-files | grep -iE "<домен>"` + grep по коду. Иначе облаку уходит строительство дублей уже существующих модулей.
3. **Облаку — только изолированные модули**: новый файл + свои тесты, shared-модули «минимальный дифф», гейты/пороги не трогать. Полный pytest облако прогнать не может — приёмка через локальный full pytest на чистом чекауте.
4. В бриф всегда: репо+ветка+«PR, не мержить», Pydantic-контракты, стиль (absolute imports, pathlib, encoding, type hints), запрет `_fixed`/`_final`, требование PR-описания «что/как проверить/ограничения».
5. Environment-специфику класть в AGENTS.md репозитория — облако его читает.
