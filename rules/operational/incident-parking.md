# Incident Parking: сырой кандидат паркуется сразу, не ждёт retro

Ошибки теряются между редкими retro: к моменту разбора никто не помнит, что
именно сломалось. Парковка снимает это одной строкой — без размышлений, без
подтверждения владельца, без формулировки правила.

**Триггер (любой из четырёх) → паркуешь НЕМЕДЛЕННО, в том же ходе:**
- владелец исправил агента («не так», «я же просил», откат твоего решения);
- ошибка повторяемая (может случиться в другой сессии, у другого агента);
- гейт/тест сработал впустую (зелёный на всём, а дефект прошёл; или красный без дефекта);
- 3 неудачные попытки подряд по одной задаче.

```bash
~/.claude/bin/park-incident.sh \
  --signal "semantic: <класс>" \
  --note "<что произошло, одна строка>"
```

Класс — короткий ярлык для группировки: `wrong-tree edit`, `stale context`,
`gate fired empty`, `scope creep`, `unverified claim`. Note — факт, не разбор.
Ни секретов, ни сырых промтов, ни кусков транскрипта.

**Это НЕ замена `learn-from-mistakes.md`.** Там полный цикл: классифицировать →
предложить формулировку → дождаться подтверждения владельца → записать правило.
Здесь — парковка сырого кандидата ДО retro, чтобы к разбору было что разбирать.
Сработал триггер и есть время на полный цикл — делай полный цикл И паркуй.
Времени нет (владелец ждёт результат) — паркуешь и продолжаешь работу.

Механический канал закрыт хуком `~/.claude/hooks/incident-parking.sh` (Stop):
≥3 маркера ошибок в хвосте транскрипта → одна строка `source=hook` на сессию.
Хук ловит падения, но не видит смысловых промахов — за них отвечаешь ты.

**Разбор парковки.** `/retro` и `/principles-review` начинают с чтения
`~/.claude/memory/incidents/parking.jsonl` — это входная очередь, а не архив.
Разобранные строки **переносятся** в `processed.jsonl` рядом (с полем
`verdict`: `rule` / `incident` / `noise`), парковка остаётся пустой. Непустая
парковка на старте retro = долг; пустая = всё разобрано. Дальнейший
review/promotion подчиняется `standards/domain/agent-memory-standard.md`;
парковка не является approved memory.

Парковка — входная очередь, `ai.incidents.jsonl` — подтверждённое: строка с
`verdict=incident` при разборе дополнительно проводится через
`~/.claude/bin/log-incident.sh` (kind/severity), не остаётся только в processed.

EVIDENCE: хотя бы один инцидент, дошедший до retro через парковку, который иначе
был бы потерян.
