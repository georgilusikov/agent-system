# Измерительный override не врезается в доменную функцию

Нужно уравнять/зафиксировать что-то ради замера (A/B, бенчмарк, канарейка) —
врезка идёт **на границе харнесса**, а не внутрь производственной функции.

**Почему.** Доменная функция держит инвариант, на который молча опираются все её
читатели. Override — единственный путь в коде, который его нарушает, и нарушает
беззвучно: каждый потребитель по отдельности работает верно, противоречие
возникает **между** ними.

**Как применять:**
1. Перед врезкой — `grep` всех потребителей функции. Больше одного → override идёт на границу харнесса.
2. Врезал всё равно → тест на каждого потребителя под включённым override. Минимум — на самого «дальнего» (чей выход читает модель или человек: промт, отчёт, UI).
3. Перед длинным прогоном — прочитать **сгенерированный промт на одном примере**. Минута против 26 прогонов.
4. Предупреждение в докстринге формулировать по реальному риску. «Не в проде» ≠ «в замере ок».
