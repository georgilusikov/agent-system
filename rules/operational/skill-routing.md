# Карта маршрутов: фраза владельца → скилл/агент

Триггеры сверены с корпусом реальных реплик владельца (аудит 909 транскриптов
2026-08-01, hit-rate триггеров был 3%). Услышал фразу слева — зови инструмент
справа, не делай ad-hoc.

## Постановка и диагностика
- «meta», «/meta», «как думать», «какая линза», «какой слой», «соедини jtbd и triz», «разбери систему/продукт с нуля» (multi-layer, не один метод) → `/meta` (`~/.claude/skills/meta`)
- «сформулируй задачу», «какой outcome», «что я получу», «5 so what» → агент **outcome-designer**
- «покритикуй план», «где план развалится», «атакуй план» → агент **plan-critic**
- «почини», «пофикс», «баг», «почему падает», «rca», flaky → `/debug`
- «рычаг», «узкое место», «что нас тормозит» → `/leverage` (один bottleneck; если +упростить/JTBD → `/meta`)
- «докажи что стало лучше», «before/after», «измерь эффект» → `/2-hypothesis-eval-loop`
- «спланируй от конца», «критическая цепочка», Голдратт → `/1-critical-chain-design`

## Проверка готового
- готовый артефакт против Expected State → `/check`
- «прогони через гемини/грок/кодекс», «второе мнение» → `/bouncer`
- «фальсифицируй», «можно ли релизить» → `/falsify`
- дифф/PR → `/code-review` · «что я упустил» постфактум → `/pizdej`
- «проверь …» без уточнения → AskUserQuestion: /check | /bouncer | /pizdej (см. CLAUDE.md §Disambiguation)

## Планирование и делегирование
- «делегируй/делигируй кодексу/гроку», «бриф» → `/delegate` · выбор тира/канала → `/cost-aware-delegation`
- волны, worktrees, мониторинг воркеров → `/agent-orchestrator-standard`
- контракт цели и гейты → `/goal-plan`, дальше **только вручную** `/goal-king` (заморожен: автономный цикл волн не стартует по авто-триггеру) · план по спеке → `/writing-plans`
- «роадмэп», «план на квартал» → `/roadmap-planning` · «приоритизируй», «что сначала» → `/prioritize`

## Остальное
- «хэндоф», «запиши в хэндоф», «подведи итоги» → `/handoff` · «продолжи с прошлой сессии», «что было в прошлой сессии» → `/handoff resume`
- «упрости», «сократи», «тримминг», «ИКР», «противоречие» → `/triz` (pure TRIZ; **не** `/meta`)
- «jtbd сценариум», «когда-хочу-чтобы» → `/jtbd-scenarium-create`
- «объясни простыми словами», «на пальцах» → `/feynman` · структура/связи/«что на что влияет» → `/graphify`
- «прототип», «накидай проверить идею» → `/prototype` · «интерфейс модуля», «шов» → `/codebase-design`
- «глоссарий», «термины домена», ADR → `/domain-modeling` · «презентация», «слайды» → `/visual-explainer`
- «скилл не сработал», «конфликт триггеров» → `/sus` · «создай скилл» → `/0-how-to-write-skills` · «найди скилл» → `/find-skills`
- merge conflict → `/resolving-merge-conflicts` · security review → `/security-best-practices` · новый проект → `/init-project`
- «аудит с субагентами», «мульти-агентный аудит» → `/audit-fanout` · «панель моделей», «консенсус-ответ» → `/fusion`
- реализация фичи по готовой спеке/плану → `/implement` · «научи меня», курс с уроками → `/teach`
- «ретро сессии», разбор паркинга инцидентов → `/retro` · аудит системы правил против META_PRINCIPLES (периодический) → `/principles-review`
- новый тест падает, а соседний идентичный проходит · «гонка» в asyncio · Antigravity молчит/worktreeconfig/CDP-гейт → `/known-symptom-fixes`
- пишешь или чинишь хук · принимаешь правки правил от внешнего агента · вышла новая неделя DS-курса → `/rules-and-hooks-maintenance`
- «повторяй каждые N минут», периодический прогон → `/loop`
