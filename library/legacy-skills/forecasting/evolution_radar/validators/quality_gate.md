# Quality Gate: Evolution Radar

## Mandatory Checks
- [ ] System Lock заполнен (система, функция, MPV, S-curve)?
- [ ] Все 6 линий эволюции проработаны?
- [ ] ≥ 18 уникальных концептов (минимум 3 на линию)?
- [ ] Каждый концепт конкретен (не "улучшить" / "оптимизировать")?
- [ ] Каждый концепт имеет реальный аналог из другой отрасли?
- [ ] Top-5 проверены: Enabling Tech + Патентабельность + Новое противоречие?
- [ ] Radar Map собрана с цветовой маркировкой (🟢🟡🔴⭐)?

## Handoff Check
- [ ] Best candidates переданы в `@boris_v5` или `@critic`?
- [ ] Новые противоречия переданы в `@contradictions`?
