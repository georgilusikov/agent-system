# 📡 Evolution Radar (Эволюционный Радар)

> **Миссия:** Принудительно прогнать систему/продукт по 6 классическим Линиям Эволюции (Злотин/Зусман) и сгенерировать **матрицу из 18-24 конкретных будущих концептов** на разных горизонтах. Инструмент для патентных зонтиков, стратегических roadmap и R&D-планирования.

## Чем отличается от соседей

| Скилл | Что делает | Тип работы |
|---|---|---|
| `@zrts` | Диагностирует, по какому закону система развивается **сейчас** | Анализ (какой закон?) |
| `@boris_ikr` | Прыгает в ИКР и строит путь назад | Визионерство (идеальный финал) |
| `@boris_v5` | Полный прогноз через 8 фаз (S-curve + ФА + ЗРТС + FOS) | Оркестратор прогноза |
| **`@evolution_radar`** | Берёт продукт и генерирует **веер из 18-24 конкретных будущих состояний** по всем линиям одновременно | **Генератор концептов** |

## Handoff

- На вход: описание продукта/системы + (опционально) текущая S-curve стадия от `@s_curve`.
- На выход: Радарная таблица (Линия × Горизонт) → передать в `@boris_v5` для глубокого анализа лучших траекторий, или в `@critic` для проверки.

Please see `core_instructions.md` for the full execution protocol.
