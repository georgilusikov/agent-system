# 📋 DE Questionnaire (Directed Evolution Diagnostic — по Злотину)

> **Источник:** Zlotin B., Zusman A. — «TRIZ to Invent Your Future» (2011), секция 5: «DE Questionnaire – a comprehensive set of questions and instructions for conducting a thorough diagnostic evaluation of the given system.»
>
> **Когда использовать:** Обязательно в Phase 0 перед Lock. Этот опросник гарантирует, что ничего не пропущено при фиксации системы.

---

## 1. История системы

- [ ] **Когда и кем создана система?** Кто был первым изобретателем / создателем? Какую задачу решали?
- [ ] **Какие альтернативные PoA рассматривались при создании?** Были ли отвергнутые варианты? Почему их отвергли — и актуальны ли те причины сегодня?
- [ ] **Какие критические точки были в истории?** Моменты, когда система почти погибла / радикально изменилась / получила второе дыхание.
- [ ] **Были ли попытки гибридизации?** Скрещивали ли систему с конкурентами / смежными системами? С каким результатом?
- [ ] **Какие «проигравшие» варианты всё ещё существуют в нишах?** (важно для Hybridization Protocol, шаг 4.0.5)

## 2. Текущий принцип действия (PoA)

- [ ] **Опишите цепочку преобразований:** INPUT → [какие физ/хим/информационные процессы] → OUTPUT. Используйте причинно-следственный формат.
- [ ] **Какой ключевой расходник / «серая зона»?** Что самое грязное / дорогое / нестабильное в текущем PoA?
- [ ] **Какой главный физический / логический предел?** Есть ли теоретический максимум (закон природы, пропускная способность, когнитивный предел)?
- [ ] **Какие подсистемы критичны?** Без чего система полностью перестанет работать?
- [ ] **Какие вредные побочные функции есть?** Что система делает «бесплатно», но нежелательно?

## 3. Контекст и надсистема

- [ ] **Какие надсистемные тренды влияют?** (регуляторика, технологический сдвиг, демография, климат, культура)
- [ ] **Кто основные конкуренты и чем отличаются?** Используют ли они другой PoA? Какие у них ±?
- [ ] **Какие системы-аналоги существуют в ДРУГИХ отраслях?** (для FOS-поиска)
- [ ] **Готова ли инфраструктура?** (Эффект «Бурана» — технически совершенная система, которую надсистема не потянула)
- [ ] **Какие регуляторные / юридические / культурные барьеры существуют?**

## 4. Эволюционный потенциал

- [ ] **На какой стадии S-кривой система?** (I-Infancy / II-Growth / III-Maturity / IV-Decline) — хотя бы предварительная гипотеза.
- [ ] **Какие ресурсы НЕ используются?** (вещественные, энергетические, информационные, пространственные, временные)
- [ ] **Какие уровни НЕ задействованы?** (если работаем на макро — какой потенциал у мезо/микро? — но не спешить!)
- [ ] **Была ли смена поколений?** Сколько раз менялся основной PoA с момента создания?
- [ ] **Есть ли «enabling technologies», которые недавно появились?** (AI, нано, биотех, IoT, блокчейн и т.д.)

## 5. IP и защита

- [ ] **Есть ли патенты у системы / конкурентов?** Сколько, в каких кластерах?
- [ ] **Есть ли блокирующие патенты?** Что ограничивает развитие?
- [ ] **Можно ли запатентовать улучшения?** (предварительная оценка)

---

## ✅ Минимальный порог

Перед переходом к Lock (Phase 0.1) должны быть заполнены:
- **≥ 3 вопроса** из каждого раздела (1–4)
- **Все вопросы** из разделов 1.2 (альтернативные PoA) и 2.2 (серая зона) — они критичны для Hybridization Protocol и Litvin Protocol

Если данных не хватает — пометьте [ASSUME] и добавьте в Assumption Ledger (Phase 5).
