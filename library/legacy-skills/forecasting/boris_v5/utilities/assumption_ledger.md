# Assumption Ledger (Phase 5)

## Назначение
Учёт всех предположений ([ASSUME]/[SPEC]) и их закрытие экспериментами, чтобы не размывать Confidence.

|---|----------------------------------|----------------|---------------------------------------|----------|------|--------|
| 1 |                                   |                |                                       |          |      |        |
| ... | ... | ... | ... | ... | ... | ... |

## Правила
- Каждому [ASSUME]/[SPEC] — 1 эксперимент или отказ с обоснованием.
- Критические (Impact H) без эксперимента → penalty к Confidence (cap при ≥2).
- Синхронизировать с Risk Register: отметить, какие риски снимаются тестами.
- По итогам эксперимента обновить Verdict/Confidence/Robustness.
