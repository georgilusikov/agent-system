# 🎯 Boris IKR-First (Прогноз)

**Purpose:** IKR-driven forecasting - start from ideal end result, work backwards.

**When to use:**
- Strategic forecasting for product/technology
- Need to see evolution path
- Want to identify breakthrough opportunities

**Output:** IKR statement, Subsystem IKR Map, Evolution Path, Three Scenarios

**Gate Check:**
- IKR clearly formulated for system
- Zero-System alternative checked
- Subsystem IKRs defined
- 3 scenarios (Incremental/Breakthrough/Blocked)
