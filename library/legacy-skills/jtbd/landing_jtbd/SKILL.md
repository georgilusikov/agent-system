# Текст лендинга продукта по структуре AJTBD (VANECHKA3000)

**Источник промпта:** `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md` — раздел **«5. Текст лендинга продукта по структуре AJTBD»**.

## Когда применять

- Пользователь просит написать или переписать текст лендинга для продукта под конкретный сегмент.
- Есть описание сегмента и работ (Core Jobs, Big Job, Micro Jobs); нужен полный текст по блокам.
- Запросы: «напиши лендинг по JTBD», «текст лендинга для сегмента», «структура лендинга Core Job», «онлайнер + ценность».

## Инструкция для агента

1. **Загрузи полный промпт** из `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md`: секция от заголовка `## 5. Текст лендинга продукта по структуре AJTBD` до конца блока промпта (включая структуру в коде). При необходимости используй `core_instructions.md` этого скилла — там каноническая структура блоков.

2. **Входные данные:**
   - **Сегмент:** описание и работы сегмента (Core Jobs, Big Job, при наличии — Micro Jobs, триггеры, эмоции в точке А/Б).
   - **Продукт:** название и краткое описание продукта.

3. **Подставь в шаблон:**
   Используй структуру из промпта №5 или из `core_instructions.md`. Заполни каждый блок конкретными формулировками под сегмент и продукт. Не пропускай блоки: Oneliner → Core Job + фичи → одна легко реализуемая Micro Job → aha-момент → ценность → «Человек узнаёт себя» → как выполнить Core Job/Big Job → Точка Б (эмоции + образ) → барьеры → конкуренты.

4. **Стиль и ссылки:**
   - Ориентируйся на пример в ALL-PROMPTS (#5) и на гайд `projects/VANECHKA3000/docs/examples/LANDING-FRAMEWORK.md` (Hero = Job Story, CTA = первый шаг прогресса, выгоды = outcomes).
   - Термины: Core Job, Big Job, Micro Job, точка А, точка Б — без перевода.

5. **Формат вывода:**
   Разметка по блокам (например `=== ONELINER ===`, `=== HERO ===`, `=== AHA-МОМЕНТ ===` и т.д.) и готовые тексты для каждого блока, чтобы можно было вставить в лендинг или бриф.

## Связь с VANECHKA3000

- Полный гайд по JTBD-лендингам: `projects/VANECHKA3000/docs/examples/LANDING-FRAMEWORK.md`
- 10-блочная структура: `projects/VANECHKA3000/docs/.../landing-os.md` (если есть в проекте)
- Стиль и CTA: `projects/VANECHKA3000/docs/.../style.md`
- После лендинга: A/B-тесты, метрики CR — см. LANDING-FRAMEWORK.md
