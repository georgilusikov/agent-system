# Граф работ ниже уровнем к Core Job (VANECHKA3000)

**Источник промпта:** `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md` — раздел **«4. Граф работ ниже уровнем к Core Job»**.

## Когда применять

- После выбора сегмента (промпт #2 или #3): нужно детализировать все работы ниже уровнем к Core Job для этого сегмента и продукта.
- Запросы: «построй граф работ», «опиши работы ниже Core Job», «customer journey по работам», «где разрывы в решении», «точки улучшения UX по графу работ».

## Инструкция для агента

1. **Загрузи полный промпт** из `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md`: секция от заголовка `## 4. Граф работ ниже уровнем к Core Job` до конца блока промпта (до `---` перед «Пример использования»). В промпте уже задана структура:
   - для **Core Job сегмента**: когда (контекст, триггер, активирующее знание, эмоции в точке А), хочу…, критерии успеха, чтобы…;
   - для **каждой работы в графе**: когда (контекст, триггер, эмоции в точке А), хочу получить ожидаемый результат, критерии успеха получения результата, проблемы [если есть], сила проблемы по 10-балльной шкале.

2. **Подставь в блок-ввод:**
   - **Сегмент** — из промпта генерации гипотез сегмента (промпт #2 или #3).
   - **Продукт** — описание продукта со ссылкой на сайт.
   - **Core Job** — описание Core Job из работы по сегменту.

3. **Выполни задачу по методологии AJTBD:** опиши полную последовательность работ ниже уровнем к Core Job; каждую работу — с детализацией по шаблону промпта.

4. **Формат вывода каждой работы в графе** (строго по промпту):
   - когда: контекст, триггер, эмоции в точке А
   - хочу получить ожидаемый результат: …
   - критерии успеха получения ожидаемого результата: …
   - Проблемы [если есть]: …
   - Сила проблемы по 10-балльной шкале: N/10

## Связь с VANECHKA3000

- Теория графа работ: `projects/VANECHKA3000/` — 4. jtbd-research (zamesin-jtbd.md, jtbd-interview-guide.md).
- Предыдущий шаг: выбор сегмента (#2 B2C или #3 B2B). Следующие шаги: лендинг (#5), рекрут респондентов (#6) — см. ALL-PROMPTS.md.
