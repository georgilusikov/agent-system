# B2C-сегментация по AJTBD (VANECHKA3000)

**Источник промпта:** `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md` — раздел **«2. Выбор 5 привлекательных B2C-сегментов по AJTBD»**.

## Когда применять

- Пользователь описывает B2C-продукт и просит выбрать сегменты для запуска или масштабирования.
- Запросы: «выбери 5 сегментов», «сегментация по JTBD/AJTBD», «кто наши клиенты по работам», «TAM/SAM/SOM по сегментам».

## Инструкция для агента

1. **Загрузи полный промпт** из `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md`: секция от заголовка `## 2. Выбор 5 привлекательных B2C-сегментов по AJTBD` до конца блока промпта (включая подраздел «Контекст: как сегментировать...»). Не копируй «Пример использования» в сам промпт.

2. **Подставь в блок-ввод:**
   - **Продукт:** описание из сообщения пользователя (или уточни, если не указано).
   - **Сайт продукта:** ссылка на сайт / AppStore / Play Market, если есть.

3. **Выполни анализ по шагам 1–2 внутренне (не выводи).** Шаг 1: 7–10 гипотетических сегментов (каждый — 1–4 Core Jobs + одна Big Job; отличаются контекстом, ролью, критериями выполнения). Шаг 2: по каждому — TAM/SAM/SOM, ценность, прибыльность, масштабируемость. Шаг 3 — единственный вывод: 5 сегментов, отсортированных по привлекательности.

4. **Формат вывода каждого сегмента** (строго по промпту):
   - Сегмент (название)
   - Core Jobs (Когда ..., хочу ...)
   - Критерии выполнения
   - Что за люди
   - Big Job (Хочу ..., чтобы ...)
   - TAM / SAM / SOM (оценка + краткая логика в цифрах)
   - Почему сегмент привлекателен (1–2 абзаца)

5. **Дополнительные правила из промпта:**
   - Не выводи шаги 1 и 2 — только результат шага 3.
   - Не используй термин «боль» — только мотивации, ситуации, критерии.
   - Регион по умолчанию — СНГ, если не указано иное.
   - Пиши компактно и по делу; результат должен помогать выбору MVP и стратегии роста.

## Связь с VANECHKA3000

- Теория и контекст сегментации: `projects/VANECHKA3000/config/resources/jtbd-3/theory/` (02_segmentation_jobs.md, 05_segment_selection.md).
- Следующие шаги после сегментов: граф работ (#4), рекрут респондентов (#6), лендинг (#5) — см. ALL-PROMPTS.md.
