# Все чек-листы AJTBD — Сборник

> **Телеграм-саммари:** 12 чек-листов с рекомендациями какой когда использовать. Распечатай и используй как руководство!

---

## 🎯 Какой чек-лист использовать?

### По задаче:

| Задача | Чек-лист | Время |
|--------|----------|-------|
| Запускаю новый продукт | #11 (Запуск) | 3-4 нед |
| Лендинг не конвертит | #7 (Лендинг) + #9 (Механики) | 1-2 нед |
| Не знаю кто клиент | #2 (Сегменты) + #8 (Валидация) | 2-3 нед |
| Оптимизирую продукт | #12 (Оптимизация) | 1-4 нед |
| Провожу интервью | #5 (Switch) или #6 (Expert) | 60/45 мин |
| Работаю с B2B | #4 (B2B) | Всегда |
| Строю граф работ | #3 (Граф) | 1-2 часа |

### По этапу:

**Этап 1: До начала** → Чек-лист #1 (Применение AJTBD)
**Этап 2: Сегментация** → Чек-лист #2 (Сегменты)
**Этап 3: Граф работ** → Чек-лист #3 (Граф)
**Этап 4: Интервью** → Чек-лист #5 (Switch) или #6 (Expert)
**Этап 5: Валидация** → Чек-лист #8 (Валидация)
**Этап 6: Лендинг** → Чек-лист #7 (Лендинг)
**Этап 7: Механики** → Чек-лист #9 (Механики)

## ✅ Чек-лист #1: Применение AJTBD (общий)

### Перед началом работы
- [ ] Прочитал базовые принципы ([1-page-summary](1-page-summary.md), 5 мин)
- [ ] Понял разницу между Big/Core/Small/Micro Jobs
- [ ] Понял модель Точка А → Б (эмоции!)
- [ ] Понял почему сегментация по работам, а не демографии

---

## ✅ Чек-лист #2: Работа с сегментами

- [ ] Использовал **промпт #2 (B2C)** или **#3 (B2B)**
- [ ] Сгенерировал 5-10 сегментов (не останавливайся на 2-3!)
- [ ] Для каждого сегмента описал:
  - [ ] Core Job (конкретная работа)
  - [ ] Big Job (эмоциональная цель)
  - [ ] Контекст (когда, где, почему)
  - [ ] Критерии (что важно для сегмента)
  - [ ] Точка А → Б (эмоции до и после)
  - [ ] TAM/SAM/SOM (размер рынка)
- [ ] Приоритизировал по привлекательности:
  - [ ] Размер рынка (TAM/SAM/SOM)
  - [ ] Ценность для сегмента (насколько важна работа)
  - [ ] Прибыльность (готовность платить)
  - [ ] Масштабируемость (легко ли добавлять клиентов)
- [ ] Выбрал **топ-2** для валидации (не больше!)
- [ ] НЕ выдумал работы (это гипотезы!) → проверю через интервью

---

## ✅ Чек-лист #3: Построение графа работ

- [ ] Использовал **промпт #4 (Граф работ)**
- [ ] Описал все уровни иерархии:
  - [ ] Big Job (долгосрочная цель, эмоциональная)
  - [ ] Core Job (основная задача, конкретная)
  - [ ] Small Jobs (шаги к Core Job)
  - [ ] Micro Jobs (действия внутри Small Jobs)
- [ ] Для каждой работы описал:
  - [ ] Триггер (что запускает работу)
  - [ ] Точка А (эмоции, контекст ПЕРЕД работой)
  - [ ] Точка Б (желаемый результат, эмоции ПОСЛЕ)
  - [ ] Критерии успеха (как поймёт что выполнил)
  - [ ] Сила проблемы (0-10/10)
- [ ] Нашёл разрывы (где клиент застревает):
  - [ ] Оценил силу каждого разрыва (0-10)
  - [ ] Выделил критические (сила ≥8/10)
  - [ ] Выделил топ-5 для работы
- [ ] Определил **критическую последовательность работ (КПР)**:
  - [ ] Работы БЕЗ которых цель не достигается = критические
  - [ ] Работы которые можно пропустить = некритические
- [ ] Фокусируюсь на КПР (самое важное!)

---

## ✅ Чек-лист #4: B2B-продукты

- [ ] Использовал **промпт #3 (B2B-сегментация)**
- [ ] Описал работы компании:
  - [ ] Увеличить прибыль
  - [ ] Снизить расходы
  - [ ] Увеличить производительность
  - [ ] Снизить риски
- [ ] Описал **личные работы ЛПР** (критично!):
  - [ ] Страхи (не потерять статус, не быть уволенным, не выглядеть некомпетентным)
  - [ ] Амбиции (получить повышение, признание, бонус)
  - [ ] KPI (выполнить личные метрики)
- [ ] Понял что **личные работы ЛПР часто ВАЖНЕЕ** работ компании!
- [ ] Включил личные работы в лендинг:
  - [ ] Работы компании (рациональные выгоды)
  - [ ] Личные работы ЛПР (эмоциональные выгоды)
- [ ] В интервью спрашивал:
  - [ ] "Что для вас лично важно?"
  - [ ] "Какие риски для вас есть?"
  - [ ] "Как это повлияет на вашу команду/статус?"

## ✅ Чек-лист #5: Switch-интервью (60 мин)

### Подготовка
- [ ] Нашёл 5-10 респондентов (**промпт #6**)
- [ ] Респонденты **УЖЕ ПЛАТИЛИ** за решение этой работы
- [ ] Забронировал **60 минут** (не 30!)
- [ ] Подготовил рекордер (Zoom, Grain.co)
- [ ] Предупредил что будет запись
- [ ] Объяснил что это НЕ продажа (исследование)

### Этап 1: Warm-up (5 мин)
- [ ] Расслабил респондента
- [ ] Узнал базовую информацию (роль, опыт)
- [ ] НЕ спрашивал про продукт (ещё рано!)

### Этап 2: Найти Switch (10 мин)
- [ ] Спросил: "Расскажите про **последний раз** когда [переключились/купили]"
- [ ] Убедился что это конкретный эпизод (не общие мнения!)
- [ ] Если не помнит → спросил про предыдущий раз

### Этап 3: Первая мысль (5 мин)
- [ ] Нашёл триггер (событие)
- [ ] Выяснил эмоции в Точке А
- [ ] Понял Big Job (долгосрочная цель)

### Этап 4: Таймлайн (25 мин) — КРИТИЧНО!
- [ ] Прошёл **ВСЕ шаги** от первой мысли до покупки
- [ ] После КАЖДОГО ответа спрашивал: **"А что дальше?"**
- [ ] Выяснил:
  - [ ] Что гуглил
  - [ ] С кем советовался
  - [ ] Какие варианты рассматривал
  - [ ] Почему выбрал этот, а не другой
  - [ ] Что пугало
  - [ ] Что останавливало
  - [ ] Что помогло принять решение
- [ ] Записал **дословно** (цитаты!)

### Этап 5: Силы переключения (10 мин)
- [ ] **Push** (от старого): Что НЕ нравилось?
- [ ] **Pull** (к новому): Что обещало новое? Чего ожидали?
- [ ] **Anxiety** (страх): Что пугало? Какие риски?
- [ ] **Habit** (привычка): Что удерживало у старого?

### Этап 6: После покупки (5 мин)
- [ ] Оправдались ли ожидания?
- [ ] Что удивило?
- [ ] Что бы сделали иначе?
- [ ] Рекомендовали бы? Почему?

### Ошибки (НЕ делай!)
- [ ] ❌ НЕ спрашивал мнения ("Что вы думаете о...")
- [ ] ❌ НЕ задавал наводящие вопросы ("Цена была важна, да?")
- [ ] ❌ НЕ продавал ("А у нас есть функция X!")
- [ ] ❌ НЕ останавливался на первом ответе (копал "Почему?" 5 раз)

### После интервью
- [ ] Транскрипция (автоматическая или вручную)
- [ ] Выделил цитаты (Job Stories)
- [ ] Выделил эмоции (Точка А → Б)
- [ ] Построил граф работ (**промпт #4**)
- [ ] Нашёл разрывы (сила 0-10)
- [ ] Сформулировал гипотезы

## ✅ Чек-лист #6: Expert-интервью (30-45 мин)

### Подготовка
- [ ] Нашёл 3-5 экспертов (разные позиции на рынке)
- [ ] Эксперты знают индустрию/рынок (не просто пользователи!)
- [ ] Забронировал 30-45 минут
- [ ] Объяснил что это исследование (не продажа)

### Во время интервью
- [ ] **Контекст эксперта** (5 мин): роль, опыт, клиенты
- [ ] **Сегментация рынка** (10 мин): типы клиентов, кто привлекательный
- [ ] **Тренды** (10 мин): что изменилось, что будет актуально
- [ ] **Боли и работы** (10 мин): типичные проблемы, существующие решения
- [ ] **Критерии выбора** (5 мин): как клиенты принимают решения

### После интервью
- [ ] Выделил гипотезы о работах (это гипотезы, не факты!)
- [ ] Выделил привлекательные сегменты
- [ ] Сформулировал что проверять через Switch
- [ ] Запросил рекомендации других экспертов

### Важно!
- [ ] ⚠️ Expert даёт **гипотезы**, Switch даёт **факты**
- [ ] ⚠️ Всегда проверяй гипотезы эксперта через Switch-интервью с клиентами!

---

## ✅ Чек-лист #7: Создание лендинга на основе AJTBD

- [ ] Провёл 5-10 Switch-интервью
- [ ] Построил граф работ (**промпт #4**)
- [ ] Использовал **промпт #5 (Текст лендинга)**
- [ ] Лендинг содержит:
  - [ ] **Hero:** Big Job (эмоциональный крючок)
  - [ ] **Oneliner:** Core Job (конкретная работа)
  - [ ] **Ценности:** Как выполняем работу лучше (6 механик)
  - [ ] **Точка А → Б:** Эмоции до и после
  - [ ] **"Узнаёшь себя?"** Триггеры, контекст, эмоции в точке А
  - [ ] **Барьеры:** Снижаем тревоги (Anxiety)
  - [ ] **Конкуренты:** Почему мы лучше выполняем работу
  - [ ] **CTA:** Следующий шаг к выполнению работы
- [ ] Использовал язык клиента (цитаты из интервью!)
- [ ] Фокус на ОДНОМ сегменте (не универсальный!)
- [ ] Эмоции важнее фич!

---

## ✅ Чек-лист #8: Валидация гипотез

- [ ] НЕ принимал решения на основе гипотез!
- [ ] Промпты дают гипотезы, интервью — факты
- [ ] Провёл минимум 5-10 Switch-интервью
- [ ] Искал только тех, кто УЖЕ ПЛАТИЛ
- [ ] Записал дословно (цитаты!)
- [ ] Проверил каждое слово в описании работы:
  - [ ] "После работы" ≠ "Перед сном" (разные триггеры!)
  - [ ] "За 3 недели" ≠ "За 3 месяца" (разные бюджеты!)
- [ ] Запустил MVP (лендинг + трафик)
- [ ] Измерил метрики:
  - [ ] CR ≥2%? → Гипотеза подтверждена ✅
  - [ ] CR <2%? → Вернулся к интервью (новые гипотезы)

## ✅ Чек-лист #9: Применение механик из кейсов

### Диагностика (1-2 часа)
- [ ] Построил граф работ (**промпт #4**)
- [ ] Оценил силу проблемы на каждом шаге (0-10)
- [ ] Нашёл топ-5 разрывов (сила ≥8/10)
- [ ] Определил текущую метрику (CR? LTV? Revenue?)

### Выбор механики (30 мин)

**Если CR низкий (<2%):**
- [ ] Механика #2 (Фокус на сегменте)
- [ ] Механика #3 (Tripwire)
- [ ] Механика #1 (Выход на предыдущую работу)

**Если LTV низкий:**
- [ ] Механика #5 (Детализация графа → узкие места)
- [ ] Механика #4 (Смена бизнес-модели)

**Если средний чек низкий:**
- [ ] Механика #2 (Фокус на сегменте с большим бюджетом)
- [ ] Механика #6 (ROI-фокус для B2B)

**Если не знаю что делать:**
- [ ] Механика #7 (OODA-цикл → быстрые эксперименты)

### Применение (1-4 недели)
- [ ] Сформулировал гипотезу ([experiment-framework](../../../[standards.md]/2.%20experiments-framework/experiment-framework.md))
- [ ] Создал MVP (лендинг, прототип, A/B-вариант)
- [ ] Запустил эксперимент (1-2 недели)
- [ ] Измерил результат (CR, LTV, Revenue)
- [ ] **Если работает** → масштабируй
- [ ] **Если не работает** → выбери другую механику

### Масштабирование (1-3 месяца)
- [ ] Применил 2-3 механики параллельно
- [ ] Создал backlog экспериментов
- [ ] Запускаю 1-2 эксперимента в неделю
- [ ] Масштабирую выигрышные механики

## ✅ Чек-лист #10: Избегание антипаттернов

### Антипаттерн: "Решать проблемы"
- [ ] ❌ НЕ спрашиваю "Какие у вас проблемы?"
- [ ] ✅ Спрашиваю "Какую работу пытались выполнить?"
- [ ] Понял: проблема = индикатор работы (не сама работа!)
- [ ] Фокусируюсь на работах, а не проблемах

### Антипаттерн: Универсальный лендинг
- [ ] ❌ НЕ пишу "для всех"
- [ ] ✅ Выбрал ОДИН сегмент
- [ ] ✅ Говорю на языке ЭТОГО сегмента

### Антипаттерн: Выдумывание работ
- [ ] ❌ НЕ принимаю решения на основе гипотез
- [ ] ✅ Провожу интервью (5-10 минимум)
- [ ] ✅ Ищу только тех, кто УЖЕ ПЛАТИЛ

### Антипаттерн: Игнорирование B2B-специфики
- [ ] ❌ НЕ говорю только про работы компании
- [ ] ✅ Выделяю личные работы ЛПР
- [ ] ✅ Понял: личные работы важнее!

### Антипаттерн: Полный редизайн без валидации
- [ ] ❌ НЕ делаю редизайн на 3-6 месяцев
- [ ] ✅ Тестирую через A/B (1-2 недели)
- [ ] ✅ Итерирую быстро (OODA-цикл)

## ✅ Чек-лист #11: Запуск нового продукта (полный)

- [ ] **Оценка рисков** (2 часа):
  - [ ] Промпт #1 (RAT) → Top-5 рисков
  - [ ] Понял что может убить продукт

- [ ] **Выбор сегмента** (1-2 часа):
  - [ ] Промпт #2 (B2C) или #3 (B2B) → 5 сегментов
  - [ ] ICE-приоритизация → топ-2

- [ ] **Детализация пути** (1-2 часа):
  - [ ] Промпт #4 (Граф работ) → разрывы
  - [ ] Топ-5 критических разрывов (сила ≥8/10)

- [ ] **Рекрут** (1-2 недели):
  - [ ] Промпт #6 → 9 каналов
  - [ ] Нашёл 10-15 респондентов
  - [ ] УЖЕ ПЛАТИЛИ за решение!

- [ ] **Интервью** (1-2 недели):
  - [ ] 5-10 Switch-интервью (по чек-листу #5)
  - [ ] Записал дословно
  - [ ] Извлёк инсайты

- [ ] **Создание MVP** (2-3 часа):
  - [ ] Промпт #5 (Лендинг) → текст
  - [ ] Вёрстка + аналитика
  - [ ] Готово к запуску

- [ ] **Запуск** (1 неделя):
  - [ ] Трафик на лендинг
  - [ ] Измерил CR, заявки, первые продажи
  - [ ] CR ≥2%? → Валидировано! ✅

**Итого:** 3-4 недели до валидированного MVP
**Экономия:** $5k-10k (vs 3-6 месяцев без AJTBD)

## ✅ Чек-лист #12: Оптимизация существующего продукта

- [ ] **Диагностика** (1-2 часа):
  - [ ] Промпт #4 (Граф работ) → разрывы
  - [ ] Какая метрика проблемная? (CR? LTV? Средний чек?)

- [ ] **Интервью** (1 неделя):
  - [ ] Switch с churned-клиентами (если LTV низкий)
  - [ ] Switch с теми кто не купил (если CR низкий)
  - [ ] 5-10 интервью

- [ ] **Выбор механики** (30 мин):
  - [ ] Посмотрел [таблицу механик](../case-mechanics-patterns.md)
  - [ ] Выбрал 1-2 механики под свою ситуацию

- [ ] **Применение** (1-2 недели):
  - [ ] Создал гипотезу
  - [ ] Запустил A/B-тест
  - [ ] Измерил результат

- [ ] **Масштабирование** (если работает):
  - [ ] Применил к другим сегментам
  - [ ] Запустил параллельные эксперименты
  - [ ] Итерирую через OODA-цикл

---

## 📊 Метрики успеха (как понять что работает)

- [ ] **CR лендинга:** ≥2% (хорошо), ≥3% (отлично)
- [ ] **CAC:** ≤ LTV/3 (окупаемость за <1 год)
- [ ] **LTV/CAC:** ≥3 (идеально)
- [ ] **Payback:** ≤6 месяцев
- [ ] **Churn:** <5% в месяц (B2B SaaS)
- [ ] **NPS:** ≥40 (готовы рекомендовать)
