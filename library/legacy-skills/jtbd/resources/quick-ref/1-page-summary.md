## 🎯 Главное

**Работа** = задача клиента (НЕ демография!)
**Ценность** = энергоэффективность выполнения работ
**Граф работ** → механики создания ценности → алгоритмы решения бизнес-задач

---

## 📊 Иерархия работ (4 уровня)

```
Big Job (годы)        → "Быть успешным founder'ом"
    ↓
Core Job (недели)     → "Запустить MVP за 3 недели"
    ↓
Small Job (дни)       → "Найти сегмент для продукта"
    ↓
Micro Job (часы)      → "Сгенерировать 5 сегментов" (промпт #2)
```

**Big Job** привлекает, **Core Job** конвертирует!

---

## 💡 Ценность = Энергоэффективность

**6 механик создания ценности:**

1. **Убить работу** → Автоматизация, чтобы не делать вообще
2. **Починить проблему** → Устранить разрыв (сила ≥8/10)
3. **Снять с человека** → Делегировать продукту/сервису
4. **Больше работ одним решением** → iPhone = телефон+камера+навигатор
5. **Выйти на следующую** → Booking: отель→билеты→такси
6. **Выйти на предыдущую** ⚠️ → Часто даёт БОЛЬШЕ роста!

---

## 🔄 Граф работ (критично!)

**Граф** = последовательность всех работ от Big до Micro

**Критическая последовательность (КПР)** = работы БЕЗ которых цель НЕ достигается

**Разрыв** = место где клиент застревает (сила 0-10)

**Применение:**
1. Построй граф (промпт #4)
2. Найди разрывы (сила ≥6/10)
3. Примени механику ценности
4. Тестируй через MVP

---

## 🎯 Сегментация (НЕ по демографии!)

**❌ НЕ работает:**
- Возраст, пол, доход
- Психография
- Должность

**✅ Работает:**
- **По работам!**
- Люди с одинаковыми Core Jobs = один сегмент
- Разные Core Jobs = разные продукты

**Формат сегмента:**
```
Core Job: [конкретная работа]
Big Job: [эмоциональная цель]
Контекст: [когда, где, почему]
Точка А→Б: [эмоции до и после]
```

---

## 🏢 B2B-специфика (критично!)

**У ЛПР 2 типа работ:**
1. Работы компании (увеличить прибыль, снизить расходы)
2. **Личные работы ЛПР** (страх, амбиции, KPI)

**⚠️ Личные работы ЛПР часто ВАЖНЕЕ работ компании!**

**Пример:**
- Продукт экономит $100k/год
- Но требует уволить 3 человек из команды ЛПР
- ЛПР боится потерять влияние → НЕ купит

**Решение:** Говори про личные работы ЛПР!

---

## 🚨 Критический антипаттерн

**"Решать проблемы клиентов" — НЕПРАВИЛЬНО!**

**Проблема ≠ то что нужно решать**

**Проблема** = индикатор работы (как температура = индикатор болезни)

**Правильно:**
1. Услышал проблему → НЕ спеши решать!
2. Спроси: "Какую работу пытались выполнить?"
3. Построй граф работ
4. Примени механику ценности

## 📋 7 механик из реальных кейсов

| Механика | Результат | Время |
|----------|-----------|-------|
| 1. Выход на предыдущую | +50-75% CR | 2-4 нед |
| 2. Фокус на сегменте | +30-75% CR | 1-2 нед |
| 3. Tripwire | +100% платящих | 1-2 нед |
| 4. Смена бизнес-модели | +50-150% LTV | 1-3 мес |
| 5. Детализация графа | +20-50% метрики | 1-2 нед |
| 6. ROI-фокус (B2B) | +30-50% CR | 1-2 нед |
| 7. OODA-цикл | Адаптация 5-10x | Постоянно |

**#4 Граф работ** → Разрывы 0-10 (1-2 часа)

## 🔍 Switch-интервью (основной метод)

**Фокус:** Последний эпизод переключения (НЕ общие мнения!)

**Структура (60 мин):**
1. Warm-up (5 мин)
2. Найти Switch (10 мин)
3. Первая мысль / триггер (5 мин)
4. **Таймлайн** (25 мин) ← КРИТИЧНО! "А что дальше?"
5. Силы переключения (10 мин): Push/Pull/Anxiety/Habit
6. После покупки (5 мин)

**Главное правило:** Спрашивай факты, НЕ мнения!
