## 📋 Формат описания работы

### Job Story
```
Когда [ситуация/контекст],
я хочу [действие/прогресс],
чтобы [ожидаемый результат],
чтобы [Big Job / долгосрочная цель]
```

**Пример:**
```
Когда менеджер просит срочный отчёт в конце дня,
я хочу одним кликом собрать дашборд,
чтобы не тратить 2 часа на сводные таблицы,
чтобы не задерживаться на работе и провести вечер с семьёй
```

## 📊 Формат описания сегмента

```
Сегмент: [название]

Core Job: [конкретная работа, измеримая, срок: недели]
Big Job: [эмоциональная цель, долгосрочная, годы]

Контекст:
- Когда: [ситуация, триггер]
- Где: [место, окружение]
- Почему важно: [связь с Big Job]

Критерии:
- [критерий 1]: [описание]
- [критерий 2]: [описание]
- [критерий 3]: [описание]

Точка А → Б:
- А: [эмоции: страх/фрустрация/тревога, контекст]
- Б: [желаемый результат, эмоции: облегчение/уверенность/радость]

TAM/SAM/SOM: [цифры]
```

## 🎯 Формат гипотезы

```
Если [изменение X],
то [метрика Y] вырастет на [Z%],
потому что верим что [причина]
```

**Пример:**
```
Если создадим отдельный лендинг для сегмента "Founders на Seed",
то CR вырастет с 1.5% до 3% (+100%),
потому что верим что фокус на одном сегменте
позволит говорить на их языке и показать релевантные кейсы
```

## 💰 Формулы метрик

### Conversion Rate (CR)
```
CR = (Конверсии / Визиты) × 100%

Норма:
- <1% — плохо
- 1-2% — средне
- 2-3% — хорошо
- >3% — отлично
```

### Customer Acquisition Cost (CAC)
```
CAC = Расходы на маркетинг / Новых клиентов

Норма: CAC ≤ LTV/3
```

### Lifetime Value (LTV)
```
LTV = ARPU × Lifetime

где:
ARPU = Средний доход на пользователя в месяц
Lifetime = 1 / Churn rate (в месяцах)

Пример:
ARPU = $50/мес
Churn = 5%/мес → Lifetime = 1/0.05 = 20 мес
LTV = $50 × 20 = $1000
```

### LTV/CAC
```
LTV/CAC = LTV / CAC

Норма:
- <1 — убыточно ❌
- 1-3 — окупается, но мало
- ≥3 — хорошо ✅
- ≥5 — отлично 🔥
```

### Payback Period
```
Payback = CAC / ARPU (в месяцах)

Норма: ≤6 месяцев
```

## 🔢 Формулы ICE/RICE приоритизации

### ICE Score
```
ICE = Impact × Confidence × Ease

где:
Impact: 1-10 (влияние на метрику)
Confidence: 1-10 (уверенность что сработает)
Ease: 1-10 (лёгкость внедрения)

Норма: ICE ≥50 → в работу
```

### RICE Score
```
RICE = (Reach × Impact × Confidence) / Effort

где:
Reach: сколько клиентов затронет
Impact: 1-3 (минимальное-массовое-максимальное)
Confidence: 0-100%
Effort: человеко-месяцы

Норма: RICE ≥10 → приоритет высокий
```

## 🎯 Команды для промптов (Copy-Paste)

### Промпт #1: Оценка рисков
```
Оцени Top-5 критических рисков для продукта:
[описание продукта, сегмент, бизнес-модель]

Используй категории: Рынок, Сегмент, Ценность,
Юнит-экономика, Каналы, Операционные

Для каждого риска укажи:
- P (вероятность 0-100%)
- I (последствия 1-10)
- P×I (приоритет)
- Как проверить (интервью/тест/MVP)
```

### Промпт #2: B2C-сегментация
```
Сгенерируй 5 привлекательных B2C-сегментов для продукта:
[описание продукта]

Для каждого сегмента укажи:
- Core Job (конкретная работа)
- Big Job (эмоциональная цель)
- Контекст и критерии
- Точка А → Б (эмоции)
- TAM/SAM/SOM
- Почему привлекателен
```

### Промпт #3: B2B-сегментация
```
Сгенерируй 5 привлекательных B2B-сегментов для продукта:
[описание продукта]

КРИТИЧНО: Выдели личные работы ЛПР (страх, амбиции, KPI)!

Для каждого сегмента укажи:
- Работы компании
- Личные работы ЛПР ← акцент!
- Core Job и Big Job
- TAM/SAM/SOM
```

### Промпт #4: Граф работ
```
Построй детальный граф работ для сегмента:
[описание сегмента и Core Job]

Для каждой работы укажи:
- Триггер
- Точка А (эмоции, контекст)
- Точка Б (результат, эмоции)
- Критерии успеха
- Сила проблемы (0-10/10)

Выдели критические разрывы (≥8/10)
```

### Промпт #5: Текст лендинга
```
Создай полный текст лендинга для сегмента:
[описание сегмента, Core/Big Jobs, инсайты из интервью]

Структура:
- Oneliner (Core Job)
- Hero (Big Job + ценность)
- Aha-момент
- Ценности (как выполняем работу)
- "Узнаёшь себя?" (триггеры, эмоции А)
- Как выполнишь работу (микро-джобы)
- Точка Б (эмоции после)
- Барьеры (снижаем тревоги)
- Конкуренты (почему мы лучше)

Язык: эмоциональный, цитаты из интервью!
```

### Промпт #6: Рекрут респондентов
```
Найди каналы для рекрута респондентов:
[описание продукта, сегмент, критерии рекрута]

Критерии:
- УЖЕ ПЛАТИЛИ за решение этой работы
- [другие критерии]

Выдай:
- 9 каналов (LinkedIn, Telegram, Панели, База, Нетворк...)
- Для каждого: почему эффективен, кого искать
- Формат сообщений
```

## 🔄 Формат описания Точки А → Б

### Точка А (текущее состояние)
```
Эмоции: [страх/фрустрация/тревога/стресс]
Контекст: [время, место, обстоятельства]
Ограничения: [дедлайн, бюджет, ресурсы]
Что только что сделал: [контекст триггера]
```

### Триггер
```
Событие: [что случилось]
Когда: [время, момент]
Почему запустило: [связь с Big Job]
```

### Точка Б (желаемое состояние)
```
Эмоции: [облегчение/уверенность/радость/спокойствие]
Результат: [что будет сделано]
Критерии: [как поймёт что достиг]
```

**Критично:** В точке А человек ПРЕДСТАВЛЯЕТ как будет чувствовать себя в точке Б!

## 🎯 Шаблон для Switch-интервью

### Вступление
```
"Спасибо что согласились! Это не продажа, я изучаю
как люди [работа]. Буду записывать для анализа, окей?"
```

### Warm-up
```
"Расскажите немного о себе, чем занимаетесь?"
```

### Найти Switch
```
"Расскажите про последний раз когда вы
[начали использовать / купили / переключились на] [продукт]?"
```

### Копай вглубь
```
"А что дальше?" ← спрашивай после КАЖДОГО ответа
"Почему именно это?" ← копай "Почему?" 5 раз
"Что ещё пробовали?"
"Что пугало?"
"Что помогло принять решение?"
```

### Силы
```
Push: "Что НЕ нравилось в старом?"
Pull: "Чего ожидали от нового?"
Anxiety: "Что пугало?"
Habit: "Что удерживало у старого?"
```

### Закрытие
```
"Спасибо огромное! Можете порекомендовать
кого-то ещё для интервью?" ← Снежный ком!
```

## 💡 6 механик создания ценности (команды)

### 1. Убить работу
```
Вопрос: Можно ли автоматизировать так,
чтобы клиент НЕ делал эту работу вообще?

Пример: Автокоробка → не переключать передачи
```

### 2. Починить проблему
```
Вопрос: Есть ли очевидный разрыв (сила ≥8/10),
который мешает выполнить работу?

Пример: Uber → найти такси за 2 минуты
```

### 3. Снять с человека
```
Вопрос: Можно ли делегировать работу
продукту или сервису?

Пример: Uber Eats → не готовить
```

### 4. Больше работ одним решением
```
Вопрос: Какие работы идут подряд
в критической последовательности?

Пример: iPhone = телефон+камера+навигатор
```

### 5. Выйти на следующую
```
Вопрос: Какая работа идёт ПОСЛЕ текущей
в графе работ?

Пример: Booking → отель → билеты → такси
```

### 6. Выйти на предыдущую ⚠️
```
Вопрос: Какая работа идёт ПЕРЕД текущей?
Это узкое место?

Пример: Uber → доехать → (предыдущая) заказать еду

⚠️ Часто даёт БОЛЬШЕ роста чем следующая!
```

## 🏢 B2B: Работы ЛПР (формат)

```
Работы компании:
- Увеличить прибыль на [X%]
- Снизить расходы на [Y руб]
- Увеличить производительность на [Z%]

Личные работы ЛПР (критично!):
Страх:
- Не потерять статус
- Не быть уволенным
- Не выглядеть некомпетентным

Амбиции:
- Получить повышение
- Получить признание
- Увеличить бонус

KPI:
- Выполнить личную метрику [X]
- Показать результаты до [дата]

⚠️ Личные работы часто ВАЖНЕЕ работ компании!
```

## 📊 Оценка силы проблемы (0-10)

```
0-3   → Не критично (можно игнорировать)
4-5   → Заметно (держим в бэклоге)
6-7   → Болезненно (планируем решать)
8-9   → Критично (решаем в приоритете)
10/10 → Блокер (решаем СРОЧНО!)
```

## 💰 ROI-формулы (для B2B)

### Экономия времени
```
ROI = (Часов экономии в месяц × Стоимость часа × 12 мес) / Цена продукта

Пример:
10 часов/мес × $100/час × 12 = $12000/год
Цена продукта: $1000/год
ROI = 1200% или 12:1
```

### Экономия денег
```
ROI = (Экономия в год / Цена продукта) × 100%

Пример:
Экономия: $50000/год
Цена: $10000/год
ROI = 500% или 5:1
```

### Рост выручки
```
ROI = (Доп. выручка в год / Цена продукта) × 100%

Пример:
Доп. выручка: $100000/год
Цена: $20000/год
ROI = 500% или 5:1
```

**Норма для B2B:** ROI ≥300% (3:1) для уверенной продажи

## 🔗 Быстрые команды

### Запустить новый продукт
```bash
1. Промпт #1 (RAT)
2. Промпт #2/3 (Сегментация)
3. Промпт #4 (Граф работ)
4. Промпт #6 (Рекрут)
5. 5-10 Switch-интервью
6. Промпт #5 (Лендинг)
7. Запуск + трафик
```

### Оптимизировать CR
```bash
1. Промпт #4 (Граф → разрывы)
2. Промпт #6 (Рекрут)
3. 5-10 Switch (почему не конвертит)
4. Механика #2 (Фокус на сегменте)
5. Промпт #5 (Новый лендинг)
6. A/B-тест
```

### Найти сегмент
```bash
1. Промпт #2/3 (5 сегментов)
2. ICE-приоритизация
3. Промпт #6 (Рекрут топ-2)
4. 5-10 Switch (валидация)
5. Выбор топ-1
```

## 📋 Критические напоминания

### ⚠️ При работе с сегментами
```
✅ По работам, НЕ по демографии!
✅ Разные работы = разные сегменты = разные продукты
✅ Выбирай ОДИН сегмент за раз
```

### ⚠️ При B2B
```
✅ Личные работы ЛПР > работы компании!
✅ Страх, амбиции, KPI ЛПР — обязательно в лендинге
✅ ROI в цифрах (сколько заработает/сэкономит)
```

### ⚠️ При интервью
```
✅ Только последний эпизод (НЕ общие мнения!)
✅ Факты, НЕ гипотезы
✅ УЖЕ ПЛАТИЛИ за решение
✅ "А что дальше?" после каждого ответа
```

### ⚠️ При валидации
```
✅ Промпты = гипотезы, интервью = факты
✅ 5-10 интервью минимум
✅ Каждое слово на вес золота!
✅ CR ≥2% = валидировано
```
