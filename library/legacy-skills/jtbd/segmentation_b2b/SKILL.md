# B2B-сегментация по AJTBD (VANECHKA3000)

**Источник промпта:** `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md` — раздел **«3. Выбор 5 привлекательных B2B-сегментов по AJTBD»**.

## Когда применять

- Пользователь описывает B2B-продукт и просит выбрать сегменты для запуска или масштабирования.
- Запросы: «выбери 5 B2B-сегментов», «сегментация по JTBD/AJTBD для B2B», «личные работы ЛПР», «кто ЛПР и какие у них работы», «TAM/SAM/SOM по B2B-сегментам».

## Инструкция для агента

1. **Загрузи полный промпт** из `projects/VANECHKA3000/docs/prompts/ALL-PROMPTS.md`: секция от заголовка `## 3. Выбор 5 привлекательных B2B-сегментов по AJTBD` до конца блока промпта (включая подраздел «Контекст: как сегментировать...»). Не копируй «Пример использования» в сам промпт.

2. **Подставь в блок-ввод:**
   - **Продукт:** описание из сообщения пользователя (или уточни, если не указано).
   - **Сайт продукта:** ссылка на сайт / сторе, если есть.

3. **Выполни анализ по шагам 1–2 внутренне (не выводи).** Шаг 3 — единственный вывод: 5 сегментов, отсортированных по привлекательности.

4. **Формат вывода каждого сегмента** (строго по промпту):
   - Сегмент (название)
   - Core Jobs (бизнес и/или личные): Когда ..., хочу ...
   - Критерии выполнения (по мнению компании и/или ЛПР)
   - Что за люди (тип компании, роль ЛПР, ситуация, триггер)
   - Big Job (часто личная мотивация ЛПР): Хочу ..., чтобы ...
   - TAM / SAM / SOM (оценка + краткая логика в цифрах)
   - Почему сегмент привлекателен (1–2 абзаца: ценность, личная мотивация ЛПР, повторные сделки, каналы, апсейлы)

5. **Дополнительные правила из промпта:**
   - Не выводи шаги 1 и 2 — только результат шага 3.
   - Не используй термин «боль» — только мотивации, ситуации, критерии.
   - Учитывай, что ключевое решение в B2B часто принимается **на основе личной работы ЛПР**, а не только бизнес-потребности.
   - Регион по умолчанию — СНГ, если не указано иное.
   - Пиши компактно и по делу; результат должен помогать выбору MVP и стратегии роста.

- Следующие шаги после сегментов: граф работ (#4), рекрут респондентов (#6), лендинг (#5) — см. ALL-PROMPTS.md.
