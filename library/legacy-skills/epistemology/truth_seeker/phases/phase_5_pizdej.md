# Phase 5: Pizdej Self-Check

## Цель
Критическая самопроверка всего анализа по протоколу `core-pizdej`. Последний шанс поймать системные ошибки перед финальным отчётом.

## Алгоритм

### Чеклист самокритики

- [ ] **Context Rot:** Не потерялся ли контекст между фазами? Все ли sub-claims имеют verdict?
- [ ] **Что НЕ проверили:** Остались ли sub-claims без evidence? Какие источники не нашли?
- [ ] **Самое слабое звено:** Какой вывод держится на МИНИМАЛЬНОМ evidence? Пометить.
- [ ] **Persona / LLM Systemic Bias (Эхо-камера):** Не повторяется ли один и тот же вывод во всех линзах подозрительно единогласно? Если все линзы дают TRUE с confidence >0.8 — задуматься: это действительно очевидно или это слепое пятно модели?
- [ ] **Epistemic Vulnerability:** Не полагались ли мы исключительно на топ ссылок из поиска? Проверены ли утверждения через прагматику и когерентность, а не только через "так пишут в интернете"?
- [ ] **Source Coverage:** Есть ли по каждому EMPIRICAL claim минимум 2 типа источников? Есть ли и support, и refute evidence?
- [ ] **Blast Radius:** Не упустили ли смежные области? Если claim про медицину — проверена ли юридическая сторона? Если про технологию — проверен ли бизнес-аспект?
- [ ] **Калибровка Confidence:** Обоснованы ли числа? Нет ли подозрительно ровных значений (0.90, 0.80)?
- [ ] **Контрпримеры:** Есть ли хотя бы 1 контрпример по каждому sub-claim? Если нет — это RED FLAG.
- [ ] **Time sensitivity:** Не устарели ли источники? Соответствует ли time_scope claim?

### Шаг: Оценка серьёзности

| Находка | Действие |
|---------|---------|
| Нет verdict для sub-claim | ⛔ RETURN TO Phase 2 |
| Все линзы единогласны без разнообразия evidence | 🟡 Пометить в отчёте + добавить предупреждение |
| Нет контрпримеров | 🟡 Пометить + Skeptic дополнительный поиск |
| Устаревшие источники | 🟡 Пометить + дополнительный search |
| Source Coverage < 2 типов | 🟡 Пометить в Limitations |

**Макс 1 возврат к Phase 2.** Если после возврата всё ещё есть дыры — фиксировать в отчёте как Limitations.
