# Phase 0: Intake

## Цель
Зафиксировать утверждение как формальный Claim Object и определить параметры анализа.

## Алгоритм

### Шаг 1: Принять утверждение
Зафиксировать исходный текст пользователя без изменений.

### Шаг 2: Сформировать Claim Object

```
Claim:
  id: C0
  text: "[точная формулировка утверждения]"
  domain: [science | finance | tech | social | medical | legal | philosophy | auto]
  time_scope: "[as-of date, default: сегодня]"
  location_scope: "[если важен географический контекст]"
  risk_level: [normal | high]
```

**Авто-определение domain** по ключевым словам:
- finance/инвестиции/криптовалюта/акции → `finance` + `risk_level: high`
- лечение/здоровье/лекарства/диагноз → `medical` + `risk_level: high`
- Закон/суд/право/штраф/регулятор → `legal` + `risk_level: high`

### Шаг 3: Определить режим (mode)
- Если пользователь явно просит быстрый ответ → `quick`
- По умолчанию → `deep`

### Шаг 4: Уточнения (опционально)
Задать 1-2 уточняющих вопроса **только если**:
- Утверждение фундаментально двусмысленно
- Не ясен временной контекст

**НЕ задавать вопросов**, если claim однозначен — сразу переходить к Phase 1.

## Output
Заполненный Claim Object → передать в Phase 1.
