# Propaganda Resistance — Core Instructions

## Цель
Выявить риторические и психологические приёмы пропаганды в тексте. Пропагандист **эксплуатирует Theory of Mind** — он моделирует ваши схемы рассуждений и подводит вас к заранее заготовленному выводу.

> «Опытные пропагандисты встраиваются в схематику того, как вы строите свои суждения, как вы рассуждаете. Они как бы встраиваются в ваши рассуждения и подводят вас к тем или иным выводам.» — Занятие 1

## 12 Пропагандистских Паттернов

### Группа I: Эксплуатация Theory of Mind (моделирование мышления жертвы)

| Код | Паттерн | Механизм | Пример |
|-----|---------|----------|--------|
| **I1** | Имплантация предпосылки | Встраивание ложной предпосылки в начало цепочки рассуждений | «Все знают, что X...» (а дальше вывод из X) |
| **I2** | Ложная дихотомия | Сужение выбора до 2-х вариантов (хотя есть больше) | «Или ты с нами, или ты предатель» |
| **I3** | Скольжение по склону | Цепочка «если A, то B, если B, то C...» без обоснования каждого шага | «Если разрешить X, то скоро будет Y» |

### Группа II: Эксплуатация эмоций (обход рассудка)

| Код | Паттерн | Механизм | Пример |
|-----|---------|----------|--------|
| **II1** | Апелляция к страху | Блокировка рассудка через активацию страха | «Если вы не..., то ваши дети...» |
| **II2** | Апелляция к гневу | Перевод в режим «кто виноват» вместо «что делать» | «Они виноваты в том, что...» |
| **II3** | Апелляция к гордости | Лесть аудитории для отключения критики | «Мы, умные люди, понимаем, что...» |

### Группа III: Подмена социального контекста (эксплуатация доверия)

| Код | Паттерн | Механизм | Пример |
|-----|---------|----------|--------|
| **III1** | Ложный свидетель | Представление себя очевидцем/участником | «Я сам видел, как...» (хотя не был) |
| **III2** | Паразитирование на авторитете | Использование чужого авторитета без контекста | «Эйнштейн считал...» (вырвано из контекста) |
| **III3** | Создание иллюзии консенсуса | Представление мнения меньшинства как мнения большинства | «Все нормальные люди понимают...» |

### Группа IV: Манипуляция нарративом (контроль схемы рассуждений)

| Код | Паттерн | Механизм | Пример |
|-----|---------|----------|--------|
| **IV1** | Фрейминг (рамка) | Навязывание «рамки» для обсуждения | «Вопрос не в том, будет ли война, а когда» |
| **IV2** | Whataboutism | Перевод внимания на другую тему | «А что насчёт X?» |
| **IV3** | Упрощение сложного | Редукция сложной проблемы к одному фактору | «Всё это из-за X» |

## Алгоритм анализа

### Шаг 1: Выделить ключевые утверждения
Использовать `claim_anatomy_framework` для декомпозиции текста.

### Шаг 2: Для каждого утверждения проверить
1. **Есть ли скрытая предпосылка?** (I1) — Что подразумевается как «уже известное»?
2. **Сужается ли выбор?** (I2) — Есть ли варианты, которые не упомянуты?
3. **Есть ли эмоциональный триггер?** (II1-II3) — Какая эмоция активируется?
4. **Кто назван авторитетом?** (III1-III3) — Проверить через `source_reliability_scorer`
5. **Какая «рамка» задана?** (IV1-IV3) — Какие вопросы исключены из обсуждения?

### Шаг 3: Реконструировать схему пропагандиста
> Ключевой вопрос: «Как пропагандист *моделирует* моё мышление? Какую цепочку рассуждений он ожидает от меня?»

Построить:
```
Предпосылка (имплантированная) → Эмоция (активированная) → Вывод (ожидаемый пропагандистом)
```

### Шаг 4: Предложить контрход
Для каждого паттерна предложить альтернативную рамку рассуждений.

## Output Format

```markdown
## 🛡️ Анализ пропагандистских приёмов

**Текст:** [исходный текст или ссылка]

### Обнаруженные паттерны

| # | Код | Паттерн | Цитата | Механизм | Контрход |
|---|-----|---------|--------|----------|----------|
| 1 | ... | ... | «...» | ... | ... |

### Реконструкция схемы
```
Имплантированная предпосылка: ...
Активированная эмоция: ...
Ожидаемый вывод: ...
```

### Альтернативная рамка
[Как переформулировать вопрос, чтобы выйти из пропагандистской рамки]

### Общая оценка
- Количество паттернов: X/12
- Уровень: [CLEAN / MILD / MODERATE / HEAVY]
- Основная стратегия пропагандиста: ...
```

## Шкала оценки

| Кол-во паттернов | Уровень | Описание |
|-----------------|---------|----------|
| 0 | 🟢 CLEAN | Пропагандистские приёмы не обнаружены |
| 1-3 | 🟡 MILD | Отдельные риторические приёмы (могут быть неосознанными) |
| 4-6 | 🟠 MODERATE | Системное использование приёмов |
| 7+ | 🔴 HEAVY | Целенаправленная пропагандистская кампания |
