# Source Reliability Scorer — Core Instructions

## Цель
Оценить надёжность источника информации по шкале от 0 до 10 с учётом 4 измерений.

> Этот скилл работает в парадигме «Эмет» (надёжность/опора) из `etymology_of_truth_framework`. Критерий A (Track Record) напрямую реализует Эмет-проверку.

## Алгоритм

### Шаг 1: Идентификация источника

Определить:
- **Тип источника:** Академический / Журналистский / Экспертный / Свидетельский / Анонимный / AI-сгенерированный
- **Автор/организация:** Кто стоит за утверждением?
- **Дата публикации:** Когда?

### Шаг 2: Оценка по 4 критериям

| Критерий | Описание | Шкала |
|----------|----------|-------|
| **A. Авторский Track Record** | Есть ли у автора экспертиза в данной области? Есть ли публикации, рецензии? | 0-10 |
| **B. Перекрёстная проверка** | Есть ли peer review, факт-чекинг, независимое подтверждение? | 0-10 |
| **C. Тип предлагаемого знания** | A priori (определение, логика) или a posteriori (эмпирические данные)? Соответствует ли тип знания типу утверждения? | 0-10 |
| **D. Поправка на ограничения** | Учтены ли 3 ограничения: индивидуальное (cognitive bias), культурно-историческое (контекст эпохи), языковое (перевод, терминология)? | 0-10 |

### Шаг 3: Расчёт итогового балла

```
Итого = (A × 0.3) + (B × 0.3) + (C × 0.2) + (D × 0.2)
```

Веса отражают приоритет: Track Record и перекрёстная проверка важнее всего.

### Шаг 4: Классификация

| Балл | Уровень | Рекомендация |
|------|---------|-------------|
| 8-10 | 🟢 HIGH | Источник надёжен, можно использовать |
| 5-7 | 🟡 MEDIUM | Нужна дополнительная проверка |
| 3-4 | 🟠 LOW | Использовать с осторожностью, искать альтернативы |
| 0-2 | 🔴 UNRELIABLE | Не использовать как основу для выводов |

## Детали оценки каждого критерия

### A. Авторский Track Record (вес 0.3)

| Балл | Описание |
|------|----------|
| 9-10 | Признанный эксперт с десятками публикаций в данной области |
| 7-8 | Специалист с публикациями в смежной области |
| 5-6 | Журналист/блогер с хорошей репутацией, но не эксперт |
| 3-4 | Автор без верифицируемых credentials |
| 1-2 | Анонимный источник / AI-контент без маркировки |
| 0 | Источник с доказанной историей дезинформации |

### B. Перекрёстная проверка (вес 0.3)

| Балл | Описание |
|------|----------|
| 9-10 | Peer-reviewed публикация + мета-анализы |
| 7-8 | Подтверждено 3+ независимыми источниками |
| 5-6 | Подтверждено 1-2 источниками |
| 3-4 | Только один источник, нет независимого подтверждения |
| 1-2 | Противоречит другим источникам |
| 0 | Активно опровергнуто мета-анализами |

### C. Тип знания (вес 0.2)

| Балл | Описание |
|------|----------|
| 9-10 | Тип знания соответствует утверждению (a posteriori для фактов, a priori для определений) |
| 5-6 | Частичное соответствие |
| 1-3 | Несоответствие: эмпирическое утверждение обосновывается только логикой, или наоборот |

### D. Поправка на ограничения (вес 0.2)

Проверить наличие трёх ограничений (из `absolute_vs_relative_truth_framework`):

- **Индивидуальное:** Есть ли у автора конфликт интересов? Cognitive bias?
- **Культурно-историческое:** Актуальны ли данные? Не устарели?
- **Языковое:** Есть ли проблемы перевода, терминологические подмены?

| Балл | Описание |
|------|----------|
| 9-10 | Все 3 ограничения учтены или неприменимы |
| 5-6 | 1 ограничение не учтено |
| 1-3 | 2-3 ограничения не учтены |

## Output Format

```markdown
## 📊 Оценка надёжности источника

**Источник:** [название/URL/автор]
**Тип:** [Академический / Журналистский / Экспертный / Свидетельский / Анонимный]
**Дата:** [дата публикации]

### Оценка по критериям

| Критерий | Балл | Обоснование |
|----------|------|------------|
| A. Track Record | X/10 | ... |
| B. Перекрёстная проверка | X/10 | ... |
| C. Тип знания | X/10 | ... |
| D. Ограничения | X/10 | ... |

### Итого
**Балл:** X.X / 10
**Уровень:** [HIGH / MEDIUM / LOW / UNRELIABLE]
**Рекомендация:** ...

### Обнаруженные риски
- ...
```

## Примеры

### Пример: Статья в Nature о вакцинах
- A: 10/10 (peer-reviewed, авторы с h-index >50)
- B: 10/10 (мета-анализ 200+ исследований)
- C: 10/10 (эмпирическое утверждение → эмпирические данные)
- D: 9/10 (все ограничения учтены)
- **Итого: 9.8 / 10 — HIGH**

### Пример: Пост в Telegram-канале без автора
- A: 1/10 (анонимный)
- B: 2/10 (нет подтверждений)
- C: 3/10 (эмпирическое утверждение без данных)
- D: 2/10 (ограничения не учтены)
- **Итого: 2.0 / 10 — UNRELIABLE**
