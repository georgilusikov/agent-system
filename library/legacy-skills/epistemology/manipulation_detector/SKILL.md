# 🛡️ Manipulation Detector

**Purpose:** Выявление эпистемологических манипуляций — приёмов, которые эксплуатируют когнитивные уязвимости и подменяют знание иллюзией знания. Основан на анализе типовых подмен из курса «Истина».

**When to use:**
- При анализе аргументации (публичные дискуссии, переговоры, СМИ)
- Когда чувствуется «что-то не так» с аргументом, но непонятно что
- Для self-check: проверка собственных рассуждений на манипулятивные паттерны
- При обучении критическому мышлению

**Output:** Список обнаруженных манипулятивных паттернов с объяснением механизма и рекомендациями по защите.
