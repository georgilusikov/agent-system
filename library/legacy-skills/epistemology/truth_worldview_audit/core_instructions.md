# Truth Worldview Audit — Core Instructions

## Цель
Оценить, какое место «истина» занимает в мировоззрении субъекта (человека, организации, текста). Определить уровень «эпистемологической зрелости».

> «Истина — это не только теория. Это идея, ценность и добродетель. "Ходить в истине" — это практическое знание.» — Занятие 5

## Три измерения

### Измерение 1: Истина как ИДЕЯ (когнитивный уровень)

| Балл | Описание |
|------|----------|
| 0 | **Отрицание:** «Истины не существует, всё относительно» (крайний релятивизм) |
| 1 | **Скептицизм:** «Истина может существовать, но мы не можем её познать» |
| 2 | **Признание:** «Истина существует, и мы можем к ней приближаться» |
| 3 | **Осознание сложности:** «Истина существует, но познание имеет ограничения. Я понимаю разницу между теориями истины» |

**Вопросы-индикаторы:**
- Использует ли субъект фразы «это правда» vs «мне кажется, что...»?
- Различает ли субъект факты и мнения?
- Допускает ли возможность собственной ошибки?

### Измерение 2: Истина как ЦЕННОСТЬ (аксиологический уровень)

| Балл | Описание |
|------|----------|
| 0 | **Инструментализм:** Истина не является ценностью; используется только когда выгодна |
| 1 | **Декларативное уважение:** «Истина важна» (на словах), но решения принимаются по другим критериям |
| 2 | **Практическое уважение:** Истина влияет на принятие решений, даже когда это неудобно |
| 3 | **Приоритет:** Истина — высшая ценность, ради которой субъект готов менять свою позицию |

**Вопросы-индикаторы:**
- Меняет ли субъект мнение при получении новых данных?
- Ищет ли подтверждение своей позиции (confirmation bias) или реальную проверку?
- Готов ли публично признать ошибку?

### Измерение 3: Истина как ДОБРОДЕТЕЛЬ (праксеологический уровень)

| Балл | Описание |
|------|----------|
| 0 | **Нет практики:** Субъект не упражняется в объективности |
| 1 | **Спорадическая:** Иногда проверяет свои убеждения, но нет системы |
| 2 | **Регулярная:** Есть привычка проверять источники, искать альтернативные мнения |
| 3 | **Пайдейя:** Систематически «упражняется в объективности» (по Платону): отделяет «я-позицию» от «мир-позиции», активно ищет опровержения своих убеждений |

**Вопросы-индикаторы:**
- Может ли субъект изложить позицию оппонента *лучше, чем оппонент*?
- Использует ли практику steelmanning (усиление аргумента оппонента)?
- Есть ли регулярная рефлексия над собственными когнитивными биасами?

## Алгоритм аудита

### Шаг 1: Сбор данных
Проанализировать тексты / высказывания / решения субъекта по трём измерениям.

### Шаг 2: Оценка по шкале 0-3 для каждого измерения

### Шаг 3: Построение профиля

```
Идея:      [0-3] ████████░░
Ценность:  [0-3] ██████░░░░
Добродетель:[0-3] ████░░░░░░
```

### Шаг 4: Определение общего уровня

| Сумма (0-9) | Уровень | Описание |
|-------------|---------|----------|
| 0-2 | 🔴 Пре-эпистемологический | Не задумывается об истине как категории |
| 3-5 | 🟡 Начинающий | Признаёт важность истины, но не практикует |
| 6-7 | 🟢 Практикующий | Активно работает с истиной на всех уровнях |
| 8-9 | 🔵 Мастер (Пайдейя) | Систематическая практика объективности |

### Шаг 5: Рекомендации
Для каждого измерения с баллом < 2 предложить конкретные упражнения.

## Пример: Типичный пользователь соцсетей

| Измерение | Балл | Обоснование |
|-----------|------|-------------|
| Идея | 1/3 | Использует «правда» и «ложь», но не различает теории истины |
| Ценность | 1/3 | Декларирует важность правды, но ищет подтверждение своей позиции |
| Добродетель | 0/3 | Не практикует проверку источников, не может изложить позицию оппонента |

**Итого: 2/9 — Пре-эпистемологический**

**Рекомендации:**
1. Начать с `objectivity_practitioner` — упражнение в отделении «я» от «мира»
2. Использовать `source_reliability_scorer` при чтении новостей
3. Практиковать steelmanning: 1 раз в неделю изложить позицию оппонента максимально сильно
