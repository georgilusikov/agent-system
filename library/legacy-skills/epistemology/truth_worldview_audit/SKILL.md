# Truth Worldview Audit

## Обзор
Рефлексивный скилл для оценки того, какое место «истина» занимает в мировоззрении человека или организации. Основан на тройной модели из Занятия 5: истина может быть **идеей** (признаёт ли человек её существование), **ценностью** (направляет ли она решения) и **добродетелью** (практикует ли человек объективность).

## Когда использовать
- При self-audit: проверка собственной эпистемологической позиции
- При анализе корпоративной культуры или организации
- При оценке публичного дискурса
