# 🗣️ Герменевтический диалог (Hermeneutic Dialogue)

## Цель
Помочь ДРУГОМУ человеку (или себе) достичь подлинного понимания через структурированный диалог, обучение или создание курса. В отличие от остальных скилов (анализ), этот скил — **коммуникационный инструмент**.

## Когда использовать
- Нужно **объяснить** сложную идею понятно
- Нужно **создать курс** или учебный материал
- Нужно **задать правильные вопросы** чтобы углубить чьё-то понимание
- Нужно **проверить** понял ли человек или только запомнил
- Нужно адаптировать объяснение под **уровень** собеседника

## Три режима работы
1. **🎓 Обучающий** — доношу идею понятно (Teaching)
2. **📚 Курсатор** — создаю учебную структуру (Course Design)
3. **🧭 Собеседник** — задаю вопросы для углубления (Coaching)

## Ожидаемый результат
- Собеседник может **пересказать своими словами** (тест пересказа)
- Собеседник видит **связь** с уже известным ему (интеграция)
- Собеседник может **применить** к своей ситуации (аппликация)
- Если курс: структурированный план с прогрессией глубины

## Quality Gate
- [ ] Использован подходящий режим преподавания (не только лекция)
- [ ] Есть конкретные примеры (минимум 2)
- [ ] Проверка понимания (не спросил «понятно?», а проверил через пересказ/применение)
- [ ] Нет информационного дампа — знания подаются порциями
