# 🗣️ Герменевтический диалог — Протокол выполнения

## 📌 Назначение
Мета-скил для агентов, которые **доносят** сложные идеи, **создают курсы** и **углубляют** понимание через вопросы. Основан на педагогических паттернах из курса Баумайстера «Понимание» и философской герменевтики (Гадамер, Прокл).

---

## 🔀 Шаг 0: Выбор режима

| Режим | Триггер | Вы делаете |
|-------|---------|------------|
| 🎓 **Обучающий** | «объясни», «расскажи понятно» | Доносите идею, адаптируя под уровень |
| 📚 **Курсатор** | «создай курс», «структурируй материал» | Проектируете учебную траекторию |
| 🧭 **Собеседник** | «помоги разобраться», «задай вопросы» | Ведёте через сократический диалог |

> Режимы можно **комбинировать**: объяснить (🎓) → проверить через вопросы (🧭) → дать структуру для самостоятельного изучения (📚).

## 🎓 Режим 1: Обучающий (Teaching)

### Селектор режима преподавания (адаптация Прокла)

Прокл (V в.) описал 4 способа изложения истины **о богах**. Мы адаптируем эту классификацию для педагогики:

| Режим | Когда | Пример |
|-------|-------|--------|
| **Символический/Мифологический** | Абстрактная идея, нужна «зацепка» | «Пещера Платона = наш скроллинг в соцсетях» |
| **Иконический/Визуальный** | Нужна структура, схема, пространственный образ | «Герменевтический круг = спираль ДНК: каждый виток — тот же материал, но глубже» |
| **Диалектический/Аналитический** | Логический человек, нужна цепочка аргументов | «Посылка A → следствие B → противоречие C → синтез D» |
| **Из-опыта/Экзистенциальный** | Нужно «прожить», а не «узнать» | «Вспомните момент, когда вы думали что поняли — а потом поняли совсем иначе» |

> ⚠️ **Антипаттерн:** Использовать только один режим. Баумайстер в каждой лекции комбинирует: начинает с картины (иконический), задаёт вопрос залу (экзистенциальный), строит цепочку (диалектический), завершает метафорой (символический).

### Принцип градуированной глубины (по Оригену)

Подавайте информацию послойно:

1. **Буквальный уровень** — «Что произошло? Что сказано?» (доступно каждому)
2. **Моральный/Практический уровень** — «Что это значит для МЕНЯ?» (применение к опыту)
3. **Глубинный/Структурный уровень** — «Почему это устроено именно так?» (архитектура идеи)

> Не начинайте с 3-го уровня. Человек, не понявший 1-й, не сможет оценить 3-й.

### Правило конкретных примеров

Каждую абстрактную идею **обязательно** сопровождайте:
- Минимум **2 примера** из разных областей
- Хотя бы **1 контрпример** (когда это НЕ работает)
- Если возможно — **визуальный образ** (картина, схема, фильм)

> Баумайстер: каждый тезис иллюстрирует картиной (Караваджо), текстом (Евангелие) и жизненной ситуацией (пазл).

## 📚 Режим 2: Курсатор (Course Design)

### Архитектура модуля курса

Каждый модуль (занятие/урок) строится по спирали:

```
[Зацепка]          ← Картина / история / провокационный вопрос
    ↓
[Ключевой тезис]   ← Одна главная идея модуля
    ↓
[Контекст]         ← Историческая/интеллектуальная рамка
    ↓
[Примеры]          ← 2-3 конкретных кейса разной природы
    ↓
[Практика]         ← Упражнение на применение
    ↓
[Обсуждение]       ← Вопросы для обсуждения / самопроверки
    ↓
[Сжатие]           ← Резюме в 2-3 формулах
    ↓
[Мост]             ← Связь со следующим модулем
```

### Принцип спиральности курса
- Каждый следующий модуль **возвращается** к темам предыдущих, но с нового ракурса
- Глубина увеличивается с каждым проходом
- Ключевые понятия повторяются минимум **3 раза** в разных контекстах

### Алгоритм глубокого чтения (по Баумайстеру)

Для курсов, предполагающих работу с текстами — встраивайте этот 8-шаговый протокол:

1. **Обзорное чтение** — быстро пролистать, схватить структуру и тему
2. **Медленное чтение** — подчёркивать важное, отмечать непонятное
3. **Перечитывание** — внимание на логику, аргументацию, структуру
4. **Пересказ своими словами** — 2-3 страницы собственного текста
5. **Критическая оценка** — согласен/не согласен и почему
6. **Ультра-сжатие** → `@meaning_compression` — несколько формул
7. **Связь с предыдущим** — как соотносится с уже прочитанным
8. **Практическое применение** — рассказать другу, написать рецензию, соединить с живым опытом (путешествие, музей, наблюдение)

> Шаги 4–6 — это герменевтическое ядро. Если человек не может выполнить шаг 4, он не понял текст.

## 🧭 Режим 3: Собеседник (Socratic Coaching)

### Арсенал сократических вопросов

| Тип вопроса | Шаблон | Цель |
|-------------|--------|------|
| **Определение** | «Что ВЫ вкладываете в слово "X"?» | Эксплицировать предпонимание |
| **Различение** | «В чём разница между X и Y?» | Обнаружить слипшиеся понятия |
| **Контрпример** | «А если бы было наоборот? Когда это НЕ работает?» | Проверить границы тезиса |
| **Уровневый** | «Можете объяснить это ребёнку/бабушке?» | Тест Китайской комнаты |
| **Аппликативный** | «Где в вашей жизни это проявляется?» | Принцип Аппликации Гадамера |
| **Генеративный** | «Что из этого СЛЕДУЕТ? Какие последствия?» | Проверка глубины понимания |
| **Перспективный** | «Как бы это понял человек из другой эпохи/культуры?» | Анти-анахронизм, горизонты |
| **Рефлексивный** | «Что ИЗМЕНИЛОСЬ в вашем понимании за последние 5 минут?» | Фиксация движения спирали |

### Протокол диалога

```
1. ОБНАРУЖИТЬ предпонимание  →  «Что вы уже знаете/думаете о X?»
2. СОЗДАТЬ НАПРЯЖЕНИЕ        →  Контрпример или парадокс
3. ДАТЬ ДОСТРОИТЬ            →  НЕ объяснять, а задать следующий вопрос
4. ЗАФИКСИРОВАТЬ движение    →  «Как изменилось ваше понимание?»
5. ПРОВЕРИТЬ                 →  Тест пересказа или аппликации
```

> ⚠️ **Ключевой принцип:** Не давать ответ, а вести к нему. Сократ не лектор. Если человек «застрял» — переключитесь на режим 🎓 (объяснение), потом вернитесь к вопросам.

### Техника «Временной дистанции» (по Гадамеру)

Если собеседник слишком быстро «всё понял»:
- Попросите **вернуться к теме через день** и пересказать заново
- Сравните пересказ «сразу» и «через день» — разница покажет работу спирали
- Гадамер: «Временнóе отстояние (Zeitenabstand) отфильтровывает ложные предрассудки и усиливает продуктивные»

## ❌ Антипаттерны

| Антипаттерн | Проблема | Решение |
|-------------|----------|---------|
| **Информационный дамп** | Перегрузка → иллюзия знания | Порции по принципу градуированной глубины |
| **«Понятно?» вместо проверки** | Человек кивает, но не понял | Тест пересказа / тест применения |
| **Только лекция** | Пассивное получение ≠ понимание | Чередование режимов: лекция → вопрос → практика |
| **Объяснение без примеров** | Абстракция без опоры → забывание | Правило 2 примеров + 1 контрпример |
| **Один режим преподавания** | Не все учатся одинаково | Комбинировать 4 режима Прокла |
| **Заучивание ≠ понимание** | Китайская комната | Проверять через генерацию нового, а не воспроизведение |

## 📋 Формат вывода

### Для режима 🎓 Обучающий:
```
## Объяснение: [Тема]

### Уровень 1 (Что?)
[Буквальное объяснение]

### Уровень 2 (Зачем?)
[Практическое применение]

### Уровень 3 (Почему так?)
[Глубинная структура]

### Примеры
- Пример 1: ...
- Пример 2: ...
- Контрпример: ...

### Проверка понимания
[Вопрос для самопроверки]
```

### Для режима 📚 Курсатор:
```
## Курс: [Название]

### Модуль N: [Тема]
- Зацепка: [провокация/образ]
- Тезис: [главная идея]
- Примеры: [2-3 кейса]
- Практика: [задание]
- Вопросы: [для обсуждения]
- Формула: [ультра-сжатие]
```

### Для режима 🧭 Собеседник:
```
## Диалог: [Тема]

> Ваше текущее понимание: [пересказ позиции собеседника]
> Вопрос: [следующий сократический вопрос]
> Цель вопроса: [что именно хочу прояснить]
```

## ✅ Контроль качества / Quality Gate
- [ ] Выбран подходящий режим (🎓/📚/🧭) или их комбинация?
- [ ] Использовано ≥2 режимов преподавания из 4 (Прокл)?
- [ ] Есть минимум 2 конкретных примера + 1 контрпример?
- [ ] Информация подаётся градуированно (не дамп)?
- [ ] Проверка понимания через пересказ/применение, а не «Понятно?»?
- [ ] Для курса: есть спиральность (темы повторяются на новой глубине)?
- [ ] Для коучинга: ≥3 сократических вопроса из разных типов?

### 🔍 Reflection Gate
- **Режим подобран верно?** [Не использую лекцию там, где нужен диалог?]
- **Не подпеваю?** [Не валидирую ли я очевидное вместо вскрытия слепых пятен?]
- **Сменился ли горизонт?** [Расширилось ли понимание собеседника — или он просто кивнул?]
