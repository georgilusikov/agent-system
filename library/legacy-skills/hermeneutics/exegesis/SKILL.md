# 📜 Многоуровневая экзегеза (Multi-Level Exegesis)

**Purpose:** Раскрыть скрытые слои смысла текста через последовательную работу на разных уровнях интерпретации — от буквального до глубинного.

**When to use:**
- Работа с метафорическими, символическими, многослойными текстами
- Анализ притч, мифов, поэзии, религиозных текстов
- Поиск «второго дна» в деловых или политических текстах

**Output:** Многоуровневая карта смыслов текста с практическими выводами

**Gate Check:**
- Проработано ≥3 уровня интерпретации
- Каждый уровень содержит конкретные примеры из текста
- Есть практический вывод (уровень Moralis/Драш)
