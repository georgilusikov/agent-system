# 📦 Сжатие смыслов (Meaning Compression)

**Purpose:** Превратить объёмный текст в лаконичную, ёмкую формулу, интегрированную в существующую базу знаний.

**When to use:**
- После завершения работы с книгой, статьёй или модулем
- Для фиксации результатов анализа
- Для подготовки к пересказу или объяснению другому

**Output:** Многоуровневое резюме: развёрнутое → критическое → экстремально сжатое + интеграция

**Gate Check:**
- Есть развёрнутое резюме (ключевые идеи)
- Есть критическая оценка (не голый пересказ)
- Есть формула сжатия ≤3 предложения
- Есть связи с другими текстами/знаниями
