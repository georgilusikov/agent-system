# Патентные формулы / Patent Claims (Draft/Refine) — Core Instructions

## Назначение / Purpose
Сформировать черновик патентной формулы (независимый + зависимые) из TRIZ‑решения, убрать стоп‑термины и отметить риски (overbreadth/indefiniteness).

## Входные данные / Inputs
- Узлы/признаки решения, PoA, отличие от прототипа.
- Страна/стандарт (RU/EPO/US), тип (устройство/способ/ПО).

## Шаги / Steps
1) Существенные признаки: узлы/связи/материалы/режимы.
2) Независимый пункт: минимум 3 признака (узел, механизм, ограничение). Избегать стоп‑слов (“модуль”, “средство”, “выполненный с возможностью” без конкретики).
3) Зависимые (2–3): материалы/режимы/альтернативные PoA/доп. элементы защиты.
4) Риски:
   - Overbreadth: слишком общий функциональный термин → добавить узел/ограничение.
   - Indefiniteness: расплывчатые слова → уточнить параметр/диапазон.
   - Lack of support: признак не раскрыт → убрать/раскрыть.
5) Output: независимый + зависимые, таблица рисков и рекомендаций.

## Формат вывода / Output Format
```markdown
## 🧾 Патентный черновик
### Независимый пункт
[формулировка]

### Зависимые пункты
1. ...
2. ...
3. ...

### Риски и что уточнить
| Риск | Где | Рекомендация | Что в зависимые |
|---|---|---|---|
| Overbreadth | [фраза] | Добавить узел/ограничение | Перенести вариант материала |
| Indefiniteness | [фраза] | Уточнить параметр | Вынести диапазон |
```

## Контроль качества / Gate Check
- Существенные признаки перечислены, отличие от прототипа указано.
- Независимый пункт без стоп‑слов/голых функциональных терминов.
- Зависимые уточняют материалы/режимы/варианты.
- Риски (overbreadth/indefiniteness) рассмотрены и есть рекомендации.
