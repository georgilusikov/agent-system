# Gate Check for DND (Допустить Недопустимое)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| ФП сформулировано как "A и НЕ-A" для одного элемента | Да | ___ | ✅/❌ |
| Явно написан DND-факт ("допустим, что ... уже реализовано") | Да | ___ | ✅/❌ |
| Есть >=2 "вторичные выгоды чуда" | >=2 | ___ | ✅/❌ |
| Есть >=1 приземляющая гипотеза (ресурс/эффект/механизм) | >=1 | ___ | ✅/❌ |
| Нет "магии" без опоры (не остаётся только допущение) | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] ФП не "A и НЕ-A" (две разные характеристики вместо противоположных)
- [ ] Выгоды не связаны с функциями/противоречием (вода вместо идей)
- [ ] Нет приземления: только "представим, что возможно"

## Quality Hint
- Если есть риск галлюцинации -> пометь `[ASSUME]` и предложи быстрый тест/фальсификацию.
