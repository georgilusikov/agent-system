## Block Conditions (STOP)
Если что-то из этого верно — **отчёт нельзя отдавать пользователю**:
- [ ] В тексте остались заглушки “Next Step”, “Handoff”, “TBD”, “TODO”
- [ ] Решения названы абстрактно без механизма (“использовать посредника”, “улучшить процесс”)
- [ ] Нет шага проверки/валидации (всё “на словах”)
- [ ] Есть английские слова (латинские строчные буквы a–z) в тексте (если отчёт предназначен человеку и требуется «всё на русском»)

## Confidence Adjustment (рекомендация)
- Все ✅ → Confidence +10%
- 1–2 ❌ → Confidence -20%
- ≥3 ❌ → Confidence cap 50%
