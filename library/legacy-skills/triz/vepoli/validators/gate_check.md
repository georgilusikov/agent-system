## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] S1 не определено → сначала @functional_analysis для идентификации компонентов
- [ ] Поле F не из МАТХЭМ (Mech/Acoust/Therm/Chem/Elec/Mag) → переформулировать
- [ ] Тип веполя перепутан (лечим Вредную связь методами Усиления) → пересмотреть диагноз
- [ ] Стандарт назван абстрактно ("подходит класс 1"), но нет конкретного S3/P2 → решение недоведено
- [ ] Смоделирован весь процесс/машина, а не одно взаимодействие S1-F-S2 → вернуться к локализации

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
- Wrong diagnosis (лечение Вреда Усилением): Confidence = 20% max
- Нет физической реализации S3/P2: Confidence -= 20%
- Нет before/after или test/no-go: Confidence -= 15%
