|-------|----------|--------|-------|

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Менее 10 ресурсов → анализ поверхностный, повторить инвентаризацию
- [ ] Нет ИКР/X-элемента → анализ стартовал без вектора поиска
- [ ] Нет ресурсов из категорий Space/Time/Information → самые ценные пропущены
- [ ] Все ресурсы — внешние (купить/арендовать) → ТРИЗ ищет ВНУТРЕННИЕ ресурсы
- [ ] Порядок поиска нарушен (сразу внешняя закупка/новый узел) → вернуться к внутренним/бросовым ресурсам
- [ ] Нет ОЗ/ОВ → вернуться к @socratic или @contradictions для локализации
- [ ] Нет Hypothesis → анализ не дошёл до actionable вывода

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
- Менее 10 ресурсов: Confidence = 30% max
- Нет Space/Time/Info: Confidence -= 25%
- Нет ИКР/X-элемента: Confidence -= 20%
- Нет quantity/availability check: Confidence -= 15%
- Нет Hypothesis/No-go: Confidence -= 15%
