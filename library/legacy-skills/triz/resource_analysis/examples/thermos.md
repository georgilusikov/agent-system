# Example: Resource Analysis - The Thermos

## Input
"We need to keep coffee hot. What resources do we have to minimize heat loss without using active heaters?"

## Execution Trace

### 1. Resource Inventory
- **Substances (S):** Coffee, Air, Metal/Plastic walls, Void (Empty space).
- **Fields (F):** Thermal energy (already in coffee - Resource!), Gravity, Vacuum (Lack of field).

### 2. Temporal Analysis
- **Micro-level:** Heat is vibration of molecules.
- **Resource Hack:** If there are NO molecules, there is NO heat conduction.
- **Action:** Create a vacuum between two walls.

### 3. Energy Source (The Coffee Itself)
- The heat in the coffee is the resource we are protecting.
- Use mirror surfaces (Substance property) to bounce the Heat Field (Field property) back into the coffee.

## Output
- **Model:** Use "Nothing" (Vacuum) as an insulator.
- **Result:** Standard Thermos bottle.
- **Insight:** Vacuums are "cheap" resources if you design for them once at production.
