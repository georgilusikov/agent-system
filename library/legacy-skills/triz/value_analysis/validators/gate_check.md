# Gate Check for Value Analysis

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Есть метрики ценности: цена/доход/маржа или LTV/CAC | Да/запрошено | ___ | ✅/❌ |
| MPV/главная ценность определена (что нельзя сломать) | Да/запрошено | ___ | ✅/❌ |
| Стоимость компонентов/функций оценена (пусть грубо, но с допущениями) | Да | ___ | ✅/❌ |
| Идентифицированы «дорогие» функции/узлы (кандидаты) | ≥2 | ___ | ✅/❌ |
| Есть приоритизация (топ‑драйверы затрат) и парковка мелкого | Да | ___ | ✅/❌ |
| Рекомендации не рушат MPV/безопасность/compliance | Да | ___ | ✅/❌ |

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Нет финансовых метрик вообще (даже грубой оценки/прокси)
- [ ] Не определена MPV/главная ценность (что нельзя сломать)

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
