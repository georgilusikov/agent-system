# Gate Check for Antisystem (Антисистема)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Рассмотрена зеркальная инверсия? | Да | ___ | ✅/❌ |
| Найден способ использовать энергию вредного фактора? | Да | ___ | ✅/❌ |
| Сформулирована гипотеза Нулевой Системы? | Да | ___ | ✅/❌ |
| Проведена связь с @diversion_analysis? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если нет зеркальной инверсии — ключевой шаг пропущен
- **BLOCK** если нет гипотезы Нулевой Системы — анализ неполный

## Confidence Adjustment
- Все 4 ✅ → confidence ≥ 85%
- 3 чека → confidence 65%
- < 3 → BLOCK
