# Gate Check for Experiment Designer

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Гипотеза в формате IF/THEN/BECAUSE | Да | ___ | ✅/❌ |
| Есть измеримый критерий успеха и провала (числа/пороги) | Да | ___ | ✅/❌ |
| Есть описание минимального эксперимента с временем и стоимостью | Да | ___ | ✅/❌ |
| Есть GO/NO-GO точка решения | Да | ___ | ✅/❌ |
| Есть риски эксперимента и митигации | Да | ___ | ✅/❌ |
| Нет обещаний 100% гарантии | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] Критерии не измеримы ("лучше", "быстрее", "качественнее" без порога)
- [ ] Эксперимент = полноценный пилот, минуя дешёвые проверки (desk research / мысленная проверка)
- [ ] Нет критерия провала (невозможно сфальсифицировать)

## Confidence Guidance
- Если нет данных -> пометь `[ASSUME]` и предложи, где взять цифры за 1-3 дня.
