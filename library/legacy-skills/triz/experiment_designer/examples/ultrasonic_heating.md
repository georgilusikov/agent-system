# Пример: Валидация ультразвукового нагрева

## Входные данные
**Решение из `@contradictions`:** Использовать ультразвуковой нагрев вместо индукционного для соединения деталей.

**Заявленное преимущество:** Быстрее, дешевле, локальнее.

---

## 🧪 План валидации: Ультразвуковой нагрев vs Индукционный

### Гипотеза
ЕСЛИ использовать УЗ-генератор 20кГц для нагрева стальной детали,
ТО температура 200°C достигается за <5 сек (vs 15 сек индукция),
ПОТОМУ ЧТО УЗ создаёт трение на границе зёрен металла.

### Критерии успеха/провала
| Критерий | Успех | Провал | Единица |
|---|---|---|---|
| Время нагрева до 200°C | <5 сек | >10 сек | сек |
| Равномерность нагрева | ±10°C | ±30°C | °C |
| Энергозатраты | <индукции | >индукции×2 | кВт·ч |
| Усталость материала | <5% снижения | >20% снижения | % прочности |

### Минимальный эксперимент
**Уровень:** 1-2 (Desk Research + Мысленный)
**Стоимость:** $0
**Время:** 2 часа

**Описание:**
1. Поиск патентов: "ultrasonic heating metal bonding"
2. Поиск статей: "ultrasonic vs induction heating steel"
3. Проверка физики: достаточно ли 20кГц для нагрева стали?

### Desk Research (результаты)
- **USPTO поиск:** 47 патентов на УЗ-нагрев металлов
- **Ключевой патент:** US 8,123,456 — УЗ-сварка алюминия, работает
- **Статья:** Journal of Materials Processing (2024) — УЗ эффективен для тонких деталей (<3мм)
- **Ограничение:** Для толстых деталей (>10мм) УЗ неэффективен

**Аналоги:**
| Аналог | Результат | Урок |
|---|---|---|
| Branson Ultrasonics (сварка пластика) | Успех | Частота 20-40кГц оптимальна |
| Herrmann Ultraschall (металл) | Частичный | Работает для Al, Cu; сталь сложнее |
| Индукционные печи | Baseline | 15 сек для 200°C — наш бенчмарк |

### Мысленная проверка
- Если УЗ-нагрев работает для стали → должны быть промышленные установки
  - Проверка: Herrmann, Branson — есть для цветных, для стали единичные ✓
- Контрпример: Толстые детали >10мм — УЗ не проникает
  - **Важно:** Уточнить толщину нашей детали!

### Риски эксперимента
| Риск | Митигация |
|---|---|
| Неправильная частота УЗ | Начать с 20кГц (стандарт), варьировать |
| Измерение температуры внутри детали | Термопара в отверстии, не на поверхности |
| Усталость видна только после 1000 циклов | Заложить в план долгосрочный тест |

### План действий
1. **Desk research** — 2 часа — $0 ✅ Сделано
2. **Уточнить толщину детали** — 5 мин — $0
3. **Если <5мм:** Найти лабораторию с УЗ-генератором — 1 день — $0
4. **Лабораторный тест:** 10 образцов — 2 дня — ~$500
5. **Точка решения:**
   - GO: время <7 сек, равномерность ±15°C
   - NO-GO: время >12 сек или неравномерность >25°C
   - PIVOT: Если сталь не работает → попробовать алюминиевый сплав

### Confidence
- До эксперимента: 40%
- После desk research: 60% (есть аналоги, но для стали мало данных)
- После лабораторного теста (ожидаемый): 85%

---

## Вывод
**Рекомендация:** Провести лабораторный тест (уровень 5) после уточнения толщины детали. Если >10мм — гипотеза скорее всего не сработает, рассмотреть pivot на композитный материал.
