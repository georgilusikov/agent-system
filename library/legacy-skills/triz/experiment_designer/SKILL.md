# Experiment Designer

## Описание
Архитектор экспериментов — проектирует минимальные проверки для валидации гипотез и решений до их внедрения.

## Когда использовать
- После генерации решения (`@contradictions`, `@ariz`, `@forty_principles`)
- Когда `@critic` оставил сомнения
- Перед крупными инвестициями
- Когда нужно убедить стейкхолдеров

## Что делает
1. Формулирует проверяемую гипотезу
2. Определяет критерии успеха/провала
3. Проектирует минимальный эксперимент (от desk research до пилота)
4. Ищет аналоги (кто уже проверял)
5. Выявляет риски самого эксперимента
6. Даёт план действий с GO/NO-GO точками

## Чего НЕ делает
- Не проводит эксперименты
- Не даёт 100% гарантий
- Не заменяет реальное тестирование

## Пример вызова
```
@experiment_designer
Проверить гипотезу: ультразвуковой нагрев детали быстрее индукционного
```

## Связанные скиллы
- `@critic` — критика после валидации
- `@diversion_analysis` — найти уязвимости эксперимента
- `@resource_analysis` — ресурсы для проведения теста
