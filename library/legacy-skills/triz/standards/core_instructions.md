## Протокол выполнения / Execution Protocol

### Фаза 1: Vepol Diagnosis (Classification)
1.  **Incomplete (Неполный):** Нет S2 или F? -> **Class 1.1**.
2.  **Harmful (Вредный):** S1 и S2 вредят друг другу? -> **Class 1.2**.
3.  **Insufficient (Слабый):** Действие есть, но слабое? -> **Class 2**.
4.  **Measurement (Измерительный):** Нужно найти/измерить? -> **Class 4**.

**Дискриминатор класса (по порядку):**
1. Нет S2 или поля F (веполь не построен)? → Класс 1.1 (достройка).
2. S1 вредит S2 / есть вредная связь? → Класс 1.2 (разрушение вредной связи).
3. Связь есть, но слабая? → Класс 2 (форсирование).
4. Задача измерения/обнаружения? → Класс 4.

В отчёте укажи класс + номер сработавшего вопроса.
⚠️ Не применяй стандарты форсирования (Класс 2) к вредному веполю (1.2) — усилишь вред.

---

### Фаза 2: Standards Lookup (The 5 Classes)

#### CLASS 1: Composition & Decomposition
*   **1.1.1 Synthesis:** Создай веполь (S1 -> F -> S2).
*   **1.1.2 Internal Complex:** Введи добавку ВНУТРЬ S1 или S2.
*   **1.2.1 Anti-Harm (S3):** Введи "Посредника" (S3) между S1 и S2.
*   **1.2.2 Modified S:** Используй "Даровой" ресурс как S3.
*   **1.2.4 Counter-Field:** Введи поле F2, нейтрализующее F1.

#### CLASS 2: Evolution (Fortification)
*   **2.1.1 Chain Vepol:** Сделай цепочку (S1-F1-S2-F2-S3).
*   **2.2.1 Field Evolution:** Замени поле на более управляемое (Mech -> Therm -> Chem -> Elec -> Mag).
*   **2.2.2 Fragmentation:** Раздроби S2 (Монолит -> Порошок -> Жидкость -> Газ -> Плазма).
*   **2.4.1 Fepol (Ferro-Field):** Магнитное поле + Ферромагнитное вещество (самый сильный стандарт!).

#### CLASS 3: Transition to Supersystem / Micro-level
*   **3.1.1 Bi-System:** Объедини две системы.
*   **3.1.2 Poly-System:** Объедини много систем.
*   **3.2.1 Micro-Level:** Перейди от "деталей" к "молекулам/полям".

#### CLASS 4: Measurement & Detection
*   **4.1.1 Change Measurement:** Измеряй производную, не само значение.
*   **4.2.1 Measurement Vepol:** Веполь, который "сигналит" при изменении.
*   **4.5.1 Bi-Functional:** Объект сам себя измеряет (самодиагностика).

#### CLASS 5: Helpers (Strategies)
*   **5.1.1 Void:** Введи "Пустоту" (Пузырьки газа).
*   **5.1.4 Micro-Dose:** Ничтожно малое количество.
*   **5.2.1 Existing Field:** Используй поля, которые УЖЕ есть в системе.

## Антипаттерны / Anti-Patterns
- **Ignoring 2.4.1 (Fepol):** "Король Стандартов". Всегда проверяйте магнитное поле.
- **Wrong Class:** Пытаться "Усилить" (Class 2) вредную связь (Class 1.2).
- **Abstract S3:** "Ввести вещество X" — какое X? Смотри `@resource_analysis`!

> ⚠️ **Guard clause:** сначала устрани вред (Класс 1.2), потом форсируй (Класс 2). Применение 2.x к вредному веполю запрещено.

**Пример плохого вывода (так НЕ делать):**
> ❌ "Веполь вредный (1.2), применяем стандарт 2.2.1 (переход к электрическому полю)" — форсирование вредной связи усиливает вред.
> ✅ "Веполь вредный (1.2) → сначала 1.2.1 (введение S3 между S1 и S2), вред устранён → теперь можно форсировать полезную связь по 2.x."
