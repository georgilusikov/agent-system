## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Нет модели/описания задачи
- [ ] Нет критериев/ограничений применения стандарта
- [ ] S3/Field остаётся абстрактным «вещество X» — не привязан к ресурсам кейса

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
