## Block Conditions (STOP)
- [ ] Заполнены 9 клеток, но нет конфликта/вывода (получилась “таблица ради таблицы”)
- [ ] Есть таблица, но нет bypass/reframed task (получилась “матрица ради матрицы”)
- [ ] Нет будущего (будущее пустое или “не знаю” без попытки трендов/гипотез)
- [ ] Нет порога/предела для стратегических/эволюционных задач (нужно вызвать `@s_curve`)

## Confidence Adjustment (рекомендация)
- Все ✅ → Confidence +10%

- ≥3 ❌ → Confidence cap 50%
