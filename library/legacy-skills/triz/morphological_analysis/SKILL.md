# 🔀 Morphological Analysis (Морфологический анализ)

**Purpose:** Систематический перебор всех возможных конфигураций системы через разбиение на параметры и значения.

**Origin:** Фриц Цвикки (Fritz Zwicky), 1960-е гг.

**When to use:**
- Патентование — поиск неочевидных комбинаций
- Сложная система с множеством параметров
- Необходимость гарантированного полноты перебора
- Поиск радикально новых решений в известной области

**Output:** Морфологическая матрица, ранжированные конфигурации, рекомендуемые варианты с оценками

**Gate Check:**
- Матрица построена (параметры × значения)
- Все ячейки заполнены
- Неочевидные комбинации выделены
- ИКР использован для фильтрации
- Ресурсы учтены в оценке
