# Gate Check for Contradictions (ТП/ФП)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Цель/MPV зафиксирована с метрикой? | Да | ___ | ✅/❌ |
| Обосновано, почему это ГЛАВНОЕ противоречие? | Да | ___ | ✅/❌ |
| ОЗ (Оперативная Зона) локализована? | Конкретно | ___ | ✅/❌ |
| ОВ (Оперативное Время) локализовано? | Конкретно | ___ | ✅/❌ |
| ТП сформулировано "Если/То/Но" (пара ТП-1 и ТП-2)? | Оба | ___ | ✅/❌ |
| Выбран конкретный Элемент конфликта (не "вся система")? | Да | ___ | ✅/❌ |
| ФП сформулировано как "A и НЕ-A" (одно свойство)? | Да | ___ | ✅/❌ |
| Why This TC обосновано? | Да | ___ | ✅/❌ |
| Quantitative Anchor указан? | Да | ___ | ✅/❌ |
| Проверены ≥4 стратегии разделения (Время, Пространство, Структура, Условие)? | ≥4 | ___ | ✅/❌ |
| У таблицы разделения есть тест (прибор + порог)? | Да | ___ | ✅/❌ |
| Выбрана гипотеза разделения с техническим концептом? | Да | ___ | ✅/❌ |
| У выбранной гипотезы есть No-go и Anti-Compromise Check? | Да | ___ | ✅/❌ |

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] ФП не является "A и НЕ-A" (т.е. два разных свойства вместо противоположных) → переформулировать
- [ ] Элемент конфликта = вся система, а не конкретная зона → применить @functional_analysis для декомпозиции
- [ ] Нет метрики успеха → вернуться к постановке задачи через @socratic или @akts
- [ ] Выбрана "золотая середина" вместо устранения конфликта → противоречие решено неверно

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
- ФП не "A и НЕ-A": Confidence = 20% max (критическая ошибка)
- Нет Why This TC / Quantitative Anchor: Confidence -= 15%
- Нет Test/No-go/Anti-Compromise: Confidence -= 15%
