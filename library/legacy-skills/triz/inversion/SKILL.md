# 🙃 Inversion Analysis

**Purpose:** Solve problems by reversing action, object, or environment.

**When to use:**
- Direct approach doesn't work
- Need to break psychological inertia
- Looking for 180-degree perspective shift

**Output:** Inversion options, selected reversal, new advantages

**Gate Check:**
- All 5 inversion screens checked
- Inversion creates real advantage (not just absurdity)
- Safety considered
