# Gate Check for OFOP (Reverse FOS)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Есть L2 и L3 описание технологии (без доменной шелухи) | Да | ___ | ✅/❌ |
| Зафиксирован козырь и компромисс | Да | ___ | ✅/❌ |
| Зафиксирован MPV/метрика/порог | Да | ___ | ✅/❌ |
| Отобрано 3-5 рынков, и >=1 из другой отрасли | Да | ___ | ✅/❌ |
| Для каждого рынка есть "что сломается" + адаптация | Да | ___ | ✅/❌ |
| Есть 2-недельный план: интервью + WTP-прокси + мини-пилот | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] Рынки без "без этого нельзя" (нет связи с потерями/штрафами/простоями)
- [ ] Нет компромисса (продажа "сферического коня")
- [ ] Нет способа фальсифицировать гипотезу рынка (что должно быть ложным, чтобы отказаться)
