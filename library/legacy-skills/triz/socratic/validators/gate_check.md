# Gate Check for Socratic Discovery

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| 3-5 вопросов (не больше и не меньше) | Да | ___ | ✅/❌ |
| Каждый вопрос конкретный и локализует ОЗ/ОВ/условия | Да | ___ | ✅/❌ |
| У каждого вопроса есть цель (ОЗ/ОВ/условия/ресурсы) | Да | ___ | ✅/❌ |
| Нет предложений решений или рекомендаций | Да | ___ | ✅/❌ |
| Есть 1-2 предложения "почему важно" | Да | ___ | ✅/❌ |
| Есть `Next Step` (куда передать после ответа) | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] >5 вопросов (анкета вместо диагностики)
- [ ] Есть общий вопрос без локализации ("Что не так?") -> переписать
- [ ] Есть совет/решение -> удалить
