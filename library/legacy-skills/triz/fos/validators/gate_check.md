# Gate Check — FOS (функционально-ориентированный поиск)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Функция оформлена в 3 уровнях (L1/L2/L3) | Да | ___ | ✅/❌ |
| Доноры/лидеры по функции: ≥5, из ≥2 разных отраслей | Да | ___ | ✅/❌ |
| Есть минимум 1 перенос **тренда** (было→стало→следующий шаг) или аргументированный отказ | Да | ___ | ✅/❌ |
| Гипотезы переноса: ≥3, у каждой есть ограничение/риск | Да | ___ | ✅/❌ |
| У каждой гипотезы есть маркер успеха + фальсификация + быстрый тест | Да | ___ | ✅/❌ |
| **Analogy Transfer Table** заполнена (функция → донор → что переносится → что нет → адаптация → тест → no-go) | Да | ___ | ✅/❌ |
| Для лучшей гипотезы указано, почему это лидирующий донор и почему соседний донор хуже | Да | ___ | ✅/❌ |
| Есть явный Adaptation Delta (совпадения / разрыв / компенсация) | Да | ___ | ✅/❌ |
| Указан Next step / Handoff | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] Нет L1/L2/L3 формулировки функции
- [ ] Доноров <3 (по сути не было поиска)
- [ ] Нет ни одного теста/фальсификации (это "набор идей", не FOS)
- [ ] Нет Analogy Transfer Table — перенос не доведён до инженерного решения
- [ ] Нет donor-quality discrimination (лидирующий vs соседний донор не различены)
- [ ] Нет Adaptation Delta / компенсации разрыва среды

## Confidence Adjustment
- Все пункты пройдены: Confidence += 10%
- 1–2 провала: Confidence -= 20%
- 3+ провала: Confidence cap 50% и требовать доработку
