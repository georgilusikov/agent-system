# Dynamic Constructor (для задач вне карт А-Н)

> **Триггер:** Задача НЕ попадает ни в одну карту. Или формулировка слишком общая.

```
ШАГ 1 — АНАЛИЗ:
  a. Начни с @akts (MPV) ИЛИ @causal_analysis (причина)
  b. Добавь 1-2 аналитических скилла по триггерам из Карты Компетенций
  c. Если задача о процессе → @flow_analysis (ФАП)
  d. Если задача о надёжности → @afd_failure_predictor
  e. ⛔ GATEWAY: инструмент принёс новое знание?
     → НЕТ: смени системный уровень (подсистема/надсистема)

ШАГ 2 — ФОРМУЛИРОВКА ЗАДАЧИ:
  Есть ТП или ФП? (обязательно!)
  ├─ ДА → Шаг 3
  └─ НЕТ → добавь ещё 1 аналитический инструмент или запроси уточнение

ШАГ 3 — МОДЕЛИРОВАНИЕ (выбор пути по барьеру):
  ├─ Конфликт параметров → @contradictions → @forty_principles [locked]
  ├─ Вредное взаимодействие → @vepoli → @standards [locked]
  ├─ Нужен механизм → @ikr → @effects
  ├─ Нужен аналог → @fos ИЛИ @benchmarking → @oas_transfer
  ├─ Система избыточна → @trimming
  └─ Тупик → @arip (быстро) → если нет → @ariz (полный)

ШАГ 4 — ПРОВЕРКА:
  @critic → если слабое звено найдено, вернись к нужному шагу

ШАГ 5 — ИТОГ:
  @akts (повторная сверка MPV) → @final_triz_report
```
