# Gate Check for AKTS (Анализ Ключевых Требований Стейкхолдеров)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Выявлены внешние стейкхолдеры (клиенты, плательщики)? | Да | ___ | ✅/❌ |
| Выявлены внутренние стейкхолдеры (сотрудники, акционеры)? | Да | ___ | ✅/❌ |
| Найден минимум 1 скрытый стейкхолдер? | Да | ___ | ✅/❌ |
| Стадия S-кривой учтена при расстановке приоритетов? | Да | ___ | ✅/❌ |
| Проведено Satisfaction Benchmarking (Us vs Market)? | Да | ___ | ✅/❌ |
| Выявлен Saturation Gap? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если нет скрытых стейкхолдеров — анализ поверхностный
- **BLOCK** если S-кривая не определена — приоритеты будут неверными

## Confidence Adjustment
- Все 6 чеков ✅ → confidence ≥ 85%
- 4-5 чеков → confidence 60-80%
- < 4 чеков → BLOCK, вернуть на доработку
