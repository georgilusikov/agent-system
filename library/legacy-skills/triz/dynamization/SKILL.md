# 🎢 Dynamization (Динамизация)

**Purpose:** Make rigid systems flexible and adaptive.

**When to use:**
- System is too rigid for changing conditions
- Need adaptability without redesign
- Part of ZRTS evolution

**Output:** Dynamization point, chain stage, technical effect

**Gate Check:**
- Dynamization chain followed (Rigid→Hinge→Flexible→Liquid→Field)
- Control/feedback added (not just flexibility)
- Complexity justified by benefit
