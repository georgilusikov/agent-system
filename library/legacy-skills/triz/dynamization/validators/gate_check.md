# Gate Check for Dynamization (Динамизация)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Определен элемент с недостаточной подвижностью? | Да | ___ | ✅/❌ |
| Предложен переход на +1 ступень эволюции? | Да | ___ | ✅/❌ |
| Рассмотрен сценарий адаптивности (условие → свойство)? | Да | ___ | ✅/❌ |
| Решение не создает неуправляемого хаоса? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если элемент не определён — нет объекта динамизации
- **BLOCK** если решение создаёт хаос — вредное побочное действие

## Confidence Adjustment
- Все 4 ✅ → confidence ≥ 85%
- 3 чека → confidence 65%
- < 3 → BLOCK
