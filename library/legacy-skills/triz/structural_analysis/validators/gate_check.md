# Gate Check for Structural Analysis (Структурный Анализ)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Граф системы построен (узлы + связи)? | Да | ___ | ✅/❌ |
| Типы связей определены (жёсткая/гибкая/информационная)? | Да | ___ | ✅/❌ |
| Критические узлы выделены? | Да | ___ | ✅/❌ |
| Мермaid-диаграмма или таблица приложена? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если нет типов связей — граф плоский и бесполезный
- **BLOCK** если нет критических узлов — нет точки входа для оптимизации

## Confidence Adjustment
- Все 4 ✅ → confidence ≥ 85%
- 3 чека → confidence 65%
- < 3 → BLOCK
