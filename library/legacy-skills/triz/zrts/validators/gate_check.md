# Gate Check for ZRTS (Законы Развития Технических Систем)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Текущий статус системы определён (Mono/Bi/Poly/...)? | Да | ___ | ✅/❌ |
| S-Curve Stage определена (1/2/3/4)? | Да | ___ | ✅/❌ |
| Применяемый закон указан? | Да | ___ | ✅/❌ |
| Объяснено `Why ZRTS / Why not S-Curve only`? | Да | ___ | ✅/❌ |
| Объяснено `Why This Law / Why Not Neighboring Law`? | Да | ___ | ✅/❌ |
| Вектор эволюции определён (Poly/Micro/Dynamic/...)? | Да | ___ | ✅/❌ |
| Предложен конкретный следующий шаг эволюции? | Да | ___ | ✅/❌ |
| **Transition Contract** заполнен (стадия + ограничение + переход + критерий опровержения)? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если S-Curve не определена — без неё вектор эволюции бессмыслен
- **BLOCK** если нет объяснения, почему S-Curve недостаточно — это может быть просто stage diagnosis, а не ZRTS
- **BLOCK** если нет конкретного следующего шага — анализ без выхода
- **BLOCK** если нет критерия опровержения стадии — прогноз непроверяем

## Confidence Adjustment
- Все 8 ✅ → confidence ≥ 85%
- 6-7 → confidence 65%
- < 6 → BLOCK
