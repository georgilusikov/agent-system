# 🌀 ZRTS (Laws of Technical System Evolution)

**Purpose:** Predict system evolution using 8 deterministic laws, anchored to S-curve stage.

**When to use:**
- System reached limits (S-curve Stage 3-4)
- Need to forecast "next generation"
- Deciding between adding features or simplifying
- Evolutionary prognosis required (Route В/F in orchestrator)

**Output:** S-curve anchor, all 8 laws checked (Да/Нет), selected evolution vector with recommendation, Reflection Gate

**Gate Check:**
- S-curve stage determined and justified
- All 8 laws checked (at least Да/Нет per law)
- Selected law consistent with S-curve stage
- Bottleneck (law #5) checked
- Concrete next step given (not "нужно улучшить")
- Reflection Gate (CRITICAL + BLIND SPOT) filled
