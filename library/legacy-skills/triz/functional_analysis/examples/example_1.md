# Example: Анализ Кофемашины

## Input
"Проведи функциональный анализ домашней кофемашины. Цель — снизить себестоимость."

## Execution Trace
1. Определён режим: Product Mode (анализ устройства)
2. Разобрана на компоненты
3. Построены Triplets
4. Оценены функции
5. Найдены кандидаты на свёртывание

## Output

### 🎯 Выбранный Режим
Product Mode (Железо)

### 📊 Модель Системы
| Компонент | Функция | Тег | Rank |
|-----------|---------|-----|------|
| Помповый насос | Создаёт давление 15 бар | + | A |
| Бойлер | Нагревает воду | + | A |
| Шланг подачи воды | Передаёт воду от бака к насосу | + | B (посредник) |
| Поддон для капель | Собирает пролитое | - | C |
| Индикатор уровня воды | Показывает количество воды | M | C |
| Декоративная панель | Эстетика | Избыточная | C |
| Термодатчик | Контролирует температуру | M | B |

### 🚨 Кандидаты на Свертывание
1. **Поддон для капель** — Можно заменить на "не проливать" (изменить форму носика) — $T_f$ = 0.8
2. **Декоративная панель** — Можно интегрировать в корпус — $T_f$ = 0.9
3. **Индикатор уровня воды** — Можно заменить на прозрачный бак — $T_f$ = 0.7

### 📈 Trimming Factor
$T_f = \frac{2 (вредные) + 1 (избыточные)}{4 (полезные)}$ = 0.75

### ➡️ Next Step
Запуск @trimming с Rank C списком: [Поддон, Панель, Индикатор]

## Why This Works
- Чётко определён режим анализа
- Использована таблица с тегами для классификации
- Рассчитан Trimming Factor
- Подготовлен handoff для следующего агента
