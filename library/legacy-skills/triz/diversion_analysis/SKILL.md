# 😈 Diversion Analysis (AFD)

**Purpose:** Find hidden vulnerabilities by thinking like a saboteur.

**When to use:**
- Validating new solutions (Pre-Mortem)
- Investigating failures (Post-Mortem)
- Security/safety analysis

**Output:** Attack scenario, vulnerability map, protection strategy

**Gate Check:**
- Inversion question asked ("How to break it?")
- Internal resources used (not external forces)
- Protection level selected (1-7)
