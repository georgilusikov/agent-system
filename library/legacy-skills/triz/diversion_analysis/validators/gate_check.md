# Gate Check for Diversion Analysis

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---:|---|:---:|
| Задача инвертирована ("как сломать, используя ресурсы системы/среды") | Да | ___ | ✅/❌ |
| Есть конкретная "миссия диверсанта" (какой отказ/поломка) | Да | ___ | ✅/❌ |
| Предложено векторов атаки | ≥3 | ___ | ✅/❌ |
| Покрытие классов атак (мех + физ/хим/тепло + инфо/сигналы) | ≥2 класса | ___ | ✅/❌ |
| Для каждого вектора оценена реализуемость в реальности | Да | ___ | ✅/❌ |
| Выделен "Smoking Gun" (главная проверяемая гипотеза) | ≥1 | ___ | ✅/❌ |
| Для критичных векторов есть контрмеры + тест контрмер | ≥1 | ___ | ✅/❌ |
| Учтён "стелс": диверсия проходит проверки и проявляется в реальном режиме | Да | ___ | ✅/❌ |
| Для сложной системы: выполнена декомпозиция по узлам/интерфейсам | Да/НП | ___ | ✅/❌ |
| Выполнен "злой джокер": цепочки ресурс+контекст→ущерб (≥3) | Да/НП | ___ | ✅/❌ |
| **Verdict & Action Plan с приоритетным действием?** | Да | ___ | ✅/❌ |
| **Fast Validation (1–7 дней)?** | Да | ___ | ✅/❌ |
| **No-go / Residual Risk указан?** | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] Используются "внешние оружия" (динамит/хакер из космоса), а не ресурсы системы/среды
- [ ] Нет связи "вектор атаки → реальный ресурс в среде"
- [ ] Нет теста: как проверить уязвимость/контрмеру в течение 1–7 дней
- [ ] Нет Verdict / Action Plan → анализ не дошёл до actionable вывода

## Confidence Adjustment (рекомендация)
- Все ✅ → Confidence +10%
- 1–2 ❌ → Confidence -20%
- ≥3 ❌ → Confidence cap 50%
- Нет Verdict/No-go → Confidence -15%
