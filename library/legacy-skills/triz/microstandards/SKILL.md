# 📖 Microstandards Lookup (Микростандарты ТРИЗ)

**Purpose:** Поиск готовых решений-аналогов в базе микростандартов ТРИЗ. Микростандарт — это узкий паттерн "Если [ситуация + ограничения] → То [рекомендация]", применимый в разных областях.

**When to use:**
- После построения модели (ТП, Веполь, ИКР) — найти аналогичные решённые задачи
- Когда нужна быстрая подсказка из практики до глубокого синтеза
- Как дополнительный source решений рядом с 76 стандартами и 40 принципами
- В Dynamic Constructor на этапе Синтеза

**Output:** Топ-3 релевантных микростандарта (score >= 6) с объяснением почему подходит

**Gate Check:**
- Запрос переформулирован из модели в "ситуация + ограничения"
- Найден хотя бы 1 результат с score >= 6
- Результаты НЕ противоречат уже выбранному направлению решения

**Database:** `_agent_shared/skills/triz/microstandards/data/microstandards.json`

**CLI:**
```bash
python3 _agent_shared/skills/triz/microstandards/scripts/run.py search.py "описание ситуации"
```
