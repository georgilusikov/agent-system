# Example: Robinson - Apollo 13 CO2 Scrubber

## Input
"Apollo 13 lunar module has square CO2 scrubber cartridges, but the command module uses round ones. The command module cartridges are exhausted. How to connect a square hole to a round peg using only resources on board?"

## Execution Trace (Robinson Protocol)

### 1. Goal
Connect the Square Cartridge to the Round Connector.

### 2. Available Resources (The "Box")
- **Substances:** Plastic bags, Cardboard (from flight manuals), Grey duct tape, A sock, Hoses.
- **Fields:** Air pressure (from fans), Manual force.

### 3. Constraints
- Zero external tools.
- Limited time (CO2 levels rising).
- No spare connectors.

### 4. Brainstorming (Combinations)
1. Use the Sock as a filter? (Too porous).
2. Taping the bag around the round hole and the square cartridge.

### 5. Selection & Implementation
- **Concept:** The "Mailbox".
- **Action:**
    - Place the square cartridge inside a plastic storage bag.
    - Cut a hole in the bag for the round hose.
    - Seal everything with duct tape.
    - Use the cardboard to create a rigid structure (stiffening).

## Output
- **Solution:** A makeshift adapter made of a bag, cardboard, and tape.
- **Result:** Successfully scrubbed CO2, saving the crew.
- **Lesson:** In survival/extreme cases, Function (connecting A to B) is more important than Design. Form follows Resources.
