# 🔄 Reverse FOS (ОФОП)

**Purpose:** Найти 3–5 рынков/контекстов, где технология “обязательна” (без неё нельзя), и сформировать быстрый план валидации.

**Inputs:** Технология/механизм через функцию L2/L3, козырь + обратная сторона.

**Outputs:** Рынки (почему “без этого нельзя”, дельта среды, адаптация), план валидации (интервью/WTP‑прокси/мини‑пилот + метрика/фальсификация), handoff.

**Gate Check:** см. `_agent_shared/skills/triz/reverse_fos/validators/gate_check.md`
- Описана функция L2/L3 + козырь и компромисс.
- ≥3 рынка, у каждого дельта среды и шаг адаптации.
- План валидации с метрикой/фальсификацией.
