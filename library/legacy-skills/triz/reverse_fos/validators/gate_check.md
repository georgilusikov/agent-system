# Gate Check — Reverse FOS (поиск рынков для технологии)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Технология описана через функцию L2/L3 (механизм), есть “козырь” и trade-off | Да | ___ | ✅/❌ |
| Есть MPV/метрика успеха и фокус (не распыление на “все рынки”) | Да/НП | ___ | ✅/❌ |
| Есть ≥3 рынка/сегмента с обоснованием “без этого нельзя” | Да | ___ | ✅/❌ |
| Для каждого рынка описана дельта среды (что сломается) и шаг адаптации | Да | ___ | ✅/❌ |
| Есть план валидации: интервью + WTP‑прокси + мини‑пилот | Да | ___ | ✅/❌ |
| Для плана валидации есть метрика успеха + фальсификация | Да | ___ | ✅/❌ |
| Есть Next step / Handoff | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] Технология не описана (нет L2/L3 и механизма)
- [ ] Рынков <3 (по сути не было поиска)
- [ ] Нет плана валидации (интервью/прокси/пилот)

## Confidence Adjustment
- Все пункты пройдены: Confidence += 10%
- 1–2 провала: Confidence -= 20%
- 3+ провала: Confidence cap 50% и требовать доработку
