# Inconsistent Parameters Method (Метод определения несогласованных параметров)

This TRIZ skill identifies hidden contradictions and root causes of system failures by mapping inconsistent parameters across functions.

## Why use it?
Standard functional analysis shows WHAT the system does, but often fails to pinpoint WHY a specific harmful chain reaction occurs. By creating an "Inverse Graph" and adding a "Parameter Object" column, we can discover chains of inadequate function execution caused by parameter mismatches.
