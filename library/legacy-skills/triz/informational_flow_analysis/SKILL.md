# Informational Flow Analysis (Информационный потоковый анализ)

Use this skill to diagnose and solve bottlenecks, delays, and inefficiencies in any complex process or system.
It relies on two powerful principles from P.N. Shimukovich:
1. Every physical interaction is an exchange of information. If parts don't work together efficiently, it's because the "receiver" is not informed about the "source".
2. The Demukron Method: Transforming sequential connections (AND operators) into parallel pipelines (OR operators) to drastically cut down process time.

Follow exactly the guidelines provided in `core_instructions.md` when analyzing flows and bottlenecks.
