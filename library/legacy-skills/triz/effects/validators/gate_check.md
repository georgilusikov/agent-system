# Gate Check for Effects

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Определена функция/явление, которое нужно реализовать/заменить | Да | ___ | ✅/❌ |
| Есть ограничения среды/материалов/энергии | Да/запрошено | ___ | ✅/❌ |
| Задан диапазон параметров (масштаб, температура, давление, точность) | Да | ___ | ✅/❌ |
| Выбрана 1 целевая функция, влияющая на MPV/метрику (вторичное в парковке) | Да/НП | ___ | ✅/❌ |
| Проверено: нет регуляторных/safety запретов на эффект | Да/нет | ___ | ✅/❌ |
| Запущен поиск по базе (`effects_lookup.py`) или показан `--list-functions/--stats` | Да | ___ | ✅/❌ |
| Обосновано выбранное семейство эффектов (а не просто назван эффект) | Да | ___ | ✅/❌ |
| Есть carrier / resource realism для реализации эффекта | Да | ___ | ✅/❌ |
| Проверен physical parameter fit (среда, температура, давление, материал, масштаб) | Да | ___ | ✅/❌ |
| Если задача ещё на model stage: явно дана эскалация в `@vepoli` / `@standards` / `@contradictions` | Да/НП | ___ | ✅/❌ |
| Если результатов 0: указаны синонимы/переформулировки или эскалация (→ `@ariz`) | Да/нет | ___ | ✅/❌ |

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Нет описания функции/явления
- [ ] Не заданы ограничения применения (риски/safety)

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
