# Gate Check for PN Eco-Innovation

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Выявлены ли позитивные (P) и негативные (N) факторы? | Да | ___ | ✅/❌ |
| Проведен ли анализ отходов как неиспользованных ресурсов? | Да | ___ | ✅/❌ |
| Сформулированы ли шаги по переводу вреда в пользу? | Да | ___ | ✅/❌ |

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Вред не определен точно (абстрактная 'экология') → конкретизировать вред
- [ ] Решения требуют внешних, дорогих фильтров → переосмыслить сброс/отходы внутри системы

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
