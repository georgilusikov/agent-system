# Core Instructions: PN-Method for Eco-Innovations

## 1. Context and Purpose
The PN-Method (developed and published on metodolog.ru) extends TRIZ functional and systemic analysis specifically for ecological and sustainable innovations. Ordinary technical solutions to ecological problems often create new harmful side-effects. This method forces a comprehensive 10-aspect review of the system.

## 2. The 10 Aspects (Десятиэкранная схема)
Analyze the problem and the proposed system across these 10 dimensions:

1. **Systemic-Goal (Системно-целевой)**: What is the true ultimate purpose of the system? Can the goal be achieved without the system at all?
2. **Historical (Исторический)**: How did previous generations solve this ecological need? What were the evolutionary steps that led to the current harmful state?
3. **Elemental (Элементный)**: What specific substances/fields are used? Can toxic or non-renewable elements be replaced with abundant, neutral ones?
4. **Structural (Структурный)**: How are elements arranged? Does the structure itself cause waste (e.g., inefficient piping, massive loss of heat)?
5. **Functional (Функциональный)**: List all functions. Which functions generate harmful waste?
6. **Resource (Ресурсный)**: What free environmental resources (wind, ambient heat, gravity, natural biological processes) are ignored?
7. **Integrational (Интеграционный)**: How does the system integrate into the larger ecosystem? Does it break natural cycles (e.g., nitrogen cycle, water cycle)?
8. **Communicational (Коммуникационный)**: How does the system communicate its state? (e.g., sensors for pollution, feedback loops for waste generation).
9. **Managerial (Управленческий)**: Who controls the system and what are their incentives? Is it profitable to pollute?
10. **Informational (Информационный)**: What data is missing that prevents an ecological solution?

## 3. Four Approaches to Ecological Problem Solving
Instead of jumping straight to a solution, evaluate the problem using these four paradigms:

- **Absolution (Невмешательство)**: Ignore it. Is the natural ecosystem capable of healing this itself over time?
- **Resolution (Снижение вреда / Частичное вмешательство)**: Patch the system. Add a filter, dilute the waste, create a barrier. (Usually the weakest TRIZ approach, but fast).
- **Solution (Оптимальное решение)**: Re-engineer the process to eliminate the contradiction. Prevent the waste from forming by changing the physical operation.
- **Dissolution (Растворение проблемы)**: Eliminate the system or the need entirely. The problem ceases to exist because the context changed. (Ideal Final Result).

## 4. Output Format
When executing the PN-Method, you must provide:
1. **The 10-Aspect Breakdown**: A brief analysis of the system across the 10 dimensions, highlighting the "levers" for ecological improvement.
2. **Four Paradigms Grid**: A proposal for the ecological issue showing one idea for each of the 4 approaches (Absolution, Resolution, Solution, Dissolution).
3. **Synthesis**: The final recommended TRIZ concept that maximizes sustainability with minimal resource expenditure.
