# STPA Analysis

Use this skill when the problem is about preventing failures before they happen in systems with controllers, feedback, software logic, operators, or safety-critical interactions.

This skill is best for:
- systems with control loops, automation, or procedures
- hazards that emerge from coordination, timing, or feedback
- situations where FMEA-style part-by-part thinking misses system interactions

Follow `core_instructions.md` exactly and finish with a concrete hazard handoff, not a generic risk list.
