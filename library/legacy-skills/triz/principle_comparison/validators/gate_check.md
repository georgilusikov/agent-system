# Gate Check for Principle Comparison (Logvinov)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Указаны системы A и B | Да | ___ | ✅/❌ |
| Таблица содержит все 5 уровней (1-5) | Да | ___ | ✅/❌ |
| Для каждого уровня заполнено A, B и вывод | Да | ___ | ✅/❌ |
| В резюме есть чёткий вывод: разные ПД или модификация | Да | ___ | ✅/❌ |
| Нет ухода в "всё лучше/хуже" без принципа | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] Нет физэффекта/механизма (уровень 1 пустой)
- [ ] Смешаны разные уровни (например материалы вместо топологии потоков)
- [ ] Вывод не следует из таблицы (прыжок логики)
