# Gate Check for OZ-OV (Оперативная Зона / Оперативное Время)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| OZ определена с ≥2 уровнями масштаба? | Да | ___ | ✅/❌ |
| OZ сфокусирована (не вся система, а зона конфликта)? | Да | ___ | ✅/❌ |
| OV определено (До / Во время / После)? | Да | ___ | ✅/❌ |
| Не включены элементы, не участвующие в конфликте? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если OZ = вся система (нет фокусировки)
- **BLOCK** если нет OV (только пространство, без времени)

## Confidence Adjustment
- Все 4 ✅ → confidence ≥ 85%
- 3 чека → confidence 65%
- < 3 → BLOCK
