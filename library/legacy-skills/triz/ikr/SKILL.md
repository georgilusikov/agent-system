# 🏁 IKR (Ideal Final Result)

**Purpose:** Formulate maximally ambitious goal to break psychological barriers.

**When to use:**
- Starting problem analysis
- Need breakthrough, not optimization
- Justifying radical simplification

**Output:** IKR formulation, ideal system image, barriers list

**Gate Check:**
- Formula follows "X САМО..."
- Not a disguised solution
- Based on available resources
