# Example: IKR - Paint Filter

## Input
"Metal filter at a paint factory clogs frequently with dry lumps. Cleaning it requires stopping the line (downtime) and manual labor."

## Execution Trace

### 1. IKR-1 (Ideal Final Result)
- **Goal:** Filter cleans itself.
- **Formula:** "The Filter X ITSELF removes the lumps without stopping the flow."

### 2. IKR-2 (Sharpening/Super-Ideal)
- **Concept:** "The System exists, but the Machine does not."
- **Formula:** "There is NO FILTER, but the filtration function is performed by the Paint itself."

### 3. Resource Mobilization
- **Resources:** Paint liquid, Lumps (solid), Centrifugal force (flow speed), Gravity.
- **Contradiction:** Paint must pass, Lumps must not pass.

### 4. Solution Concept
- **Idea:** Use density difference.
- **Mechanism:** A Centrifuge (Hydrocyclone).
- **Physics:** Heavy lumps are pushed to the walls by centrifugal force; clean lighter paint stays in the center.
- **Result:** Filtration happens without a mesh/grid. The "Filter" (as an obstruction) has effectively disappeared.

## Output
- **Ideal System:** Hydrocyclone separator.
- **Result:** Zero downtime for cleaning mesh.
