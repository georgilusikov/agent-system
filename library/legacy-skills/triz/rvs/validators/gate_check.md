# Gate Check for RVS (Размер-Время-Стоимость)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Проведены эксперименты Size → ∞ и Size → 0? | Да | ___ | ✅/❌ |
| Проведены эксперименты Time → ∞ и Time → 0? | Да | ___ | ✅/❌ |
| Проведены эксперименты Cost → ∞ и Cost → 0? | Да | ___ | ✅/❌ |
| Каждый эксперимент содержит инсайт/идею? | Да | ___ | ✅/❌ |
| Из 6 экспериментов выбрана лучшая идея? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если < 4 экспериментов из 6 — анализ неполный
- **BLOCK** если инсайты не извлечены — формальное выполнение

## Confidence Adjustment
- Все 5 ✅ → confidence ≥ 85%
- 3-4 → confidence 65%
- < 3 → BLOCK
