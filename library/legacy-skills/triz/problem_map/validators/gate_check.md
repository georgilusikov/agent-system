# Gate Check for Problem Map

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Есть 2-5 symptom clusters | Да | ___ | ✅/❌ |
| Назван primary stakeholder / owner of pain | Да | ___ | ✅/❌ |
| Зафиксирован current harm | Да | ___ | ✅/❌ |
| Зафиксированы constraints | Да | ___ | ✅/❌ |
| Есть measurable marker или candidate metric | Да | ___ | ✅/❌ |
| Есть 2-4 candidate problem statements | Да | ___ | ✅/❌ |
| Выбран recommended primary problem statement | Да | ___ | ✅/❌ |
| Есть явный handoff в @problem_formulator | Да | ___ | ✅/❌ |

## Block Conditions
- [ ] Output содержит solution concepts вместо problem statements
- [ ] Нет recommended primary problem statement
- [ ] Нет owner of pain
- [ ] Нет metric / marker / measurable anchor
