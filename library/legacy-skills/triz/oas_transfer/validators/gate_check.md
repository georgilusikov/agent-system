# Gate Check for OAS Transfer (Перенос ОАС / Объект-Аналог-Свойство)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Дефицит реципиента определён (какого свойства не хватает)? | Да | ___ | ✅/❌ |
| Система-Донор идентифицирована? | Да | ___ | ✅/❌ |
| Механизм переноса описан (ОАС → Реципиент)? | Да | ___ | ✅/❌ |
| Адаптация к контексту нашей системы проведена? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если донор не из другого домена — это не трансфер, а копирование
- **BLOCK** если нет механизма адаптации — решение не реализуемо

## Confidence Adjustment
- Все 4 ✅ → confidence ≥ 85%
- 3 чека → confidence 65%
- < 3 → BLOCK
