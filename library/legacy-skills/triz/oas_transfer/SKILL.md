# 🧬 OAS (Feature Transfer / Hybridization)

**Purpose:** Create hybrid systems by transferring features from donor to recipient.

**When to use:**
- Want to add capability without redesign
- Looking for competitive advantage
- Creating new market category

**Output:** Deficit analysis, donor selection, transfer mechanism, conflict resolution

**Gate Check:**
- Deficit clearly identified
- Donor has feature as MAIN strength
- Transfer mechanism selected (Substance/Field/Info)
- Conflicts resolved via trimming
