# 👨‍👩‍👧‍👦 MMCh (Метод Маленьких Человечков)

**Purpose:** Resolve physical contradictions through animated visualization of conflict zone with 3 groups of "little people."

**When to use:**
- Physical contradiction identified but resolution unclear
- Need to "see inside" the conflict zone
- Part of ARIZ (Part 4 — MMCh mobilization)

**Output:** Populated zone (A≥5/B≥3/C≥2), conflict dramaturgy, victory configuration, engineering translation (Phase 3.5), Reflection Gate

**Gate Check:**
- All 3 groups populated (A≥5, B≥3, C≥2)
- Conflict described without technical terms
- Victory configuration satisfies both ФП properties
- Engineering translation done (Phase 3.5) with named physical effect
- Reflection Gate (CRITICAL + BLIND SPOT) filled
