## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Задача решается "в лоб" (нет реального противоречия) → используйте @arip или @contradictions
- [ ] Нет данных о системе (нет ОЗ/ОВ) → сначала @socratic + @functional_analysis
- [ ] ФП не сформулировано после 2 попыток → вернитесь к @causal_analysis

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
- ФП отсутствует: Confidence = 30% max
