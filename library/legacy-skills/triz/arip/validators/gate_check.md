# Gate Check for ARIP (Алгоритм Решения Изобретательских Проблем)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Проверены Стандарты (76 стандартов)? | Да | ___ | ✅/❌ |
| Проверены Принципы (40 приёмов)? | Да | ___ | ✅/❌ |
| Если решения нет — вызван @ariz? | Да/N/A | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если не проверены Стандарты — нарушение последовательности TRIZ
- **BLOCK** если решение найдено но не верифицировано через @critic

## Confidence Adjustment
- Все 3 ✅ → confidence ≥ 80%
- 2 чека → confidence 60%
- < 2 → BLOCK
