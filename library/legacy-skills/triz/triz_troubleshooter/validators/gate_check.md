| Check | Required | Actual | Pass? |

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] Проблема описана только интерпретациями без фактов → вернуться к уточнению
- [ ] Ни одного парадокса не найдено → задача не подходит для этого метода, передать в `@causal_analysis`
- [ ] Гипотеза объясняет только 1 из 3+ парадоксов → гипотеза слабая, вернуться к Фазе 2
- [ ] Корневая причина = "система в целом" → не локализовано, передать в `@functional_analysis`

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
- No paradoxes found: Confidence = 30% max (метод не подошёл)
