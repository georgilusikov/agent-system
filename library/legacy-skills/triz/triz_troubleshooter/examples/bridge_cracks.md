# Example: Трещины на новом мосту

## Input
"Новый мост (бетон, 2 года) начал покрываться трещинами. Прочность бетона проверена — соответствует проекту. Нагрузка в пределах нормы. Трещины появляются только на южной стороне моста, хотя конструкция симметрична."

## Execution Trace

### Фаза 0: Фиксация проблемы
- **Система:** Бетонный мост, 2 года эксплуатации
- **Ожидание:** Без трещин при проектной нагрузке (срок службы 50+ лет)
- **Факт:** Трещины на поверхности
- **Контекст:** Только южная сторона; прочность и нагрузка в норме

### Фаза 1: Поиск парадоксов

**Факты:**
1. Бетон соответствует проекту (прочность OK)
2. Нагрузка в пределах нормы
3. Трещины только на южной стороне
4. Конструкция симметрична
5. Мосту всего 2 года

**ПАРАДОКС #1:**
- Ожидание: Если прочность и нагрузка в норме, трещин быть не должно
- Факт: Трещины есть
- Почему странно: Бетон рассчитан с запасом, нагрузка не превышена — по механике всё верно

**ПАРАДОКС #2:**
- Ожидание: Если конструкция симметрична, трещины должны быть с обеих сторон
- Факт: Только южная сторона
- Почему странно: Нагрузка (транспорт) одинакова для обеих сторон; разница — только в ориентации

**ПАРАДОКС #3:**
- Ожидание: Мост должен выдерживать минимум 50 лет
- Факт: Трещины через 2 года
- Почему странно: Скорость разрушения на порядок выше расчётной

### Фаза 2: Генерация гипотез

**ГИПОТЕЗА #1: Термическое воздействие солнца**
- Объясняет парадоксы: #1, #2, #3
- Механизм: Южная сторона получает максимум прямого солнечного света. Циклы нагрев-охлаждение создают термические напряжения в бетоне, которые не учтены в расчёте прочности (расчёт учитывает механическую нагрузку, а не термическую). За 2 года — сотни циклов нагрева до +60°C на поверхности.
- Скрытый фактор: Термические нагрузки не входят в стандартный расчёт прочности

**ГИПОТЕЗА #2: Дефект партии бетона южной стороны**
- Объясняет парадоксы: #2 (только юг), частично #1 (прочность проверена выборочно)
- НЕ объясняет #3: дефект бетона дал бы трещины раньше
- Ослаблена, но не отброшена

### Фаза 3: Тестирование

**ТЕСТ ДЛЯ ГИПОТЕЗЫ #1:**
- Действие: Установить термодатчики на южную и северную стороны, измерить суточный перепад температуры поверхности
- Если верна: Южная сторона покажет перепад >40°C за день; северная <15°C
- Если неверна: Перепад одинаковый с обеих сторон

**ТЕСТ ДЛЯ ГИПОТЕЗЫ #2:**
- Действие: Извлечь керн из южной и северной стороны, сравнить микроструктуру
- Если верна: Микроструктура южного керна хуже (поры, неравномерность)
- Если неверна: Микроструктура одинаковая

### Фаза 4: Корневая причина

- **Элемент:** Термический режим южной поверхности бетона
- **Механизм:** Прямой солнечный нагрев → перепад 50°C между поверхностью и глубиной → термические напряжения → микротрещины → рост через циклы
- **Маскировка:** Стандартный расчёт прочности учитывает механику (вес, ветер), но не термоциклы; прочность "в норме" — но по другим критериям

## Output Summary
- **Корневая причина:** Термоциклическое разрушение от солнечного нагрева
- **Ключевой парадокс:** Асимметрия (только юг) + нормальная прочность → причина не механическая, а термическая
- **Next step:** → `@contradictions` (нужен солнечный свет для видимости, но он разрушает конструкцию) → защитное покрытие или теплоотражающая обработка
