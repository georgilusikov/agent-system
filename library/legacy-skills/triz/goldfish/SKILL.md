# 🧜‍♀️ Goldfish (Золотая Рыбка)

**Purpose:** Separate fantasy from reality to find engineering attack point.

**When to use:**
- User has "impossible" idea
- Need to break down magic into physics
- Looking for "entry point" into problem

**Output:** Real shell / Fantasy core split, recursive "Why?" chain (≥2 levels), physical contradiction, FOS analog, Reflection Gate

**Gate Check:**
- Real shell identified
- Fantasy core localized to one specific element
- ≥2 levels of "Why?" recursion conducted
- Physical Contradiction formulated
- ≥1 FOS analog (nature or industry)
- Reflection Gate (CRITICAL + BLIND SPOT) filled
