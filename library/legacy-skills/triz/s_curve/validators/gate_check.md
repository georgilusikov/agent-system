## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] MPV не определён → нет кривой без MPV, вернуться к @akts
- [ ] FPV не декомпозирован → невозможно оценить предел, углубить анализ
- [ ] Менее 3 индикаторов → диагноз ненадёжен, собрать больше данных
- [ ] Конфликт: график показывает Рост, индикаторы — Зрелость → индикаторы приоритетнее (правило)
- [ ] Нет объяснения, почему диагноз стадии достаточно без ZRTS-перехода → риск перепутать диагностику и laws-of-evolution

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 15%
- 2+ checks fail: Confidence = 50% max
- Нет триангуляции: Confidence -= 30%
- % от предела не рассчитан: Confidence = 40% max
