# Gate Check for 40 Principles

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| ТП сформулировано ("Улучшаем А, ухудшается Б")? | Да | ___ | ✅/❌ |
| Параметры А и Б переведены на язык 39 параметров? | Да | ___ | ✅/❌ |
| Скрипт `triz_matrix_lookup.py` запущен? | Да | ___ | ✅/❌ |
| В ответе номера принципов совпадают с выводом скрипта? | Да | ___ | ✅/❌ |
| Предложено минимум 3 концепта? | ≥3 | ___ | ✅/❌ |
| Каждый концепт содержит конкретный механизм (не абстракцию)? | Да | ___ | ✅/❌ |

## Block Conditions
If any of these are true, **STOP and escalate**:
- [ ] ТП не сформулировано → сначала @contradictions
- [ ] Параметры не из списка 39 → перемапить (не "Цена"→"Вес", а "Цена"→"Потеря энергии" или использовать @trimming)
- [ ] Скрипт не запущен и номера "угаданы" → ЗАПРЕЩЕНО, перезапуск обязателен
- [ ] Концепты абстрактные ("разделите объект") → конкретизировать: чем? на сколько? как?

## Confidence Adjustment
- All checks pass: Confidence += 10%
- 1 check fails: Confidence -= 20%
- 2+ checks fail: Confidence = 50% max
- Номера "угаданы" без скрипта: Confidence = 20% max
