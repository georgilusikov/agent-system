# Case Logger

## Описание
Архивариус ТРИЗ — сохраняет решённые задачи и ищет похожие кейсы для обучения системы.

## Режимы работы

### SAVE — сохранить кейс
Вызывается после:
- Успешного прохождения `@critic`
- Получения результата эксперимента
- Обратной связи о внедрении

### SEARCH — найти похожие кейсы
Вызывается:
- В начале работы над новой задачей
- Когда нужен аналог/прецедент
- Для извлечения уроков

## Что хранит
- Описание проблемы (ОЗ/ОВ, ограничения)
- Анализ (TC/PC, корневая причина, ресурсы)
- Решение (принцип, механизм)
- Результат (успех/провал, метрики, уроки)

## Пример вызова
```
@case_logger SEARCH
Задача: Как нагреть деталь без деформации?
Домен: manufacturing
Противоречие: температура vs стабильность формы
```

```
@case_logger SAVE
[результат решения задачи]
```

## Связанные скиллы
- `@socratic` — уточнить перед поиском
- `@experiment_designer` — сохранить результат эксперимента
- `@final_triz_report` — включить кейсы в отчёт
