# Gate Check for Case Logger

## Minimum Criteria
| Check | Required | Actual | Pass? |
|---|---|---|---|
| Режим (SAVE/SEARCH) явно указан? | Да | ___ | ✅/❌ |
| SAVE: есть `id/date/domain` и короткое название кейса? | Да | ___ | ✅/❌ |
| SAVE: есть ОЗ/ОВ и ограничения (>=2)? | Да | ___ | ✅/❌ |
| SAVE: есть outcome.status и хотя бы 1 метрика (или явно `unknown`)? | Да | ___ | ✅/❌ |
| SEARCH: найдено >= 3 кейса (ID + урок для нас)? | >=3 | ___ | ✅/❌ |
| SEARCH: есть блоки "общие паттерны" и "ошибки" | Да | ___ | ✅/❌ |

## Block Conditions (STOP)
- [ ] SAVE без outcome.status (успех/провал/частично/unknown)
- [ ] SEARCH выдаёт общие советы вместо конкретных кейсов (ID/проблема/решение/исход)
- [ ] Теги слишком общие (`#проблема`, `#решение`) и не помогают поиску

## Output Rules
- SAVE: сначала формируй структуру кейса (YAML или эквивалент), затем короткий markdown‑summary.
- SEARCH: показывай топ‑кейсы с релевантностью и переносимыми уроками.
