# Gate Check for Limits Strategy (Анализ Пределов)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| MPV (Главный Параметр Ценности) определён? | Да | ___ | ✅/❌ |
| Текущий уровень параметра указан? | Да | ___ | ✅/❌ |
| Теоретический предел рассчитан/обоснован? | Да | ___ | ✅/❌ |
| Запас развития посчитан (% от предела)? | Да | ___ | ✅/❌ |
| Стратегия выбрана (углублять/расширять/менять систему)? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если предел не обоснован физически/логически
- **BLOCK** если нет стратегии — анализ без вывода

## Confidence Adjustment
- Все 5 ✅ → confidence ≥ 85%
- 3-4 → confidence 65%
- < 3 → BLOCK
