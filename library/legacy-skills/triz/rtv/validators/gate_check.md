# Gate Check for RTV (Развитие Творческого Воображения)

## Minimum Criteria
| Check | Required | Actual | Pass? |
|-------|----------|--------|-------|
| Тип психологического блока диагностирован? | Да | ___ | ✅/❌ |
| Выбран подходящий инструмент (RVS/MMCh/Goldfish/Robinson)? | Да | ___ | ✅/❌ |
| Объяснено "Why RTV / Why not neighboring tool"? | Да | ___ | ✅/❌ |
| Инструмент выполнен (результат получен)? | Да | ___ | ✅/❌ |
| Получены **≥3 экстремальные трансформации** (ранг ≥3)? | Да | ___ | ✅/❌ |
| Результат переведён в техническое решение? | Да | ___ | ✅/❌ |
| **Приземление заполнено** (реалистичный перенос + инженерное приземление + тест + no-go)? | Да | ___ | ✅/❌ |
| Есть high-surprise, но grounded transformation (ранг ≥4)? | Да | ___ | ✅/❌ |
| Есть финальный grounded concept ИЛИ явный handoff target? | Да | ___ | ✅/❌ |

## Block Conditions
- **BLOCK** если блок не диагностирован — инструмент выбран вслепую
- **BLOCK** если нет перевода в техническое решение — фантазия без выхода
- **BLOCK** если нет приземления с тестом — идея не проверяема
- **BLOCK** если нет Why RTV / Why not neighboring tool — метод выбран неосознанно
- **BLOCK** если нет grounded concept и нет handoff — сессия не доведена до полезного выхода

## Confidence Adjustment
- Все 8 ✅ → confidence ≥ 85%
- 6-7 чеков → confidence 65%
- < 6 → BLOCK
