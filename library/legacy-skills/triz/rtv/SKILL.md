# 🎭 RTV (Creative Imagination Engine)

**Purpose:** Creative imagination engine — diagnoses mental block type, applies tool (RVS/MMCh/Goldfish/Robinson) with inline fallback, grounds result in physics.

**When to use:**
- Stuck on a problem ("It's impossible!" / "No ideas" / "No resources")
- Need creative breakthrough via psychological technique
- Part of ARIZ creative phase

**Output:** Block diagnosis, tool result with ≥1 surprising insight (rank ≥3), engineering translation with measurement test, Reflection Gate

**Gate Check:**
- Block type diagnosed (Невозможно / Скучно / Непонятно / Нет ресурсов)
- Tool selected by diagnostic table (not random)
- ≥1 insight with surprise rank ≥3
- Insight grounded in physics (engineering formulation + measurement test)
- Reflection Gate (CRITICAL + BLIND SPOT) filled
