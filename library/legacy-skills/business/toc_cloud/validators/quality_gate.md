# Quality Gate — TOC Evaporating Cloud
# Based on: W. Dettmer, Ch. 4 "Conflict Resolution Diagram"

## Обязательные проверки

- [ ] **Подход выбран?** Right-to-Left / Left-Right-Center / Clockwise Rotation — с обоснованием выбора.
- [ ] **Все 7 элементов?** O, R1, R2, P1, P2, Assumptions, Injection(s) — все присутствуют.
- [ ] **Вербализация?** Каждая стрелка читается как "Чтобы [O], нам необходимо [R1]" без frikción.
- [ ] **R1 ≠ P1?** Требования (R) не конфликтуют между собой. Конфликт ТОЛЬКО на уровне Prerequisites (P1 vs P2).
- [ ] **≥ 14 допущений?** Минимум 3 на каждую из 4 основных стрелок + 2 на стрелку конфликта (P1↔P2).
- [ ] **Outrageous-формулировка?** Каждое допущение записано провокационно ("Конечно, АБСОЛЮТНО НЕВОЗМОЖНО...").
- [ ] **Все 5 стрелок проверены?** Не зациклились на одной стрелке — checked all arrows.
- [ ] **≥ 1 ложное допущение?** Найдено и классифицировано (Привычка / Экономика / Физика).
- [ ] **Инъекция через "Альтернативную среду"?** "Как иметь R без P?" — перечислены альтернативы.
- [ ] **Тип инъекции?** Указан: Действие (Action) или Условие (Condition).
- [ ] **NBR выполнен?** Побочные эффекты проверены, новые конфликты не созданы (или обработаны мини-Тучей).
- [ ] **Нет компромисса?** Инъекция НЕ является "50/50 split". Конфликт ИСПАРЁН, а не сглажен.
