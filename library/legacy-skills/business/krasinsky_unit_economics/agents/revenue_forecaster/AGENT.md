# 📈 Revenue Forecaster

## Назначение
Прогнозирует выручку на основе когортного анализа и исторических паттернов поведения пользователей, избегая ловушек линейной экстраполяции.

## Когда Использовать
- При планировании бюджета на следующий период
- Для оценки достижимости целей топ-менеджмента
- При прогнозировании роста подписного бизнеса
- Для валидации маркетинговых планов
- Перед принятием решений о масштабировании

## Входные Данные
- Исторические данные по когортам (минимум 3-6 месяцев)
- Данные о новых пользователях по периодам
- Метрики удержания (retention) по когортам
- Метрики монетизации (ARPPU, average check) по когортам
- Планы по привлечению новых пользователей
- Сезонные факторы (если применимо)

## Алгоритм

### Шаг 1: Подготовка Исторических Данных

Соберите данные по всем существующим когортам:

```
Для каждой когорты:
- Размер когорты при создании
- Выручка по месяцам/неделям
- Retention rate по периодам
- ARPPU по периодам
- Повторные покупки (repeat purchase rate)
```

**Важно:** Используйте фактические данные, а не агрегированные средние!

### Шаг 2: Анализ Паттернов Когорт

Найдите закономерности в исторических данных:

**Вопросы для анализа:**
- Каковы средние показатели retention для каждого периода?
- Есть ли улучшение или ухудшение метрик от когорты к когорте?
- Какие когорты выбиваются из паттерна?
- Есть ли сезонные эффекты?

**Пример паттерна:**
```
Period 0: 100% активны
Period 1: 45% остаются
Period 2: 32% остаются
Period 3: 28% остаются
Period 4+: ~25% плато
```

### Шаг 3: Прогноз Существующих Когорт

Для каждой существующей когорты:

1. **Возьмите фактические данные** до текущего периода
2. **Примените исторические паттерны** для будущих периодов
3. **Рассчитайте ожидаемую выручку** на каждый будущий период

**Формула:**
```
Future_Revenue_Cohort_n = Active_Users_n × ARPPU_avg × Retention_avg
```

### Шаг 4: Прогноз Новых Когорт

Для плановых новых пользователей:

1. **Возьмите план привлечения** по периодам
2. **Примените усредненные паттерны** новых когорт
3. **Рассчитайте ожидаемую выручку** для новых когорт

**Формула:**
```
Future_Revenue_New_Cohorts = Σ(New_Users_per_period × Expected_ARPPU × Expected_Retention_Curve)
```

### Шаг 5: Суммирование и Валидация

**Общая формула прогноза:**
```
Total_Future_Revenue = Σ(Existing_Cohorts_Projected) + Σ(New_Cohorts_Projected)
```

**Проверки валидности:**
- Сравните с текущим трендом
- Проверьте на аномальные скачки
- Валидируйте против внешних факторов (сезонность, рынок)
- Сравните с планом топ-менеджмента

### Шаг 6: Создание Сценариев

Создайте 3 сценария:

**Оптимистичный:**
- Лучшая конверсия из истории
- Лучший retention из истории
- Верхняя граница плана привлечения

**Реалистичный:**
- Средние показатели из истории
- План привлечения как есть
- Учет тренда улучшения/ухудшения

**Пессимистичный:**
- Худшая конверсия из истории
- Худший retention из истории
- Нижняя граница плана привлечения

### Шаг 7: Управление Ожиданиями

**Подготовка презентации для топ-менеджмента:**

1. **Покажите причинно-следственные связи**
   - Откуда взялись цифры
   - Какие когорты дали вклад
   - Какие допущения сделаны

2. **Сравните с планом**
   - Если план нереалистичен — покажите почему
   - Дайте конкретные рычаги для достижения цели
   - Покажите trade-offs

3. **Предложите действия**
   - Что нужно изменить для достижения цели
   - Какие метрики улучшить
   - Какие ресурсы нужны

**НЕ говорите "ваш план херня"** — покажите реалистичный прогноз

## Формулы

### Базовая формула прогноза:
```
Future_Revenue = Σ(Existing_Cohorts × Projected_Metrics) + Σ(New_Cohorts × Projected_Metrics)
```

### Прогноз по существующей когорте:
```
Future_Revenue_Cohort = Active_Users × ARPPU × Retention_Rate
```

### Прогноз по новой когорте:
```
Future_Revenue_New = New_Users × Expected_ARPPU × (1 - Churn_Rate)^Period
```

### Кумулятивная выручка когорты:
```
Cohort_LTV = Σ(Revenue_Period_i) for all periods
```

### Скорректированный план (с учетом improvements):
```
Adjusted_Plan = Baseline_Forecast + Σ(Improvement_Effect_i)
```

## Типичные Ошибки

### Ошибка 1: Линейная экстраполяция
**Проблема:** "У нас 20 продаж в неделю, значит через год будет 20→30→40→45→50"
**Реальность:** Рост редко бывает линейным
**Решение:** Используйте исторические кривые когорт

### Ошибка 2: Агрегированные средние вместо когорт
**Проблема:** "Средний retention = 40%"
**Реальность:** Когорта 1: 50%, Когорта 2: 30%, Когорта 3: 20%
**Решение:** Всегда прогнозируйте по когортам

### Ошибка 3: Игнорирование тренда качества когорт
**Проблема:** Использование среднего retention за все время
**Реальность:** Качество когорт ухудшается (45% → 42% → 40%)
**Решение:** Учитывайте тренд в прогнозе

### Ошибка 4: Отсутствие сценариев
**Проблема:** Один точечный прогноз
**Реальность:** Бизнес неопределен, нужны диапазоны
**Решение:** Давайте 3 сценария с допущениями

### Ошибка 5: Планы на основе фантазии
**Проблема:** "Нам нужно $180M, просто добавим 10% роста в месяц"
**Реальность:** Ни одна когорта так не росла
**Решение:** Покажите реалистичный прогноз на основе данных

### Ошибка 6: Непонимание composition
**Проблема:** "У нас 20 продаж в неделю" (не понятно, новые или старые клиенты)
**Реальность:** Это может быть 15 старых + 5 новых
**Решение:** Всегда разделяйте новые и существующие когорты

## Принципы из ProductDo

### "Планы есть у всех"
> "Я не видел ни одну компанию без плана. Плохой, какой-нибудь, чуть-чуть — у них всегда есть план."

У фаундера без плана всё плохо. Но даже плохой план лучше, чем никакого.

### "Линейная экстраполяция — враг"
> "Люди естественным образом предсказывают линейный рост. Реальность редко бывает линейной."

Используйте паттерны поведения когорт, а не прямые линии.

### "Покажи causal relationships"
> "Не спорьте с планом напрямую. Покажите, откуда взялись цифры."

Когортный анализ показывает причинно-следственные связи за цифрами.

### "Дай рычаги, а не критику"
> "Вместо 'ваш план нереалистичен', покажите, что нужно изменить для достижения цели."

Конкретные улучшения метрик + эффект в деньгах = конструктивная критика.

### "Unit economics = одна строка из когортной таблицы"
> "Юнит-экономика — это выгрузка одной строки из когорты."

Всё связано. Когорты → юнит-экономика → прогноз.

## Примеры из Курса

### Пример 1: Компания с нереалистичным планом (из PHs18.5)
**Ситуация:**
- План топ-менеджмента: $180-200M/год
- План основан на: фантазии аналитика
- Метод: просто добавили процент к прошлым данным
- Результат в реальности: $28M - $242M в разные месяцы (колбасит)

**Проблема:**
- Аналитик построил три сценария: оптимистичный, реалистичный, пессимистичный
- По факту: все сценарии оптимистичные, основаны на фантазии
- Никакой связи с реальностью

**Решение:**
1. Построить прогноз на основе когортного анализа
2. Показать composition (новые vs старые клиенты)
3. Дать конкретные рычаги для улучшения
4. Показать, что план нереалистичен через данные, не через критику

**Урок:** Линейная экстраполяция и фантазия vs когортный анализ

### Пример 2: SaaS подписный сервис (из PHs18.5)
**Модель:**
- B2B/B2C гибрид (фрилансеры используют B2C, агентства — B2B)
- Метрики:
  - 70-80% retention (стандарт для SaaS с рекуррентными платежами)
  - Сильные когорты

**Подход к планированию:**
- Используйте исторические показатели retention по когортам
- Прогнозируйте на основе привлечения новых пользователей
- Фокус на двух метриках: рост новых пользователей и MPPU (ARPPU)

**Прогноз:**
```
Future Revenue = Σ(Existing_Cohorts × 70-80% retention) + (New_Users × Expected_ARPPU)
```

### Пример 3: Интернет-магазин (из PHs18.5)
**Ситуация:**
- ~30M RUB/месяц
- Когортный анализ показал:
  - Только 4% retention до следующего месяца
  - Бизнес сильно зависит от новых клиентов
  - Очень низкий repeat purchase rate

**Прогноз:**
- Без улучшения конверсии: бизнес ограничен ~30M RUB
- С улучшением конверсии с 1% до 2%: потенциал ~60M RUB
- Ключевой рычаг: конверсия в первую покупку

**Урок:** Ограничения бизнеса видны через когортный анализ

### Пример 4: B2B SaaS — 13x рост без фич (из PHs18.5)
**Старт:** $150/неделя → $300,000/месяц за год

**Ключ к прогнозированию:**
- Коммерческие когорты по cycle time
- Паттерны: быстрые (3-4 недели), средние, медленные клиенты
- Прогноз основан на улучшении показателей каждой когорты

**Важный инсайт:**
> "Продукт = не только фичи. Коммуникация с пользователями управляет поведением больше, чем фичи."

## Интеграция с Antigravity
- Автоматически создавать прогноз на основе исторических когорт
- Показывать 3 сценария с допущениями
- Выделять когорты, которые выбиваются из паттерна
- Сравнивать прогноз с планом автоматически
- Рекомендовать конкретные рычаги для достижения целей
- Предупреждать о линейной экстраполяции
