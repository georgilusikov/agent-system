# 📊 Funnel Analysis Module

## Назначение
Модуль для анализа воронки конверсии, выявления точек отсева и расчета статистической значимости улучшений.

## Ключевое Правило (Из курсов)
> "Работайте там, где конверсия 'ломается' сильнее всего (checkout), а не там, где 'большие цифры' (трафик). Рост конверсии дает двойной эффект: рост продаж + снижение CAC."

## Алгоритм Анализа

### 1. Расчет Воронки
Для каждого этапа `N` и `N+1`:
1.  **Конверсия:** `Stage_{N+1} / Stage_N`
2.  **Drop-off:** `Stage_N - Stage_{N+1}` (Абсолют) и `%`
3.  **Доверительный Интервал (95% CI):** `Conv ± 1.96 * sqrt(p*(1-p)/n)`

### 2. Приоритизация
*   ❌ **Ошибка:** Оптимизировать `Users -> Leads` (потому что там миллионы).
*   ✅ **Правильно:** Оптимизировать этап с максимальным относительным drop-off.
*   **Исключение:** Если трафика слишком мало (n < 1000), CI будет слишком широким для выводов.

### 3. Двойной Эффект (Rick.ai)
Всегда оценивайте эффект в деньгах:
*   `Effect = (New_Conv - Old_Conv) * Users * LTV + (CAC_old - CAC_new) * Buyers`
*   Рост конверсии позволяет выигрывать аукционы в рекламе!

## Типичные Ошибки
1.  **Средняя температура:** Смотреть общую конверсию без сегментации (Desktop vs Mobile).
2.  **Рассинхрон:** Данные GA не совпадают с CRM (CRM = source of truth).
3.  **Игнорирование окон:** Не учитывать конверсионное окно (пользователь купил через 30 дней).

## Формат Вывода
```markdown
### 🌪 Funnel Analysis
| Stage | Users | Conv | CI (95%) | Drop-off |
|-------|-------|------|----------|----------|
| Users | 10k   | -    | -        | -        |
| Leads | 2k    | 20%  | ±1.5%    | -80%     |
| Pay   | 200   | 10%  | ±4.2%    | -90% 🔴  |

**Recommendation:** Focus on Leads -> Pay. Drop-off is critical (-90%).
```
