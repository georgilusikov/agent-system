# Back-of-the-Envelope Viability Check (Проверка на Салфетке)

**Источник:** Refined Unit Economics Toolkit
**Назначение:** Быстрая (5-15 минут) проверка жизнеспособности идеи БЕЗ написания кода.

## 🧠 Mindset: "Продукт никому не нужен"
Исходите из того, что ваш продукт — это "багованный кусок кода", который заставляет юзера менять привычки.
1.  **Продавайте Терапию, а не Фичи:** Людям плевать на функции. Им нужно снять тревогу, страх или сэкономить время.
2.  **B2B — это про Отчеты:** ЛПР (Лицо Принимающее Решение) часто не пользуется продуктом. Он покупает *отчет* или *результат*, который можно показать боссу, чтобы получить премию или не быть уволенным.

## 🔍 Channel/Price Matrix (Проверка адекватности Канала)
Ваша цена диктует, как вы можете продавать. Не пытайтесь продавать дешевый продукт через личные встречи!

| Чек (Price) | Канал продаж (Channel Strategy) | Тип продаж (Sales Motion) |
| :--- | :--- | :--- |
| **< $10** | Viral / SEO / Organic | **Automatic** (No humans involved) |
| **$10 - $100** | Paid Ads (FB/Google/Tg) | **Automatic** (Self-service funnel) |
| **$100 - $2k** | Content / Webinars / Lead Magnets | **Low-touch** (Automated onboarding + support) |
| **> $10k** | Direct Sales / Networking | **High-touch** (Meetings, Demos, Negotiations) |

> **⚠️ The Dead Zone ($100 - $5,000):**
> Самая опасная зона. Продукт слишком дорогой для импульсивной покупки с рекламы, но слишком дешевый, чтобы окупить зарплату продавца.
> *Решение:* Либо снижать цену и автоматизировать, либо повышать ценник и нанимать sales-команду.

## 🛑 The "STOP" Checklist
Остановитесь и переосмыслите идею, если:
1.  [ ] **CPA > 50% от Цены** (при LTV < 2 покупок).
2.  [ ] Цена попадает в **"Мертвую Зону"** ($100-$5k), но вы планируете звонить клиентам.
3.  [ ] Вы рассчитываете на **"виральный рост"** при конверсии < 1% (K-factor будет < 1).
4.  [ ] Бизнес-модель требует **100 фич** для первого запуска (продавайте решение симптома, а не комбайн).
5.  [ ] **B2B:** Продукт не генерирует понятный "Отчет для Босса".

## 📐 Формула для Салфетки

```python
Viability = (Conversion * Price) - (CPA + COGS)
```

*Если результат < 0 — идея мертва.*

**Benchmarks:**
- B2C Conversion: 1-3%
- B2B Conversion: 0.5-2%
- Digital COGS: ~5% (эквайринг + сервера)
