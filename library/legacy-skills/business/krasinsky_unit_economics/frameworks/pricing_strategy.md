# Pricing Strategy Framework

**Источник:** ARTICLE_Spolsky_Pricing.txt
**Версия:** 1.0.0
**Автор:** Joel Spolsky

## Суть
Ценообразование — это баланс между слишком низкой ценой (банкротство от нехватки прибыли) и слишком высокой (банкротство от нехватки клиентов). Цель бизнеса — максимизировать прибыль, а не количество продаж, через сегментацию клиентов по их готовности платить.

## Пошаговый Алгоритм

### 1. Анализ Кривой Спроса
- Поймите: кривая спроса всегда убывает (выше цена → меньше клиентов)
- Найдите точку оптимума: максимум прибыли, не максимум продаж
- Рассчитайте: Profit = (Price - Variable Cost) × Quantity Sold

### 2. Сегментация по Потребительскому Излишку
- Определите потребительский излишек для каждого сегмента
- Consumer Surplus = Willingness to Pay - Actual Price
- Создайте тарифы для захвата излишка разных сегментов
- Избегайте "безлимитного" подхода (одна цена для всех)

### 3. Анализ Рыночного Пробела
- **До $1000:** Self-service, быстрые платежи, низкий CAC
- **$1000 - $75,000:** Опасная зона (требует корпоративных процедур)
- **$75,000+:** Enterprise sales, длинный цикл, высокая маржа

### 4. Расчет NPV (Временная Стоимость Денег)
- Дисконтируйте будущие платежи: NPV = Σ (Cash Flow / (1 + r)^t)
- Сравните одномоментный payment vs подписку
- Учитывайте инфляцию и возможность инвестирования

### 5. Выбор Стратегии
- Self-service ($0-$1000) → автоматизация, низкий CAC
- Mid-market ($1000-$10000) → телесная поддержка
- Enterprise ($10000+) → персональный менеджер

## Ключевые Метрики/Формулы

### Основные Формулы
```
Consumer Surplus = Willingness to Pay - Actual Price

NPV = Σ (Cash Flow_t / (1 + r)^t)

Profit = (Price - Variable Cost) × Quantity Sold
```

### Ставка Дисконтирования
- Обычно: 10-20% для бизнеса
- Учет инфляции + возможности инвестирования + риск

## Типичные Ошибки

### 1. Одна Цена для Всех (Безлимитный Подход)
**Проблема:**
- Крупные клиенты (IBM, Google) готовы платить больше
- Малый бизнес отпугивается высокой ценой
- Теряете прибыль на обоих концах

**Решение:** Сегментируйте и создавайте тарифы для каждого сегмента

### 2. Игнорирование Рыночного Пробела
**Проблема:**
- Цена $2000 попадает под корпоративные процедуры закупок
- Требуются тендеры, согласования CEO, долгий цикл
- Нет команды продаж для работы с этим диапазоном

**Решение:**
- Либо <$1000 (self-service)
- Либо >$75000 (enterprise sales)

### 3. Не Учет NPV
**Проблема:**
- Сравниваете номинальные суммы без дисконтирования
- $100 сейчас ≠ $100 через год

**Решение:** Всегда дисконтируйте будущие потоки

### 4. Максимизация Выручки Вместо Прибыли
**Проблема:**
- Фокус на количестве продаж
- Игнорирование переменных затрат
- Больше продаж ≠ больше денег

**Решение:** Оптимизируйте прибыль, не выручку

### 5. Отсутствие Сегментации
**Проблема:**
- Все клиенты разные по готовности платить
- Одна цена оставляет деньги на столе

**Решение:** Создайте ценовую лестницу для разных сегментов

## Ключевые Принципы

1. **Кривая спроса всегда убывает** — выше цена, меньше клиентов
2. **Максимизируй прибыль, а не продажи** — количество ≠ деньги
3. **Сегментируй по готовности платить** — разные клиенты = разные цены
4. **Учитывай рыночный пробел** — $1000 меняет всё
5. **Деньги сейчас стоят больше** — всегда дисконтируй будущие потоки
6. **Захватывай потребительский излишек** — не оставляй деньги на столе

## Примеры Применения

### Oracle Strategy (Enterprise Pricing)
- Очень дорогой софт: $75,000+
- Требует профессиональных продажников
- Длинный цикл сделки (6-18 месяцев)
- Высокая маржинальность оправдывает усилия

### Почему Это Работает
- Enterprise клиенты имеют бюджет
- Готовы платить за надежность и поддержку
- LTV одного клиента огромен
- Высокая цена = сигнал качества

## Интеграция с Другими Фреймворками

### Связь с Unit Economics
- Цена влияет на ARPU и ARPPU
- Сегментация цен нужна для когортного анализа
- LTV расчеты требуют NPV дисконтирования

### Связь с CJM (Customer Journey Map)
- Разные сегменты имеют разные пути покупки
- Enterprise требует longer sales cycle
- Рыночный пробел влияет на touchpoints

## Рекомендации по Применению

1. **Начните с анализа готовности платить** — опросы, интервью, A/B тесты
2. **Создайте ценовую лестницу** — 3-5 тарифов для разных сегментов
3. **Тестируйте цены** — небольшие изменения могут дать +20% прибыли
4. **Учитывайте затраты на продажи** — enterprise требует команды
5. **Мониторьте конверсию** — разные цены дают разную конверсию
6. **Пересматривайте цены** — рынок меняется, обновляйте тарифы
