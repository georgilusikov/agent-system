# Amplitude Analytics

**Источник:** ARTICLE_GoPractice_Amplitude.txt
**Версия:** 1.0.0

## Суть
Amplitude — продвинутая система продуктовой аналитики, которая позволяет гибко настраивать отчеты по удержанию, воронкам и поведенческим когортам, а также находить корреляции между ранними действиями пользователей и их долгосрочной лояльностью (Aha-moment).

## Пошаговый Алгоритм

### 1. Выберите тип анализа

**Сегментация ивентов (Event Segmentation):**
- Разбивка одного события по параметрам (страны, устройства, источники)
- Для анализа распределения метрик

**Выделение сегментов пользователей (User Segmentation):**
- Создание групп людей по критериям (iOS vs Android, Платящие vs Неплатящие)
- Применяется глобально ко всем отчетам

### 2. Настройте Retention отчет

**Типы Retention:**

**Rolling Retention:**
- Пользователь вернулся в течение N дней
- Либеральный подход
- Пример: Rolling 7-day = вернулся в любой из дней 1-7

**Fixed Period Retention:**
- Пользователь вернулся точно на день N
- Строгий подход
- Пример: Day 7 retention = вернулся ровно на 7-й день

**Custom Period:**
- Настраиваемые интервалы (день/неделя/месяц)
- Выбор в зависимости от типа продукта

### 3. Постройте Воронку с конверсионным окном

**Конверсионное окно (Conversion Window):**
- Временной период для следующего шага воронки
- Критически важно для точного расчета

**Примеры:**
- 24 часа на завершение покупки после добавления в корзину
- 7 дней на регистрацию после первого визита
- 30 дней на повторную покупку

### 4. Создайте поведенческие когорты

**Определение:** Сегмент пользователей, совершивших или НЕ совершивших действие.

**Примеры:**
- Отброшенные корзины (добавили, но не купили за 24ч)
- Неактивные (не заходили 30+ дней)
- Power users (5+ покупок за месяц)

### 5. Используйте Compass для Aha-moment

**Compass:** Поиск корреляций между ранними действиями и долгосрочным retention.

**Алгоритм:**
1. Определите целевой retention (Day 30 > 20%)
2. Запустите Compass (период: первые 7 дней)
3. Найдите действия с наивысшим impact score
4. Валидируйте A/B тестом
5. Интегрируйте в onboarding

**Примеры Aha-moments:**
- Facebook: 10 друзей в первые 7 дней
- Slack: 2000 сообщений
- Spotify: 50 песен в плейлисте

### 6. Изучайте профили пользователей

**User Profiles:** Детальная последовательность событий конкретного человека.

**Применение:**
- Найдите аномального пользователя в когорте
- Откройте его профиль
- Изучите последовательность событий
- Поймите причину поведения

## Ключевые Метрики

**Retention Types:**
- Rolling Retention (скользящее)
- Fixed Retention (точечное)
- Custom Period (настраиваемое)

**Funnel Metrics:**
- Conversion с учетом окна
- Time to convert
- Drop-off по сегментам

**Compass Metrics:**
- Correlation score (корреляция действия с retention)
- Impact score (влияние на долгосрочное удержание)
- Aha-moment (ключевое действие)

## Типичные Ошибки

**Ошибка 1: Игнорирование конверсионных окон**
- Проблема: Завышение конверсии (пользователь через месяц)
- Решение: Установите реалистичные окна для каждого этапа

**Ошибка 2: Смешивание сегментаций**
- Проблема: Event segmentation vs User segmentation
- Решение: Понимайте разницу и используйте правильно

**Ошибка 3: Корреляция = каузация**
- Проблема: Compass находит корреляцию, а не причину
- Решение: Всегда валидируйте A/B тестом

**Ошибка 4: Один тип retention для всех**
- Проблема: Fixed retention слишком строгий
- Решение: Используйте Rolling для долгосрочного, Fixed для точного анализа

**Ошибка 5: Игнорирование профилей**
- Проблема: Агрегированные данные скрывают паттерны
- Решение: Изучайте отдельных пользователей из когорт
