# System Value Formula (Формула Работоспособной Системы)

**Источник:** ARTICLE_Bureau_Formula.txt
**Версия:** 1.0.0
**Автор:** Бюро Горбунова

## Суть
Система становится работоспособной только тогда, когда находит и начинает выполнять своё полезное действие, которое мотивировано реальной потребностью, инстинктом или чувством пользователя. Без "потому что" (источника энергии) не заработает ни один стартап.

## Пошаговый Алгоритм

### 1. Декомпозиция системы
Выделите элементы:
- Пользователи (кто?)
- Интерфейсы (через что?)
- Функции (что可以做?)
- Объекты (над чем?)

### 2. Формулировка формулы
```
[Элементы] [Взаимодействие] [Объект] потому что [Мотивация/Сила]
```

**Критически важно:** "потому что" — это источник энергии системы

### 3. Проверка на жизнеспособность
- Уберите "потому что" — осталось ли действие?
- Есть ли источник движения?
- Хочет ли пользователь это сам?

### 4. Поиск полезного действия
- Какую ПРАВДУ о мире использует продукт?
- Какой инстинкт/потребность активирует?
- Какую боль закрывает?

### 5. Итерация
Изменяйте элементы, объект или мотивацию пока формула не станет правдой.

## Ключевые Метрики

### Индекс Работоспособности Системы
```
System_Viability_Index = (Motivation_Strength × Action_Clarity × Element_Availability) / 3
```

**Шкала:**
- 8-10: Система будет работать
- 5-7: Требуется доработка
- 1-4: Система не жизнеспособна

### Энергетический Баланс
```
Energy_Balance = User_Intrinsic_Motivation - Required_Effort
```

## Типы Мотивации (Источники Энергии)

1. **Инстинкты** — голод, безопасность, размножение, принадлежность
2. **Эмоции** — скука, страх, радость, любопытство, гнев
3. **Социальные потребности** — признание, статус, связь, конкуренция
4. **Культурные традиции** — "так принято", "все так делают"
5. **Рациональные выгоды** — сэкономить время, деньги, силы

## Типичные Ошибки

### 1. "Продукт для Продукта"
Создание функции которая никому не нужна
**Признак:** Нет "потому что" в формуле

### 2. "Заставим Пользователя"
Попытка мотивировать внешним стимулом
**Реальность:** Если не ХОЧУ сам → не будет работать

### 3. "Рациональный Пользователь"
Уверенность что люди действуют логично
**Реальность:** Люди действуют по мотивации, инстинктам, эмоциям

### 4. "Это Очевидно"
Пропуск проверки "потому что"
**Реальность:** "Очевидно" ≠ "Правда"

## Примеры

### YouTube
**Правильно:** "Пользователи смотрят видео **потому что** им скучно и они хотят развлечения"
- Полезное действие: Entertainment
- Мотивация: Скука → потребность в развлечениях

### Неправильная формула
**Неправильно:** "Пользователи смотрят видео"
- Нет "потому что"
- Нет источника энергии
- Система не работает

## Ключевые Принципы

1. **Нет мотивации = нет системы** — без "потому что" не работает
2. **Мотивация = источник энергии** — в ней сила движения
3. **Хочу ≠ Могу** — кнопка не означает желание нажать
4. **Правда о людях > Ваше желание** — пользователи такие какие они есть
5. **Инстинкты и эмоции > Логика** — люди иррациональны
