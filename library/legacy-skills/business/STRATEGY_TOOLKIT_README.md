# 🧰 Strategy Toolkit

**Назначение:** Общий набор стратегических инструментов, доступных всем департаментам.

---

## 📋 Содержимое

### 1. Theory of Constraints Analyzer
**Когда использовать:** Система не справляется с нагрузкой, есть bottleneck.
**Что делает:** Находит "узкое горлышко" и показывает, как его эксплуатировать.

### 2. Thinking Processes Analyzer
**Когда использовать:** Конфликт между двумя взаимоисключающими требованиями.
**Что делает:** Использует "Грозовую Тучу" Голдратта для разрешения без компромисса.

### 3. System Value Architect
**Когда использовать:** Продукт/фича готова, но никто не пользуется.
**Что делает:** Проверяет формулу: "[Действие] потому что [Мотивация]". Если "потому что" нет — система мертва.

### 4. ISRICE Prioritizer
**Когда использовать:** 50-100 гипотез, нужно быстро отфильтровать топ-15.
**Что делает:** Ранжирует по формуле: (Reach × Impact × Confidence) / Effort.

### 5. Hypothesis Cost Calculator
**Когда использовать:** Нужно решить, стоит ли тратить ресурсы на проверку гипотезы.
**Что делает:** Считает цену проверки и ожидаемый ROI.

---

## 🔗 Как Использовать

Любой департамент может вызвать эти агенты:
- **Product Manager:** Для приоритизации гипотез и поиска bottleneck в воронке.
- **Philosopher:** Для разрешения логических конфликтов.
- **Content Factory:** Для проверки мотивации контента.
