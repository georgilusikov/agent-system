# Multimodal Video Retakes Editor

Профессиональный стандарт и модуль для сквозного монтажа «сырых» видеозаписей говорящих голов (talking-head), содержащих множество повторов, оговорок, фальстартов и дублей.

Основан на синергии **пословной ASR-разметки (Whisper)**, **прямого мультимодального отсмотра кандидатов моделью (через `view_file` видео/аудио)** и **прецизионной сборки таймлайна в FFmpeg** с микро-кроссфейдами и очисткой от пре-речевых причмокиваний.

---

## Назначение (РАДИ ЧЕГО)

Этот skill нужен, когда у пользователя есть сырая запись (например, на 5–15 минут), где спикер повторяет реплики по несколько раз, и требуется:
- `исходник содержит 3-10 дублей каждой реплики`
- `нужно найти и оставить только идеальные дубли без оговорок и пауз`
- `нужно собрать единый связный ролик без щелчков звука и фазовых искажений`

Цель: автоматизировать отбор лучших дублей с человеческим качеством режиссуры, используя мультимодальные способности модели по оценке мимики, взгляда и дикции.

## When NOT to Use

- Видео уже без дублей и нужно только нарезать зумы и субтитры $\to$ `/talking-head-jumpcut-zoom`
- Задача требует многокамерного монтажа (multicam sync) $\to$ сторонний софт (Premiere/DaVinci)
- Простая конвертация формата без смыслового монтажа $\to$ прямой вызов `ffmpeg`

## Протокол монтажа (КАК)

### §1. Инспекция контейнера и извлечение пословного транскрипта
1. Выполнить `ffprobe` для проверки разрешения, fps, ориентации (`rotation` / display matrix) и аудиопотока.
2. Извлечь аудио и запустить Whisper с пословными таймкодами (`word_timestamps=True`).
3. Зафиксировать структуру предложений и таймкоды каждого слова в `transcript_words.json`.

```bash
python3 -c "
import whisper, json
model = whisper.load_model('base')
res = model.transcribe('input.mov', language='ru', word_timestamps=True)
with open('transcript_words.json', 'w') as f: json.dump(res, f, ensure_ascii=False, indent=2)
"
```

### §2. Семантическая кластеризация дублей
1. Разбить транскрипт на смысловые блоки (тезисы сценария).
2. Сгруппировать все повторяющиеся попытки внутри каждого блока в группу кандидатов:
   - `Блок 1 (Хук)`: Дубль 1.1 (0:01–0:23), Дубль 1.2 (0:33–0:57)
   - `Блок 2 (Аргумент)`: Дубль 2.1 (1:01–1:15), Дубль 2.2 (1:19–1:43)
3. Автоматически отбросить явный текстовый брак: оборванные фразы, фальстарты, смех, оговорки.

### §3. Нарезка и прямой мультимодальный отсмотр кандидатов
Для оставшихся кандидатов каждого блока:
1. Нарезать легковесные `.mp4` видеоклипы кандидатов в `scratch/video_takes/`.
2. **Мультимодальный отсмотр**: агент вызывает инструмент `view_file` для каждого видеоклипа и оценивает:
   - **Зрительный контакт**: смотрит ли спикер прямо в объектив (`at_camera`) на старте и финише фразы;
   - **Мимика и энергия**: уверенная подача, отсутствие растерянности или зажатости;
   - **Чистота дикции**: отсутствие запинок, проглоченных окончаний и проглатываний звуков;
   - **Акустический комфорт**: отсутствие глубоких шумных вздохов и резких причмокиваний.
3. Применить **Last Take Rule (Правило последнего дубля)** как базовую эвристику (в 85–90% случаев финальный дубль — самый чистый), подтверждая его видео-отсмотром.

### §4. Прецизионная микро-подрезка стыков (Clean Speech & Anti-Smack)
1. **Pre-speech trim**: сдвинуть точку старта дубля на 50–120 мс вперёд — строго к началу первого звука, срезая предшествующий вдох и размыкание губ.
2. **Post-speech trim**: остановить сегмент через 50–100 мс после финального согласного/гласного звука, не дожидаясь отвода взгляда или выдоха.
3. **Audio crossfade**: установить 25 мс микро-фейды (`afade=t=in:d=0.025`, `afade=t=out:d=0.025`) на границах каждого сегмента для устранения кликов постоянного тока (DC offset).

### §5. Аудио-гигиена без фазовой деградации
**Критическое правило**: Запрещено применять агрессивный FFT spectral subtraction или резкие гейты ко всей дорожке — это порождает фазовые искажения («звук под водой/роботизацию»).
Безопасная цепочка обработки:
- `highpass=f=60..80` — мягкий срез инфразвукового гула кузова/микрофона;
- `loudnorm=I=-14:TP=-1:LRA=7` — платформенная нормализация громкости под соцсети;
- Опционально: подмешивание тонкой интершумной подложки (`volume=0.05..0.07`) или Lo-Fi музыки (-22 дБ) для маскировки смены акустики на стыках.

### §6. Чистовая сборка таймлайна через FFmpeg
1. Сформировать непрерывный `filter_complex` со всеми выбранными сегментами.
2. Срендерить мастер-файл (1080x1920, H.264, crf 17, 30 fps, Rec.709).
3. Экспортировать `captions.srt` с таймкодами, привязанными к хронометражу чистового мастера (`out_ms`).

## Definition of Done (DoD)

- [ ] Входной файл размечен по словам через Whisper с точностью до миллисекунды.
- [ ] Все дубли сгруппированы по смысловым блокам сценария.
- [ ] Каждый кандидат-дубль отсмотрен агентом напрямую через `view_file`.
- [ ] В итоговый таймлайн вошли только лучшие дубли без повторов и оговорок.
- [ ] На аудиостыках применены 25 мс микро-кроссфейды (0 аудиокликов).
- [ ] Пре-речевые причмокивания и вдохи перед стартом фраз подрезаны.
- [ ] Звук сохраняет 100% естественный тембр (без фазовых искажений и спектрального «аквариума»).
- [ ] Сформирован файл субтитров `captions.srt` с таймкодами чистового мастера.
- [ ] Мастер-файл успешно воспроизводится и имеет статус GO.

## Известные грабли (Anti-Recurrence)

1. **Агрессивный FFT шумодав**: попытка вычистить 100% шума и цоканий через спектральный гейт превращает голос в металлический/роботизированный $\to$ *Защита:* оставлять живой органический звук, убирать цоканья точечной подрезкой границ фраз и микро-пауз, а не спектральной фильтрацией.
2. **Разрезание видео вслепую на равные отрезки**: нарезка по 15–30 секунд режет слова пополам $\to$ *Защита:* резать строго по временным границам слов из ASR-транскрипта.
3. **Хвост предыдущего дубля в склейке**: если оставить 200 мс перед началом чистового дубля, туда попадает обрывок предыдущей запинки $\to$ *Защита:* подрезать границу точно за 50 мс до первого слова.
4. **Неверная ориентация iPhone видео**: файлы MOV с iPhone содержат тег `rotation -90` $\to$ *Защита:* проверять ffprobe и гарантировать правильное вертикальное кадрирование 1080x1920 на выходе.

---

## FORBIDDEN

- Запрещено резать видео на одинаковые временные куски вслепую без пословной ASR-разметки.
- Запрещено применять агрессивный спектральный шумодав, разрушающий естественный тембр голоса.
- Запрещено выбирать дубль «вслепую» только по длине текста без прямого просмотра видеоклипа через `view_file`.
- Запрещено оставлять в финальном мастере дублирующиеся варианты одной и той же мысли.
- Запрещено фальсифицировать факт отсмотра видео (см. `no-fabricated-evidence.md`).

---

## Hard fail

- В итоговом видео остался неудачный дубль или повтор реплики.
- Голос звучит с металлическими фазовыми искажениями («эффект робота»).
- Слова на стыках склеек обрезаны на полуслове.
- Таймкоды субтитров SRT рассинхронизированы с чистовым мастером.
