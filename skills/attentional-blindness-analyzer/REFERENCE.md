# Attentional Blindness Analyzer — Полный справочник

## Подробная методология

### Шаг 1: Анализ точек фокусировки

1. Определите основную задачу, на которой концентрируется пользователь
2. Выявите все элементы, требующие внимания пользователя
3. Оцените уровень концентрации (низкий/средний/предельный)
4. Определите, сколько объектов пользователь должен отслеживать одновременно

### Шаг 2: Выявление потенциально невидимых элементов

1. Составьте список всех объектов/сигналов в ситуации
2. Разделите их на категории:
   - **Ожидаемые**: связанные с основной задачей
   - **Неожиданные**: не связанные с задачей или появляющиеся внезапно
3. Для каждого неожиданного элемента оцените вероятность заметности

### Шаг 3: Оценка рисков слепоты невнимания

Для каждого критического элемента проведите оценку:

**Факторы риска:**
- Высокая концентрация на одной задаче
- Нагрузка на когнитивную память (счёт, параллельные операции)
- Сложность отвлекающих факторов
- Неожиданность появления элемента
- Перегруженность визуального поля

**Последствия пропуска:**
- Критические: угроза жизни/здоровью
- Серьёзные: финансовые потери, репутационный ущерб
- Минимальные: небольшие неудобства

### Шаг 4: Разработка стратегий минимизации

**Для интерфейсов и UX:**
1. Используйте контраст и движение для критических элементов
2. Применяйте иерархию визуального внимания
3. Избегайте перегрузки интерфейса
4. Тестируйте с пользователями в условиях нагрузки

**Для обучения и тренингов:**
1. Демонстрируйте эффект невидимой гориллы
2. Тренируйте переключение внимания между задачами
3. Учите выделять главное среди второстепенного
4. Развивайте осознанность через практику

**Для процессов и процедур:**
1. Внедрите двойной контроль для критических операций
2. Используйте систематические чек-листы
3. Добавьте принудительные паузы для сканирования ситуации
4. Автоматизируйте обнаружение критических событий

### Шаг 5: Проверка на манипулятивные техники

1. Анализируйте: не используют ли ситуацию для отвлечения внимания?
2. Выявляйте «слышимые, но незначительные» элементы
3. Проверяйте: не закрывают ли мелочи главное?
4. Оценивайте честность намерений

## Формулы и модели

**Базовая модель:**
```
Вероятность_Заметки = f(Контраст, Движение, Ожидаемость, Когнитивная_Нагрузка)
```

**Факторы снижения заметности:**
- Предельная концентрация: ×0.5
- Параллельный счёт/анализ: ×0.3
- Неожиданность появления: ×0.2
- Статичный объект: ×0.6

---

## Принципы слепоты невнимания

1. **Избирательность внимания** — сознание анализирует лишь часть происходящего
2. **Дорисовывание реальности** — мозг заполняет пробелы ожидаемыми образами
3. **Предельная концентрация** — фокус на одной задаче сужает поле восприятия
4. **Неожиданность = невидимость** — неожиданные объекты чаще игнорируются
5. **Когнитивная нагрузка** — параллельные задачи усиливают эффект

---

## Типичные ошибки

1. **Недооценка неожиданности** — предположение, что пользователь заметит «очевидное»
2. **Перегрузка интерфейса** — слишком много элементов требуют внимания
3. **Игнорирование контекста** — забывают о реальных условиях использования
4. **Отсутствие тестирования** — не проверяют в условиях стресса/нагрузки
5. **Полагание на «здравый смысл»** — игнорирование когнитивных ограничений

## Примеры из источников

### Пример 1: Эксперимент с гориллой (1975)
**Ситуация:** Испытуемые считали пасы мяча между игроками в белых футболках

**Фактор:** Предельная концентрация на счёте

**Результат:** 50% участников не заметили человека в костюме гориллы, проходившего сквозь игру

**Урок:** Концентрация на одной задаче делает неожиданные объекты невидимыми

### Пример 2: Авиация
**Ситуация:** Пилоты концентрируются на показаниях приборов

**Пропущенный элемент:** Самолёт на взлётно-посадочной полосе

**Последствия:** Аварии и столкновения

**Решение:** Двойной контроль, сканирование ситуации, систематические процедуры

### Пример 3: Вождение
**Ситуация:** Водитель увлечён сложным разговором по телефону

**Фактор:** Когнитивная нагрузка от разговора

**Риск:** Невидимость препятствий на дороге

**Решение:** Запрет разговоров за рулём, тренировка переключения внимания

## Связь с другими методологиями

- **UX/UI Design:** напрямую связано с принципами внимания и иерархии
- **Cognitive Load Theory:** слепота невнимания — следствие перегрузки
- **Situation Awareness:** внимание — базовый компонент ситуационной осведомлённости
- **Behavioral Economics:** объясняет нерациональное поведение пользователей

---

## Практические упражнения для тренировки

1. **Тест с гориллой** — показывать видео для демонстрации эффекта
2. **Подсчёт с отвлечениями** — тренировка переключения внимания
3. **Сканирование окружения** — упражнение на выделение главного
4. **Игра «Найди изменения»** — развитие наблюдательности
5. **Медитация осознанности** — тренировка мета-внимания
