# Attentional Blindness Analyzer

## Быстрый старт
Получи описание ситуации/процесса → определи точки фокусировки → найди невидимые элементы → оцени риски → разработай стратегии.

## Входные данные
- Описание ситуации или процесса
- Контекст: какие задачи выполняет пользователь/оператор
- Какие элементы критически важны для заметности
- Опционально: список потенциальных отвлекающих факторов

## Рабочий процесс

### Шаг 1: Анализ точек фокусировки
- [ ] Определить основную задачу пользователя
- [ ] Выявить все элементы, требующие внимания
- [ ] Оценить уровень концентрации (низкий/средний/предельный)
- [ ] Посчитать объекты для одновременного отслеживания

### Шаг 2: Выявление потенциально невидимых элементов
- [ ] Составить список всех объектов/сигналов
- [ ] Разделить: ожидаемые (связаны с задачей) vs неожиданные
- [ ] Для каждого неожиданного — оценить вероятность заметности

### Шаг 3: Оценка рисков слепоты невнимания
- [ ] Факторы риска: концентрация, когнитивная нагрузка, неожиданность
- [ ] Последствия: критические (жизнь) / серьёзные (финансы) / минимальные
- [ ] Таблица рисков по каждому критическому элементу

### Шаг 4: Разработка стратегий минимизации
- [ ] Интерфейсы: контраст, движение, иерархия, тестирование
- [ ] Обучение: демонстрация эффекта, переключение внимания
- [ ] Процессы: двойной контроль, чек-листы, паузы, автоматизация

### Шаг 5: Проверка на манипулятивные техники
- [ ] Не используют ли ситуацию для отвлечения внимания?
- [ ] Не закрывают ли мелочи главное?
- [ ] Оценить честность намерений

## Формат вывода

```
## Анализ ситуации — точки фокусировки

## Риски слепоты невнимания
### Критические | Серьёзные | Минимальные
| Элемент | Вероятность пропуска | Последствия | Рекомендации |

## Стратегии минимизации
### Интерактивные | Процедурные | Обучающие

## Проверка на манипуляцию
## Рекомендации по валидации
```

## Ключевые принципы
- **Избирательность внимания** — сознание анализирует лишь часть происходящего
- **Дорисовывание реальности** — мозг заполняет пробелы ожидаемыми образами
- **Предельная концентрация** — фокус сужает поле восприятия
- **Неожиданность = невидимость** — неожиданные объекты чаще игнорируются
- **Когнитивная нагрузка** — параллельные задачи усиливают эффект

## Базовая модель
```
Вероятность_Заметки = f(Контраст, Движение, Ожидаемость, Когнитивная_Нагрузка)
```
