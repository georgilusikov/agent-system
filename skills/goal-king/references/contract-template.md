«по возможности») = открытая степень свободы = следующая пустая волна.

## Гейт неизменяемости

Контракт — **вход волны, а не рабочий файл**. После первой волны его текст
не меняется. Что делать с тем, что не влезло:

| Находка | Куда | Куда НЕ |
|---|---|---|
| «нашёл ещё дефект X» | `backlog.md` строкой | новый lane |
| «критерий сформулирован криво» | OWNER_QUEUE | правка `completion_criteria` |
| «бюджета не хватает» | STOP + отчёт владельцу | поднять число в контракте |
| «политика диспатча неоптимальна» | OWNER_QUEUE | волна на переписывание промтов |

Прошлый контракт при новом прогоне не перезаписывается: строка
`Prior run of record: <путь>. NOT overwritten.` Новый прогон — новый файл
с датой в имени.

**Красный флаг прямо в ledger:** волна с `Cost: 0 dispatches`, чей результат —
новая версия контракта, промта или политики. Одна такая = предупреждение,
две подряд = цикл встал, нужен владелец. В плохом прогоне их было три.

## Red-test перед стартом

Прогони `completion_criteria` на текущем состоянии ДО работ — обязаны FAIL.
Зелёные до старта = ничего не измеряют, переписывай. То же для acceptance
каждого lane при нарезке волны.
