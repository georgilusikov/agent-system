# Landing Page Optimizer

## Quick start
Предоставь текущий лендинг (URL/скриншот), описание продукта и целевое действие.
Агент проведёт 6-шаговый аудит и выдаст приоритизированные рекомендации.

> **⚠️ AI-анализ**: Текстовый скрапинг пропускает ~40% контента (JS-элементы, цены, интерактивные элементы, sticky-бары). ВСЕГДА запрашивай визуальный скриншот (PDF/PNG полной страницы). Перед рекомендацией убедись, что элемент действительно отсутствует. Помечай находки: [ВИЗУАЛ ✓] или [ТОЛЬКО ТЕКСТ ⚠️].

## Workflow

### Шаг 1: JTBD пользователя
- Определи сегменты: кто приходит на лендинг и зачем
- Инсайт: никто не хочет ваш продукт — люди хотят решение проблемы

### Шаг 2: Проверка офера
- [ ] Офер про выгоду пользователя, НЕ про продукт
- Плохо: «Мы создаём квизы для лидогенерации»
- Хорошо: «Получи 50 квалифицированных лидов в неделю»

### Шаг 3: Квиз-квалификация
- [ ] Визуальные кнопки, не поля ввода
- [ ] Сегментация по кликам (кто вы?)
- [ ] Квалификация (готовность купить)
- [ ] Контакт через мессенджер, не попап
- ℹ️ Для инфопродуктов ≤$50: квиз может быть избыточным. Альтернатива: фильтр в 1 вопрос или персонализированный CTA

### Шаг 4: Design from the End (активация)
- [ ] Пользователь пробует продукт ДО регистрации
- Паттерн 11Labs: показать результат → переключалка → попробовать → регистрация

### Шаг 5: Минимизация «налогов»
- [ ] Убрана авторизация на лендинге
- [ ] Убран попап «остаться на сайте»
- [ ] Минимум навигации и когнитивной нагрузки

### Шаг 6: Современные инструменты
- Figma Sites / Dev Mode — лендинг без кода
- AI-агенты для генерации текстов и дизайна

## Output format
```
## Оптимизация Лендинга
### Текущий анализ
- Сообщение: {что говорит лендинг}
- Про продукт или пользователя?: {ответ}
- Когнитивная нагрузка: {кол-во объектов}
### Рекомендации
1. Offer: было → стало
2. Квиз: сегменты + вопросы
3. Активация: было → стало
4. Контакт: канал + CTA
### Приоритет изменений
### Метрики: CR, Activation Rate, Qualification Rate
```

## Формулы
- **CR** = Конверсии / Посетители
- **Activation Rate** = Активировались / Посетители
- **Qualification Rate** = Квалифицированные / Всего лидов
- **Conversion** = Sum(Benefits) − Sum(Taxes)

## Чек-лист качества
- [ ] Офер через выгоду пользователя
- [ ] Квиз на кнопках, не на полях ввода
- [ ] Активация без регистрации
- [ ] Контакт через мессенджер
- [ ] Минимум объектов, понятная иерархия

## Key principles
- **Не про тебя, про пользователя** — люди приходят с проблемой
- **Квиз = квалификация** — понимаем кто и что хочет
- **Активация раньше регистрации** — ценность до данных
- **Мессенджеры, не попапы** — не теряй контакт при уходе (Бразилия=WhatsApp, Россия=Telegram, США/Европа=email)
- **Каждый объект = когнитивная нагрузка** — меньше = лучше
- **Проверяй перед рекомендацией** — убедись на визуале, что элемент действительно отсутствует
