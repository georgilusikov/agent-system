# ISRICE Приоритизация

Быстрая оценка: 1-3 минуты на гипотезу. Скорость важнее точности.

## When NOT to Use

- Список ещё не собран, надо ИСКАТЬ узкие места/рычаги → `/leverage`
- Конкурирующие причины одной проблемы → `/debug` Mode H (там prior/evidence, не R×I×C/E)
- 2-3 пункта и порядок очевиден → не нужен skill, просто делай

## Формула

```
ISRICE = (Reach × Impact × Confidence) / Effort
```

| Компонент | Шкала | Что оцениваем |
|---|---|---|
| **Reach** | 1-10 | Сколько людей/кейсов затронет? |
| **Impact** | 1-10 | Насколько велик эффект? |
| **Confidence** | 1-10 | Насколько уверен что сработает? + тег [O/I/S/A] |
| **Effort** | 1-5 | Сколько работы? (1=день, 5=месяц+) |

## Протокол

### §1. Собери список

Перечисли все гипотезы/задачи. Не фильтруй заранее.

### §2. Оцени каждую

Для каждой — R, I, C, E. Не перфекционизируй, первая интуиция обычно верна.
К Confidence обязателен evidence-тег: [O] данные есть / [I] вывод / [S] со слов / [A] допущение.
Confidence ≥7 с тегом [A] — запрещено: либо снизь, либо найди evidence.

### §3. Посчитай и отсортируй

```
| # | Гипотеза | R | I | C (тег) | E | ISRICE | Решение |
|---|----------|---|---|---------|---|--------|---------|
| 1 | ...      | 8 | 9 | 7 [O]   | 2 | 252    | ДЕЛАТЬ  |
| 2 | ...      | 6 | 5 | 4 [A]   | 5 | 24     | ДРОПНУТЬ|
```

### §4. Decompose gate для top-кандидатов

Одно число без декомпозиции = шум. Для каждого «ДЕЛАТЬ» — одна строка:
**сценарии применения + ожидаемая частота + что даст compound-эффект + стоимость создания.**
Не можешь разложить — Impact завышен, пересчитай.

### §5. Отрежь

- **Top 3-5** → делать (уточни effort — для долгих прогонов замер на 1-2 реальных сэмплах, не из головы)
- **Середина** → отложить
- **Хвост** → дропнуть без сожалений

## Принципы

- **Не спорь** — запиши оценку и двигайся. 1-3 минуты на гипотезу
- **Убивай быстро** — лучше дропнуть хорошую идею, чем реализовать плохую
- **Effort — делитель** — сложная задача с высоким impact может проиграть простой со средним
- **Одна метрика** — каждая гипотеза меняет ОДНУ метрику, не «улучшим всё»
- **Ищи кратный рост** — 1.1x игнорируй, ищи 2x-10x

## Калибровка

**Уверенность: [до]% → [после]% — [причина]**

Типичные ошибки:
- Confidence завышен (хочется верить) → снизь на 2-3 пункта
- Effort занижен (оптимизм планирования) → повысь на 1-2 пункта; долгий прогон → замер на сэмпле
- Impact переоценён для «любимых» идей → сравни с уже работающими фичами

## Известные грабли

- **ETA из головы:** оценил прогон «2-4 часа», реально ~10ч (5 мин/кейс × 116) → защита: §5 — замер wall-clock на 1-2 реальных сэмплах до анонса effort
- **Оценка без декомпозиции:** «применимость 8/10» одним числом → шум, спор ни о чём → защита: §4 Decompose gate
- **Confidence [A] = 8:** «уверен что сработает» без единого наблюдения → защита: §2 запрет C≥7 при [A]

- `/anti-bias` — если ловишь себя на завышении любимой идеи

## FORBIDDEN

- Confidence ≥7 с тегом [A] (уверенность без наблюдения)
- «ДЕЛАТЬ» без Decompose-строки §4
- Выдумывать Reach/frequency данные — нет данных = [A] + честная низкая C
  (см. `~/.claude/standards/no-fabricated-evidence.md`)
- Ранжировать 2 пункта через таблицу (ритуал без функции)

## Hard fail

- Нет ISRICE-таблицы → это мнение, не приоритизация
- Все Confidence без evidence-тегов → таблица неотличима от гадания
- Нет решений ДЕЛАТЬ/ОТЛОЖИТЬ/ДРОПНУТЬ → ранжирование без отреза бесполезно
