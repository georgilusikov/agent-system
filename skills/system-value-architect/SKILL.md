# System Value & Motivation Architect

## Быстрый старт
Декомпозируйте продукт на элементы, соберите формулу работоспособности с «потому что», найдите источник энергии (мотивацию), проверьте на правду.

## Workflow

### 1. Декомпозиция системы на элементы
- [ ] Выделить: пользователи, интерфейсы, функции, объекты
- [ ] Для каждого элемента — тип и назначение

### 2. Формула работоспособности
```
[Элементы] [Взаимодействие] [Объект] потому что [Мотивация/Сила]
```
- Без «потому что» система НЕ работает
- Мотивация = источник движения и поступков

### 3. Поиск полезного действия
- [ ] Какую правду о мире использует продукт?
- [ ] Какой инстинкт/потребность активирует?
- [ ] Какую боль закрывает? Какое желание удовлетворяет?
- Типы мотивации: инстинкты, эмоции, социальные, культурные, рациональные

### 4. Проверка формулы (3 теста)
- **Test «Because»** — убрать «потому что»: осталось ли действие?
- **Test Energy** — хочет ли пользователь это сам, или вы заставляете?
- **Test Truth** — это правда о людях, или вы хотите чтобы это было правдой?

### 5. Анализ конкурентов и аналогов
- [ ] Какая формула у успешных продуктов?
- [ ] Какую мотивацию используют? Какое полезное действие?

### 6. Итерация и уточнение
Если формула не работает — изменить объект / мотивацию / сегмент / элементы.
Итерировать пока формула не станет правдой и источник энергии не станет очевидным.

## Формат вывода
```
## Анализ системы на работоспособность
Продукт: [Название] — [Описание]
Элементы: [таблица: элемент | тип | описание]
Формула: [Элементы] [Взаимодействие] [Объект] потому что [Мотивация]
Проверка: Because ✓/✗ | Energy ✓/✗ | Truth ✓/✗
Вердикт: [Работает / Не работает] — [Обоснование]
Полезное действие: [Действие] → [Мотивация] → [Тип]
Аналоги: [таблица сравнений]
Улучшенные варианты: [Формула Б, В...]
Рекомендации: [конкретные действия]
```

## Ключевые принципы
- **Нет мотивации = нет системы** — без «потому что» не работает
- **Мотивация = источник энергии** — в ней сила движения
- **Хочу ≠ Могу** — наличие кнопки не означает желание нажать
- **Правда о людях > Ваше желание** — пользователи такие какие есть
- **Инстинкты и эмоции > Логика** — люди иррациональны

## Формулы
- `System_Viability_Index = (Motivation_Strength × Action_Clarity × Element_Availability) / 3` (шкала 1-10; 8-10 работает, 5-7 доработать, 1-4 не жизнеспособна)
- `Energy_Balance = User_Intrinsic_Motivation - Required_Effort` (положительный = работает)
