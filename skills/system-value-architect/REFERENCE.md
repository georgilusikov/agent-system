# System Value & Motivation Architect — Справочник

## Подробная методология

### Шаг 1: Декомпозиция системы на элементы

Выделите все элементы системы:
- **Пользователи**: кто они? (сегменты, персоны)
- **Интерфейсы**: кнопки, экраны, формы, сообщения
- **Функции**: что может делать продукт?
- **Объекты**: над чем выполняются действия? (контент, товары, сервисы)

**Примеры:**
- YouTube: пользователи, видеоплеер, кнопки, комментарии, видео
- Доставка еды: голодные люди, приложение, курьеры, рестораны, еда
- Мессенджер: люди, сообщения, контакты, чаты

### Шаг 2: Формула работоспособности

```
[Элементы] [Взаимодействие] [Объект] потому что [Мотивация/Сила]
```

**Структура:**
1. **Элементы** — кто участвует?
2. **Взаимодействие** — что делают? (глагол действия)
3. **Объект** — над чем?
4. **Мотивация (потому что)** — САМОЕ ВАЖНОЕ!

**Критерий проверки:**
- Без «потому что» система не работает
- Мотивация = источник движения и поступков

### Шаг 3: Поиск полезного действия

**Вопросы для поиска:**
- Какую ПРАВДУ о мире использует продукт?
- Какой инстинкт/потребность активирует?
- Какую боль закрывает?
- Какое желание удовлетворяет?

**Типы мотивации:**
- **Инстинкты**: голод, безопасность, размножение, принадлежность
- **Эмоции**: скука, страх, радость, любопытство, гнев
- **Социальные потребности**: признание, статус, связь, конкуренция
- **Культурные традиции**: «так принято», «все так делают»
- **Рациональные выгоды**: сэкономить время, деньги, силы

### Шаг 4: Проверка формулы на жизнеспособность

**Тест 1: Test «Because» (Проверка «Потому что»)**
- Уберите «потому что» из формулы
- Осталось ли действие?
- Если НЕТ → нет мотивации → система не работает

**Тест 2: Test Energy (Проверка Энергии)**
- Есть ли источник движения?
- Хочет ли пользователь это сам?
- Или вы заставляете/просите/платите?

**Тест 3: Test Truth (Проверка Правды)**
- Это правда о людях?
- Или вы хотите чтобы это было правдой?
- Есть ли подтверждение в реальном мире?

### Шаг 5: Анализ конкурентов и аналогов

Посмотрите на успешные продукты:
- Какая у них формула?
- Какую мотивацию используют?
- Какое «полезное действие» они выполняют?

**Примеры:**
- YouTube = развлечения (потому что скучно)
- Telegram = общение (потому что нужно передать информацию)
- Tinder = знакомства (потому что одиночество + инстинкт размножения)
- Instagram = самовыражение + зависть (потому что нужен статус)

### Шаг 6: Итерация и уточнение

Если формула не работает:
1. Измените объект действия
2. Измените тип мотивации
3. Измените сегмент пользователей
4. Добавьте/уберите элементы системы

Итерируйте пока:
- Формула не станет правдой
- Не появится источник энергии
- Мотивация не станет очевидной

## Формулы

### Индекс Работоспособности Системы

```
System_Viability_Index = (Motivation_Strength × Action_Clarity × Element_Availability) / 3
```

**Где:**
- Motivation_Strength = сила мотивации (1-10)
- Action_Clarity = ясность действия для пользователя (1-10)
- Element_Availability = доступность элементов (1-10)

**Интерпретация:**
- 8-10: Система будет работать
- 5-7: Требуется доработка
- 1-4: Система не жизнеспособна

### Энергетический Баланс

```
Energy_Balance = User_Intrinsic_Motivation - Required_Effort
```

**Где:**
- User_Intrinsic_Motivation = внутренняя мотивация пользователя (хочет сам)
- Required_Effort = усилия которые нужно приложить

**Интерпретация:**
- Положительный баланс = система работает
- Отрицательный баланс = нужен внешний стимул (плата, принуждение)

## Типичные ошибки

### 1. «Продукт для Продукта»
**Суть:** Создание функции которая никому не нужна

**Примеры:**
- «Видеохостинг» (без развлечений)
- «Мессенджер» (без потребности общаться)
- «Маркетплейс дров» (без понимания зачем)

**Как исправить:** Найти ПОЧЕМУ

### 2. «Заставим Пользователя»
**Суть:** Попытка мотивировать внешним стимулом вместо внутреннего

**Примеры:**
- «Попросим их зарегистрироваться»
- «Дадим скидку если они...»
- «Напишем им письмо»

**Реальность:** Если не ХОЧУ сам → не будет работать

**Как исправить:** Найти внутреннюю мотивацию

### 3. «Рациональный Пользователь»
**Суть:** Уверенность что люди действуют логично

**Реальность:** Люди действуют по мотивации, инстинктам, эмоциям

**Как исправить:** Проверить что реально движет людьми

### 4. «Это Очевидно»
**Суть:** Пропуск проверки «потому что»

**Реальность:** «Очевидно» ≠ «Правда»

**Как исправить:** Всегда проверять формулу на реальных людях

## Примеры

### Пример 1: YouTube
**Неправильная формула:**
«Пользователи смотрят видео»

**Правильная формула:**
«Пользователи смотрят видео потому что им скучно и они хотят развлечения»

**Полезное действие:** Развлечения
**Мотивация:** Скука → потребность в развлечениях
**Тип:** Эмоция + Культурная привычка

### Пример 2: Непонятный Стартап
**Ошибка:** «У нас есть пользователи, кнопки, сайт, но ничего не работает»

**Диагноз:** Нет «потому что» — нет мотивации

**Решение:** Найти что пользователи ХОТЯТ делать, а не что они МОГУТ делать
