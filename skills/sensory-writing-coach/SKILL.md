# Sensory Writing Coach

## Быстрый старт
Получи текст от пользователя → найди абстракции → замени чувственным опытом → проверь визуализируемость.

## Входные данные
- Исходный текст (абстрактный или для проверки)
- Цель текста (что должен понять/сделать читатель)
- Целевая аудитория (опционально)

## Рабочий процесс

### Шаг 1: Определить абстракции
- [ ] Выписать все абстрактные слова (качество, надёжность, эффективность)
- [ ] Для каждой спросить: «Что конкретно?»
- [ ] Проверить: можно ли это визуально представить?

### Шаг 2: Найти чувственный эквивалент
- [ ] Для каждой абстракции: «Как это выглядит/звучит/ощущается?»
- [ ] Описать через 5 чувств: зрение, слух, осязание, обоняние, вкус
- [ ] Пример: «Надёжный» → «Выдерживает падение с 2 метров»

### Шаг 3: Описать сценарий
- [ ] Создать «внутренний фильм» — последовательность действий
- [ ] Использовать глаголы действия + сенсорные детали
- [ ] Описать узнаваемую ситуацию из жизни читателя

### Шаг 4: Проверить абстрактность
- [ ] Есть ли визуальные образы?
- [ ] Можно ли представить как кино?
- [ ] Есть ли конкретные детали и глаголы действия?
- [ ] Если не пройден — «прибить абстракции к реальности»

### Шаг 5: Адаптировать под аудиторию
- [ ] Определить типичные ситуации аудитории
- [ ] Использовать знакомые образы
- [ ] Проверить: поймёт ли человек без контекста?

## Формат вывода

```
## Анализ текста на чувственный опыт

### Найденные абстракции
| Абстракция | Проблема | Что конкретно? |

### Сценарии использования
**Ситуация N**: описание + чувственный опыт + конкретика

### Улучшенный текст
{переписанный текст}

### До/После
**До (абстрактно)**: ... → **После (чувственно)**: ...

### Рекомендации
```

## Ключевые принципы
- **Показывай, а не рассказывай** — сенсорные образы вместо оценок
- **Конкретика убеждает** — чем детальнее, тем лучше
- **Внутренний фильм** — читатель должен представлять ситуацию
- **Молоток и гвозди** — прибей абстракции к реальности
- **Убедительность** = сенсорные образы / абстракции

## Формулы
- **Убедительность** = (Количество сенсорных образов) / (Количество абстракций)
- **Визуализируемость** = Можно ли представить текст как кино?
