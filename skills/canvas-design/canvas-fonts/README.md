# Canvas Fonts Directory

This directory contains fonts for use with the canvas-design skill.

To add fonts:
1. Download .ttf or .otf font files
2. Place them in this directory
3. Reference them in your canvas design code

Recommended sources for free fonts:
- Google Fonts: https://fonts.google.com
- Font Squirrel: https://www.fontsquirrel.com
- DaFont: https://www.dafont.com
